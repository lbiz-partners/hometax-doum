# 홈택스 도움 스킬

> **“부가세 신고, 무엇부터 준비해야 하죠?”**
>
> **“매출과 실제 입금이 맞는지 확인하고 싶어요.”**
>
> **“이번 달 세금 업무를 한 번에 정리해 주세요.”**

**혼자 챙기기 어려운 홈택스 업무를 AI와 함께 준비하세요.** 소상공인·개인사업자·프리랜서를 위한 스킬 모음입니다. 사용하는 AI 앱에 설치하면, 평소 말하듯 요청해 필요한 자료와 다음 할 일을 안내받을 수 있습니다.

**버전:** 4.1.2 · **무료 스킬 6종** · [처음 시작 가이드](시작-가이드.md)

## 이런 일을 도와드려요

세무 용어를 몰라도 괜찮습니다. **지금 해야 할 일을 평소 쓰는 말로 알려주세요.** 필요한 자료와 확인 순서를 함께 정리합니다.

| 지금 필요한 일 | 이렇게 요청하세요 | 받게 되는 도움 |
|---|---|---|
| 무엇부터 할지 모르겠어요 | “이번 달 세금 업무 정리해줘.” | 사업장 상황에 맞는 할 일과 준비자료 목록 |
| 부가세 신고가 다가와요 | “부가세 신고 준비부터 도와줘.” | 일반·간이과세 구분, 매출·매입 자료, 제출 전 확인 |
| 종합소득세를 준비해요 | “종합소득세 신고 도와줘.” | 필요한 자료, 신고 화면 순서, 신고 후 확인할 일 |
| 세금계산서를 발행해야 해요 | “세금계산서 발급 전에 점검해줘.” | 거래처·금액·청구/영수 확인, 발급·수정·조회 안내 |
| 카드·영수증이 쌓였어요 | “사업 관련 지출을 분류해줘.” | 지출 분류, 증빙 누락과 공제·불공제 후보 확인 |
| 아직 못 받은 돈이 있어요 | “계산서와 입금내역을 확인해줘.” | 미수금·부분입금·선금 등 확인할 거래 정리 |
| 면세사업자예요 | “사업장현황신고 준비해줘.” | 학원·주택임대·인적용역 등의 자료·첨부 안내 |
| 외주비를 지급했어요 | “어떤 자료와 신고가 필요한지 알려줘.” | 원천세·지급명세서 준비 목록 |
| 증명서가 필요해요 | “대출에 필요한 세무서류를 점검해줘.” | 문서 종류·귀속기간·발급일·누락 확인 |
| 신고 후에도 불안해요 | “신고·납부·환급 상태를 나눠 확인해줘.” | 접수증·납부 결과·환급 입금을 각각 확인 |

개업·사업자등록 정정·휴폐업·현금영수증·신고 정정·기한연장 등도 포함해 **개인사업자 24개 업무 묶음**을 안내합니다. [전체 업무 목록](skills/hometax-tax-hub/references/service-catalog.md)에서 업무별 지원 수준을 확인할 수 있습니다.

## 처음에는 이 문장 하나면 됩니다

설치한 AI 앱의 **새 대화**에 아래 문장을 복사하세요.

```text
홈택스 도움 스킬로 내 사업장 상황부터 확인해줘.
업종, 과세유형, 직원 유무, 확인할 기간 중 필요한 것만 질문하고,
이번 달 할 일과 준비자료를 정리해줘.
자료가 없거나 확인하지 않은 항목은 미확인으로 남겨줘.
```

이후에는 “부가세부터 준비하자”, “이 파일에서 빠진 자료를 찾아줘”처럼 이어가면 됩니다. 스킬이 여러 개 설치되어 있다면 **홈택스 도움 스킬로**라는 표현을 함께 말해 주세요.

사용 흐름은 **사업장·기간 확인 → 자료 준비 → 점검 → 홈택스 화면 확인 → 결과 증빙 확인**입니다. 실제 화면을 함께 보려면 AI 앱에 브라우저 연결 도구가 필요합니다. 로그인·인증과 마지막 제출·발급·납부는 본인이 진행합니다.

## Free와 Pro는 무엇이 다른가요?

**Free는 필요한 자료와 화면 순서, 수동 점검을 돕습니다. Pro는 계산과 여러 파일의 일괄 대조를 더합니다.**

| 기능 | Free · 무료 6종 | Pro · 9종 |
|---|---|---|
| 24개 업무의 준비자료·화면 안내 | 제공 | 포함 |
| 8개 업종·상황별 준비목록 | 제공 | 포함 |
| 영수증 분류·미수금 수동 점검 | 제공 | 포함 |
| 종소세·원천징수 예상액 계산 | 준비자료 안내 | 지원 범위 내 계산·검산 |
| 매출·정산·입금 파일 대조 | 수동 확인표 | 파일 변환·일괄 대조·보고서 |
| 업종별 8개 계산 모드 | 자료 준비·수동 확인 | 지원 조건 내 계산·화면 금액 비교 |
| 증명서 기간·발급일·누락 점검 | 수동 확인표 | 입력한 서류 조건 일괄 대조 |
| 사업자등록 신청·정정 | 기본 안내 | 전용 스킬로 상세 안내 |

Pro는 Free 6종에 **종소세 준비·계산, 원천세, 사업자등록 전용 스킬 3종**을 더한 구성입니다. 법인세는 별도 제품 범위이며 이 패키지에 포함되지 않습니다.

## 내 업종에도 사용할 수 있나요?

온라인판매·소매, 음식점, 제조, 프리랜서, 학원·면세 서비스, 상가임대, 주택임대, 수출·과세면세 겸영의 **8개 업종·상황**에 맞춘 준비목록이 있습니다.

예를 들어 “온라인 판매를 하는데 정산금이 매출보다 적어”, “학원 사업장현황신고 자료를 준비하고 싶어”처럼 요청하세요. 업종명만으로 과세유형이나 공제 자격을 정하지 않고 실제 조건과 자료를 확인합니다. [업종별 준비 안내](skills/tax-prep-kr/references/industry-guide.md)

## 설치하고 시작하기

이 저장소는 **Free 공개판**입니다. 윈도우·맥·리눅스에서 사용할 수 있습니다. 지금 쓰는 방법을 고르세요. 사용하는 AI 앱의 이용조건과 브라우저 연결 환경은 별도로 확인하세요.

| 지금 쓰는 것 | 설치 | Python | 운영체제 |
|---|---|---|---|
| Claude Code | 아래 플러그인 두 줄 | 필요 없음 | 윈도우·맥·리눅스 같음 |
| `.skill` 업로드 앱 | 데스크탑용 `.skill` 6개 추가 | 필요 없음 | 윈도우·맥 같음 |
| Codex 등 폴더 스킬 (Windows) | `py -3 install.py` | 3.10 이상 | Windows |
| Codex 등 폴더 스킬 (Mac/Linux) | `bash install.sh` | 3.10 이상 | macOS·Linux·Git Bash |

### Claude Code를 사용한다면

Claude Code 대화창에서 다음 두 줄을 차례로 입력하세요. 윈도우와 맥이 같습니다.

```text
/plugin marketplace add lbiz-partners/hometax-doum
/plugin install hometax-doum@lbiz-partners
```

무료 스킬 6종이 함께 설치됩니다. 업데이트할 때는 `/plugin marketplace update lbiz-partners`로 마켓플레이스를 갱신하고 설치된 플러그인의 버전을 확인하세요.

### `.skill` 업로드를 지원하는 앱이라면

전달받은 ZIP의 데스크탑용 `.skill` 파일 **6개**를 앱의 스킬 설정에 추가하세요. 터미널과 Python이 없어도 됩니다. 설치 방식은 [처음 시작 가이드](시작-가이드.md)에 정리했습니다.

### 폴더 스킬을 사용한다면 (Windows · Mac · Linux)

1. 이 페이지의 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. 압축을 푼 폴더로 이동합니다. 전달용 ZIP은 `2_CLI용_폴더스킬` 폴더를 사용합니다.
3. 아래 중 환경에 맞는 명령을 실행합니다.

**Windows (PowerShell)** — Python 3.10 이상. `py` 실행기가 없으면 `python install.py ...`처럼 `-3`도 빼고 실행하세요.

```powershell
py -3 install.py --check
py -3 install.py --target-dir $env:USERPROFILE\.codex\skills
```

실행 정책 때문에 `install.ps1`이 막히면 위 `py -3` 명령을 쓰세요. `install.ps1`은 같은 설치기를 실행합니다.

**Mac / Linux / Git Bash**

```bash
bash install.sh --check
bash install.sh --target-dir ~/.codex/skills
```

설치기는 기존 스킬을 백업한 뒤 교체합니다. 앱별 폴더는 아래와 같습니다.

| 앱 | Windows | Mac / Linux |
|---|---|---|
| Codex | `%USERPROFILE%\.codex\skills` | `~/.codex/skills` |
| Claude Code 폴더 설치 | `%USERPROFILE%\.claude\skills` | `~/.claude/skills` |
| Aside | `%USERPROFILE%\.aside\u\0\skills\user` | `~/.aside/u/0/skills/user` |

인자 없이 실행하면 설치된 앱 폴더를 찾아 넣습니다. 앱을 못 찾으면 `--target-dir`로 지정하세요.

설치 후 새 대화에서 “**홈택스 도움 스킬로 이번 달 할 일을 정리해줘**”라고 요청하고, 해당 스킬이 선택되는지 확인하세요.

## 어디까지 확인된 기능인가요?

공개 검증 기록은 **24개 대표 경로**의 메뉴 진입·로그인 요구·공개 조회와 가상자료 모의계산을 구분합니다. 모든 하위 기능이나 실제 신고·발급·납부를 완료했다는 뜻은 아닙니다. [업무별 공개 확인 범위](skills/hometax-tax-hub/references/live-ui-verification.md)

- 계산은 지원 연도·유형·자료 범위 안에서 수행합니다. 일부 금액의 일치는 최종 세액이나 신고서 전체의 적정성을 뜻하지 않습니다.
- 자료가 없거나 확인하지 못한 값은 **미확인**으로 남깁니다. 신고 접수·납부·환급 입금도 따로 확인합니다.
- 로그인·인증과 최종 제출·발급·납부는 본인이 진행합니다. 비밀번호·인증서 암호·OTP를 AI에 알려주지 마세요.
- 자료의 주민번호·계좌번호 등 불필요한 식별정보는 가리거나 가명으로 바꿔 주세요.
- 복잡하거나 지원 범위 밖의 세무 판단은 필요한 자료와 쟁점을 정리해 전문가 검토로 연결합니다.

# 홈택스 도움 스킬

> **“부가세 신고 도와줘.”**
>
> **“세금계산서 발행해줘.”**
>
> **“사업장현황신고 도와줘.”**

**홈택스에서 막히면, AI에게 이렇게 말해 보세요.** 스킬을 설치하면 Claude·Codex·Aside 등 지원 도구에서 필요한 자료, 화면 순서, 확인할 숫자를 함께 짚어갑니다. 소상공인·소규모 개인사업자·1인 대표·프리랜서가 혼자서도 신고 준비를 이어가도록 돕습니다.

로그인·인증과 마지막 제출·발급·납부는 본인이 진행합니다.

**버전:** 3.9.0 · **무료 스킬 6종**

## 무료로 이만큼 됩니다

**무료 6종으로 부가세·종소세·세금계산서·면세사업자 신고 준비를 시작하세요.**

| 하고 싶은 일 | AI에게 이렇게 말하세요 | 도움받는 내용 |
|---|---|---|
| **부가세 신고** | **“부가세 신고 도와줘”** | 일반·간이과세 자료 준비, 매출·매입 대조, 제출 전 확인 |
| **전자세금계산서 발행** | **“세금계산서 발행해줘”** | 거래처·금액·청구/영수 확인, 발급·수정·조회 안내 |
| **면세사업자 사업장현황신고** | **“사업장현황신고 도와줘”** | 학원·주택임대·인적용역·기타 면세의 자료와 첨부 확인 |
| **종합소득세 신고** | **“종합소득세 신고 도와줘”** | 모두채움·일반 신고 안내, 제출 전 확인, 신고 후 할 일 |
| **못 받은 돈 확인** | **“미수금 확인해줘”** | 계산서와 입금내역 수동 대조, 부분입금·선금·불명확한 거래 확인 |
| 영수증·카드 정리 | “카드 내역 분류해줘” | 사업 관련 지출과 공제·불공제 후보 정리 |
| 이번 달 할 일 | “이번 달 세금 업무 정리해줘” | 사업장 상황에 맞춘 자료·일정·증명서 체크리스트 |
| 신고·납부 마무리 | “신고하고 납부까지 끝났는지 확인해줘” | 접수증·국세·지방세·환급 진행을 각각 확인 |

처음부터 세무 용어를 알 필요는 없습니다. **“세무 도와줘”**로 시작하면 필요한 것부터 묻습니다. 이미 확인한 사업장 설정은 사용자가 선택한 로컬 폴더에서 다시 쓸 수 있습니다.

> 스킬이 많은 환경에서는 **“홈택스 도움 스킬로 부가세 신고 도와줘”**처럼 이름을 함께 말하세요. 미수금은 **“tax-invoice-hometax 스킬로 미수금 점검해줘”**로 바로 시작할 수 있습니다.

**화면 안내와 수동 점검으로 시작하려면 무료**, **예상세액 계산과 여러 자료의 일괄 대조가 필요하면 Pro**를 선택하세요.

|---|:---:|:---:|
| 부가세·종소세 신고 화면 안내 | **제공** | **포함** |
| 세금계산서 발급·수정·조회 안내 | **제공** | **포함** |
| 영수증·카드 분류, 미수금 수동 점검 | **제공** | **포함** |
| 사업장현황신고 업종별 안내·수동 양식 | **제공** | **포함** |
| 이번 달 할 일·신고/납부 상태 확인표 | **제공** | **포함 + 상태 검증** |
| **내 종소세 예상세액 계산·검산** | — | **제공** |
| **급여·일용직·외주비 원천징수 계산** | — | **제공** |
| **여러 매출·정산·입금 자료 일괄 대조** | — | **대조 + 보고서** |
| **사업장현황신고 연간 집계·입력값 대조** | — | **집계 + 준비표** |
| **사업자등록 신청·정정 전용 스킬** | 기본 경로 안내 | **제공** |

Pro는 무료 6종에 **종소세 준비·계산, 원천세, 사업자등록 전용 스킬 3종**을 더한 구성입니다. 계산·검증은 각 엔진이 지원하는 연도와 입력 범위 안에서 수행합니다. 법인세는 향후 별도 **Ultra** 제품 계획입니다.

## Pro는 이럴 때 도움이 됩니다

### ① “내 세금, 미리 얼마 나올지 알고 싶어요”

`jongsose-prep-kr`로 **종합소득세 예상세액과 분납 규모**를 확인하고, 지원 범위 안에서 근로·사업소득 합산과 홈택스 입력값을 검산합니다.

같은 스킬에 **월간 매출·정산·입금 대조**와 **면세사업자 연간 수입·매입 집계**도 들어 있습니다. “연간 수입과 신고 화면의 금액이 맞는지 확인해줘”처럼 요청하면 누락·중복·환불·분류 차이를 정리합니다. 연간 집계는 정리된 JSON 입력을 사용하며 원본 엑셀·CSV는 먼저 대조·변환합니다.

### ② “직원 급여나 외주비에서 얼마를 떼야 하죠?”

`withholding-tax-hometax`로 **근로·일용·사업·기타소득의 예상 원천징수액**을 계산하고, 원천세 신고 준비와 지급명세서 확인을 이어갑니다. **내 종소세**와 **인건비를 지급하면서 처리하는 원천세**를 구분해 안내합니다.

### ③ “사업자등록을 하거나 업종을 바꾸고 싶어요”

`biz-reg-hometax`로 **개인 사업자등록 신청·정정·업종 추가**에 필요한 자료와 홈택스 절차를 확인합니다. 통신판매업 연계도 함께 안내합니다.

## 설치하고 바로 시작하기

### Claude Code — 마켓플레이스 설치

Claude Code 대화창에서 아래 두 줄을 차례로 입력합니다.

```text
/plugin marketplace add lbiz-partners/hometax-doum
/plugin install hometax-doum@lbiz-partners
```

무료 스킬 6종이 함께 설치됩니다. 새 버전은 `/plugin marketplace update lbiz-partners`로 마켓플레이스를 갱신한 뒤 설치된 플러그인의 버전을 확인하세요.

### Codex·Aside 등 — 폴더 스킬 설치

이 저장소의 **Code → Download ZIP**으로 내려받아 압축을 풀거나, 전달받은 무료 ZIP의 CLI 폴더로 이동합니다. Codex 설치 예시입니다.

```bash
bash install.sh --check
bash install.sh --target-dir ~/.codex/skills
```

Claude Code의 폴더 설치는 `~/.claude/skills`를 지정합니다. Aside 등 다른 도구는 실제 스킬 폴더를 확인해 지정하세요. 설치 스크립트에는 Python 3.10 이상이 필요하며 **기존 스킬은 백업한 뒤 교체**합니다.

### `.skill` 업로드를 지원하는 앱

동봉된 **데스크탑용 `.skill` 파일 6개**를 앱의 스킬 설정에서 설치합니다. 앱별 지원 여부와 자세한 경로는 [시작 가이드](시작-가이드.md)를 참고하세요.

**설치 후 새 대화에서 “홈택스 도움 스킬로 부가세 신고 도와줘”라고 말해 보세요.** 자료 준비 안내가 나오면 스킬이 인식된 것입니다. 실제 홈택스 로그인은 별도로 진행합니다.

## 사용 전 이것만 확인하세요

- **로그인·인증은 본인만:** 비밀번호·인증서 암호·OTP를 AI에 알려주지 않습니다.
- **마지막 버튼은 본인만:** 최종 제출·발급·납부는 내용을 확인한 뒤 직접 진행합니다.
- **모르는 숫자는 미확인으로:** 자료가 없다고 0원이나 신고 완료로 처리하지 않습니다.
- **식별정보는 최소한만:** 주민번호·계좌번호 등은 대화창에 넣지 말고 가명이나 마스킹한 자료를 사용합니다.
- **판단 근거는 현재 자료로:** 해당 연도 국세청·법령 원문, 현재 홈택스 화면과 실제 접수·납부 결과를 각각 확인합니다.

사업장현황신고 기능은 신고 준비용입니다. 공식 신고서 자동 완성·제출, 면세 자격·수입 귀속·신고 의무의 자동 판단, 간주임대료·세액 계산은 이 기능에 포함되지 않습니다.

# 홈택스 도움 무료판

**버전:** 3.8.0 · 무료 스킬 6종 · 소규모 개인사업자·1인 대표·프리랜서용

매달 자료를 모으고, 확인할 거래를 정리하고, 홈택스 신고·납부 상태를 점검하도록 돕습니다. 한 사람이 사무·영업·세무 준비를 함께 하는 사업장을 중심으로 구성했습니다.

## 시작하기

AI에게 **“홈택스 도움 스킬로 이번 달 제가 할 일 알려줘”**라고 말하세요. 처음에는 사업 형태, 일반·간이·면세 여부, 매출 경로, 직원·외주비 지급 여부를 확인합니다. 모르는 내용은 확인 필요로 남깁니다. 이미 확인한 사업장 설정은 사용자가 선택한 로컬 폴더에서 재사용합니다.

| 할 일 | 사용 문장 | 무료 스킬 |
|---|---|---|
| 사업장 설정·이번 달 할 일 | 이번 달 세금 업무 정리해줘 | hometax-tax-hub |
| 자료·일정·증명서 준비 | 필요한 자료와 증명서 알려줘 | tax-prep-kr |
| 카드·영수증 점검 | 확인해야 할 지출만 골라줘 | receipt-classify-kr |
| 계산서·미수금 | 발급한 계산서와 입금 내역 대조해줘 | tax-invoice-hometax |
| 부가세 | 일반/간이과세 부가세 준비해줘 | vat-hometax |
| 종소세·면세사업자 | 모두채움 확인하고 신고 후 할 일 알려줘 | income-tax-hometax |

기존 무료판의 세금계산서 발급·수정·조회와 미수금 수동 점검을 유지합니다. 자료 누락, 중복 증빙, 취소·환불, 불명확한 입금을 확인하며 자동 추측으로 완납이나 신고 완료를 확정하지 않습니다.

## 무료와 Pro

| 내용 | 무료 6종 | 유료 Pro 9종 |
|---|---|---|
| 기본 안내·수동 분류·미수금·신고 점검 | 제공 | 포함 |
| 사업장 설정·월간 체크리스트·신고/납부 구분 | 안내·사용자 확인표 | 코드로 상태 검증 추가 |
| 면세사업자·국세증명·환급/포인트 | 공식 경로·요건 확인 안내 | 포함 |
| 여러 CSV/JSON 매출·정산·은행 자료 일괄 대조 | 수동 대조 안내 | 코드 대조·보고서 |
| 종소세 예상세액·원천세 계산 | 전용 엔진 미포함 | 지원 범위 내 제공 |
| 개인 사업자등록 신청·정정 전용 스킬 | 기본 경로 안내 | biz-reg-hometax 포함 |

Pro 전용 3종은 `jongsose-prep-kr`, `withholding-tax-hometax`, `biz-reg-hometax`입니다. 무료판에 계산 코드가 포함되지 않습니다. 필요한 Pro 스킬이 없으면 미설치를 알리고 가능한 기본 안내를 계속합니다. 법인세는 이후 별도 Ultra 제품 계획이며 현재 무료/Pro의 법인세 신고 기능으로 안내하지 않습니다.

## 설치

상세 단계와 파일 위치는 [시작 가이드](시작-가이드.md)를 따르세요.

- `.skill` 업로드를 지원하는 앱: 동봉한 데스크탑 파일 6개를 설치합니다. 업로드 지원 여부는 해당 앱에서 확인합니다.
- 폴더 스킬을 지원하는 도구: `bash install.sh --check`로 검사하고 `bash install.sh --target-dir <내 스킬 폴더>`로 설치합니다. 설치 스크립트에는 Python 3.10 이상이 필요합니다.
- 기존 Claude Code 마켓플레이스 주소는 `lbiz-partners/hometax-doum`입니다. 원격 게시 전에는 마켓플레이스에 이번 버전이 반영됐다고 간주하지 마세요. 받은 패키지의 VERSION을 확인합니다.

기존 같은 이름의 스킬은 백업 후 교체합니다. 설치된 파일, 앱의 스킬 인식, 실제 홈택스 로그인 세션은 각각 확인합니다.

## 사용 범위

화면 경로는 현재 홈택스 화면에서 확인하고, 세법·기한·적용 요건은 해당 연도 국세청/법령 원문을 대조합니다. 신고 접수와 납부는 별도입니다. 개인지방소득세 등은 해당 시스템의 후속 절차와 결과를 확인합니다.

로그인·인증·최종 제출·발급·납부는 사용자가 직접 합니다. 계좌·주민번호를 채팅에 입력하게 하지 않으며 샘플은 가상 자료입니다. 세무대리나 확정적인 세무 판단을 제공하는 서비스가 아닙니다. 자세한 이용 조건은 [LICENSE.md](LICENSE.md)를 확인하세요.

## 개발·검증

개발용 훅은 저장소 개발 세션에만 적용하며 고객 ZIP에는 넣지 않습니다. 복제한 개발 저장소에서는 `git config core.hooksPath .githooks`를 한 번 실행합니다. 빌드는 `bash scripts/build.sh`이며 무료 코드 경계·회귀·설치·ZIP 바이트 대조를 통과한 산출물만 생성합니다.

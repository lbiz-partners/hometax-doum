# 🧾 홈택스 도움 스킬 (hometax-doum)

> AI 에이전트(Claude·Codex·Aside)에게 **말로 시키면**, 홈택스 세무 작업을 제출·발급 직전까지 안내해 주는 무료 스킬 모음입니다.
> 부가가치세 · 종합소득세 · 전자세금계산서를 다루는 **개인사업자·프리랜서용**.

**세무 지식이 없어도 됩니다.** "부가세 신고 도와줘" 한마디면 화면 순서·확인할 숫자·놓치기 쉬운 함정을 옆에서 짚어줍니다.

---

## 무엇을 할 수 있나요

| 하고 싶은 일 | AI에게 이렇게 말하세요 | 스킬 |
|---|---|---|
| 뭐부터 할지 모르겠다 | **"세무 도와줘"** | hometax-tax-hub |
| 신고 전 서류 준비 | "신고 준비 뭐부터 해?" | tax-prep-kr |
| 영수증·카드내역 정리 | "카드 내역 분류해줘" (엑셀 첨부) | receipt-classify-kr |
| 세금계산서 발행 | "세금계산서 끊어줘" | tax-invoice-hometax |
| 부가세 신고 (일반/간이) | "부가세 신고 도와줘" | vat-hometax |
| 종소세 홈택스 신고 | "종합소득세 신고 도와줘" | income-tax-hometax |

전부 **홈택스 화면을 최종 근거**로 삼고, 제출·발급·납부 버튼은 **반드시 본인이** 누르는 구조입니다.

## 설치 (1분)

이 저장소를 다운로드(`Code → Download ZIP` 또는 `git clone`)한 뒤, 쓰는 도구의 스킬 폴더에 복사:

```bash
cp -R skills/* ~/.claude/skills/                          # Claude Code
cp -R skills/* ~/.codex/skills/                           # Codex
cp -R skills/* ~/.aside/u/0/agents/main/skills/user/      # Aside
```

Claude Desktop 앱은 각 스킬 폴더를 zip으로 압축해 설정 → Skills에 업로드하면 됩니다.

설치 확인: 새 대화에서 **"세무 도와줘"** → 안내가 나오면 성공.

## 안전 규칙 (모든 스킬에 내장)

1. 홈택스 로그인·인증서·OTP는 **본인만** 입력 — AI에게 비밀번호를 주지 않습니다
2. **최종 제출·발급 버튼은 반드시 본인이** — AI는 "이 내용으로 진행해도 될까요?" 확인까지만
3. 홈택스에 없는 숫자를 창작하지 않음, 공제/불공제는 단정 대신 "후보 + 확인 질문"
4. 문제가 있으면 제출 권유 자체를 차단

## 📝 업데이트 내역

### 2026-07-23 — 세금계산서 발급 스킬(tax-invoice-hometax) 실무 개선 2종

실제 발급 작업 중 나온 불편을 반영했습니다.

- **청구/영수 자동 선택** — 홈택스 발급 화면 기본값이 `청구`라 실수하기 쉬웠습니다. 이제 스킬이 **"대금을 이미 받으셨나요, 아직 안 받고 청구하는 건가요?"**를 먼저 물어, **받았으면 `영수`, 아직이면 `청구`**로 자동 선택하고 발급 직전 다시 확인합니다.
- **기존/신규 거래처 구분** — 발급 시작 시 **"전에 발행한 곳인가요, 신규인가요?"**를 먼저 물어, 기존 거래처는 저장된 정보를 불러오고(재입력·오타 방지), 신규는 사업자번호로 조회합니다. 어느 쪽이든 발급 전 **휴·폐업 여부**를 한 번 확인합니다.

### 2026-07-22 — 부가세 스킬(vat-hometax) 보완

개인사업자가 **놓치기 쉬운 경감·공제세액 2종**을 제출 직전 체크리스트에서 자동으로 짚도록 강화했습니다. 실제 신고 중 발견한 누락을 반영한 개선입니다.

- **전자신고 세액공제** — 확정신고를 본인이 직접 전자신고하면 자동 적용 (2026년 1기 확정신고부터 건당 5,000원, 기존 1만원에서 축소)
- **전자세금계산서 발급세액 공제** — 직전연도 공급가액(면세 포함) 합계 **3억원 미만 개인사업자**가 전자세금계산서를 발급하고 다음날까지 전송하면 **발급 건당 200원**(연 100만원 한도) 공제
  - 이 공제는 미리채움에 자동 반영되지 않고 **발급건수를 직접 입력**해야 반영됩니다 — 스킬이 조회→입력→입력완료 절차를 안내
  - 홈택스가 `전자세금계산서발급정상입력여부` 안내(경고)를 띄우면 = 이 공제를 확인하라는 신호
- 대상 아님: 간이과세자, 법인사업자, 직전연도 3억원 이상 개인사업자

> 두 공제 모두 **매 확정신고마다 반복 발생**하므로, 이제 스킬이 매번 먼저 확인합니다.

## 면책

본 스킬은 신고 '준비'와 화면 안내를 돕는 참고용 도구이며 세무 자문이 아닙니다. 최종 수치의 근거는 홈택스 화면이고, 신고·납부 판단은 세무 전문가 검토를 권합니다. 사용 결과에 대한 책임은 사용자에게 있습니다.

# 🧾 홈택스 도움 스킬 (hometax-doum)

> AI 에이전트(Claude·Codex·Aside)에게 **말로 시키면**, 홈택스 세무 작업을 제출·발급 직전까지 안내해 주는 **무료** 스킬 모음입니다.
> **부가가치세 · 종합소득세 · 전자세금계산서**를 다루는 개인사업자·프리랜서용.
> **소규모 법인(1인 대표·스타트업)도 부가세·세금계산서는 그대로 씁니다** — 아래 「소규모 법인사업자도 씁니다」 참고.

**세무 지식이 없어도 됩니다.** "부가세 신고 도와줘" 한마디면 화면 순서·확인할 숫자·놓치기 쉬운 함정을 옆에서 짚어줍니다. 세무사에게 맡기기 전에, 또는 직접 신고하는 분이 **혼자서도 막히지 않게** 돕는 것이 목표입니다.

---

## ✅ 무료로 이만큼 됩니다

이 저장소 6종만으로 **홈택스 3대 작업을 제출·발급 직전까지** 스스로 진행할 수 있습니다.

| 하고 싶은 일 | AI에게 이렇게 말하세요 | 스킬 |
|---|---|---|
| 뭐부터 할지 모르겠다 | **"세무 도와줘"** | hometax-tax-hub |
| 신고 전 서류·폴더·일정 준비 | "신고 준비 뭐부터 해?" | tax-prep-kr |
| 영수증·카드내역 정리(공제/불공제) | "카드 내역 분류해줘" (엑셀 첨부) | receipt-classify-kr |
| **전자세금계산서 발행·수정·조회** | "세금계산서 끊어줘" | tax-invoice-hometax |
| **못 받은 돈(미수금) 점검** | "미수금 확인해줘" (통장내역 엑셀 첨부 시 **계좌번호는 지우거나 가리고**) | tax-invoice-hometax |
| **부가가치세 신고** (일반/간이) | "부가세 신고 도와줘" | vat-hometax |
| **종합소득세 홈택스 신고** (5월) | "종합소득세 신고 도와줘" | income-tax-hometax |

- **부가세**: 미리채움 조회 → 매출·매입 대조 → 놓치기 쉬운 공제(전자신고·전자세금계산서 발급세액)까지 제출 직전 점검
- **종소세**: 모두채움/일반 신고, 경비율 vs 간편장부 선택 점검, 제출 직전 QA
- **세금계산서**: 발급·수정발급·조회 — **기존 거래처는 질문 5개 패스트트랙**(저장된 정보 재활용, 반복 거래는 "지난달과 같아요" 한마디)으로 빠르게, **신규 거래처는 꼭 필요한 7가지만** 한 번에 물어서 쉽게 발행. 금액 자릿수·청구/영수·과세구분·거래처 확인으로 실수 방지
- **미수금 점검**: 청구로 발행한 세금계산서를 통장 입금내역과 대조해 **못 받은 돈을 찾아줍니다**. 건수 검증 게이트와 "애매하면 임의 판단 대신 사장님께 확인" 원칙으로 건이 조용히 사라지지 않게 설계했고(현금·상계처럼 통장에 안 잡히는 결제는 확인 질문으로 보완), 경과일수별 경고(독촉 → 내용증명 검토 → 지급명령·소멸시효 주의)로 다음 할 일까지 짚어줍니다. 미입금이어도 매출 신고는 필수라는 세무 함정, '영수'로 잘못 발행된 미수금의 분쟁 리스크까지 경고합니다

> 전부 **홈택스 화면을 최종 근거**로 삼고, **제출·발급·납부 버튼은 반드시 본인이** 누르는 구조라 안심하고 쓸 수 있습니다.

## 설치 (1분)

### Claude Code — 마켓플레이스 (권장)

Claude Code에서는 마켓플레이스로 한 번에 설치하고 자동 업데이트를 받을 수 있습니다:

```
/plugin marketplace add lbiz-partners/hometax-doum
/plugin install hometax-doum@lbiz-partners
```

설치하면 6종 스킬이 함께 들어옵니다. 저장소가 갱신되면 `/plugin marketplace update lbiz-partners`로 새로 고칩니다.

### 그 외 도구 — 수동 복사

이 저장소를 다운로드(`Code → Download ZIP` 또는 `git clone`)한 뒤, 쓰는 도구의 스킬 폴더에 복사:

```bash
cp -R skills/* ~/.claude/skills/          # Claude Code
cp -R skills/* ~/.codex/skills/           # Codex
cp -R skills/* ~/.aside/u/0/skills/user/  # Aside
```

Claude Desktop 앱은 각 스킬 폴더를 zip으로 압축해 설정 → Skills에 업로드하면 됩니다.

> 참고: 이 저장소 **폴더 자체를 Claude Code의 작업 폴더로 열면** 개발용 검증 훅(`.claude/`)이 활성화됩니다. 스킬을 **사용**하는 데는 필요 없는 장치이니, 위처럼 `skills/`만 복사해 쓰세요. (스킬을 직접 수정·기여하려는 경우에만 해당 — `CLAUDE.md` 참조)

설치 확인: 새 대화에서 **"세무 도와줘"** → 안내가 나오면 성공.

> 팁 (Codex·Aside 등 다른 도구): 스킬이 많이 설치된 환경에서는 범용 문구가 다른 스킬로 갈 수 있습니다. **"홈택스 스킬로 부가세 신고 도와줘"**, **"tax-invoice-hometax 스킬로 미수금 점검해줘"** 처럼 스킬을 특정하면 확실하게 발동합니다.

## 안전 규칙 (모든 스킬에 내장)

1. 홈택스 로그인·인증서·OTP는 **본인만** 입력 — AI에게 비밀번호를 주지 않습니다
2. **최종 제출·발급 버튼은 반드시 본인이** — AI는 "이 내용으로 진행해도 될까요?" 확인까지만
3. 홈택스에 없는 숫자를 창작하지 않음, 공제/불공제는 단정 대신 "후보 + 확인 질문"
4. 주민번호·계좌 등 식별정보는 마스킹·최소 입력
5. 문제가 있으면 제출 권유 자체를 차단

## 🏢 소규모 법인사업자(1인 대표·스타트업)도 씁니다

**"법인인데 써도 되나요?"** — 네. **부가세와 전자세금계산서는 개인·법인이 같은 규칙**을 씁니다. 홈택스 화면도 같습니다. 1인 대표나 초기 스타트업처럼 **사장이 직접 실무를 보는 법인**이라면 무료 6종이 그대로 맞습니다.

### 그대로 쓰는 것 (로직 동일)

| 스킬 | 법인에서 달라지는 점 |
|---|---|
| `tax-invoice-hometax` 발행·수정·조회 | 없음. 오히려 **법인은 금액과 무관하게 전원 전자 의무발급**(「부가가치세법」 §32②)이라 개인보다 더 자주 씁니다 |
| `tax-invoice-hometax` 미수금 점검 | 없음. 청구 발행분 ↔ 통장 입금 대조는 사업자 형태와 무관 |
| `vat-hometax` 부가세 신고 | 신고 **횟수**만 다름(아래 표) — 매출·매입 대조와 화면 순서는 동일 |
| `receipt-classify-kr` 영수증·카드 분류 | 없음. 법인카드 내역도 같은 방식으로 공제/불공제 후보를 분류 |
| `tax-prep-kr` 신고 준비 | 없음 |

### 법인이라서 다른 것

| | 개인사업자 | 법인사업자 |
|---|---|---|
| 부가세 과세유형 | 간이 또는 일반 | **항상 일반과세** (간이과세는 개인만 — §61①) |
| 부가세 신고 횟수 | 확정신고 2회 + 예정고지 | 원칙 **4회**(예정신고 2 + 확정 2). 단 **직전 과세기간 공급가액 1억 5천만원 미만**이면 예정고지로 바뀌어 **개인과 같은 연 2회 신고** (§48③, 시행령 §90④) |
| 전자세금계산서 | 직전연도 공급가액 8천만원 이상만 의무 | **전원 의무** (§32②) |
| 부가세 전자신고 세액공제 | 5,000원 | **5,000원 동일** (조특법 §104조의8②) |
| 전자세금계산서 발급세액공제 | 건당 200원·연 100만원 한도 | **해당 없음** — 조문이 "개인사업자"로 한정 (§47①) |
| 소득에 대한 신고 | 종합소득세 (5월) | **법인세** (사업연도 종료 후 3개월) — **이 스킬 범위 밖** |

> 💡 여기서 말하는 **"소규모 법인사업자"는 세법 용어**입니다. 직전 과세기간(6개월) 공급가액이 **1억 5천만원 미만**인 법인은 예정신고 의무가 없고 **4월·10월에 고지서만 받습니다**(고지할 세액이 50만원 미만이면 고지조차 나오지 않습니다). 초기 스타트업 법인 대부분이 여기에 해당해서, 실제로 신고서를 쓰는 건 **1월·7월 두 번**으로 개인과 같습니다.

### 법인은 이 범위까지는 안 됩니다 (세무사·회계 영역)

- **법인세 신고·결산·재무제표** — 재무상태표·손익계산서 작성, 세무조정은 무료 6종도 Pro도 다루지 않습니다. 이름이 비슷해도 `income-tax-hometax`는 **종합소득세** 스킬이니 법인세에 쓰지 마세요
- **법인 특유의 판단** — 대표자 가지급금과 인정이자, 법인카드 사적 사용(업무무관 지출은 대표자 상여로 처분될 수 있습니다), 기업업무추진비 한도
- 법인 대표 **개인**의 종합소득세는 급여 외 소득(임대·배당·프리랜서 등)이 있을 때만 `income-tax-hometax`가 의미 있습니다

### 1인 대표 법인이 가장 먼저 막히는 곳

직원이 0명이어도, **대표 본인에게 급여를 지급하면 원천징수 의무**가 생깁니다. 매월(또는 반기) 원천징수이행상황신고서, 연말 지급명세서까지 따라옵니다. 놓치면 가산세입니다. 이 부분은 Pro의 `withholding-tax-hometax` 엔진이 계산과 기한 점검까지 맡습니다.

## 🔒 Pro — 직접 "계산"까지 해주는 엔진 2종 (별매)

무료 모음은 **홈택스 화면 안내자**입니다(위 6종으로 충분히 신고·발급 가능). Pro는 여기에 **숫자를 코드로 직접 계산하는 엔진 2종**을 더합니다 — 이 둘은 **세금 종류가 서로 다릅니다.**

### ① 종소세 예상세액 엔진 · `jongsose-prep-kr` — "**내** 세금 얼마 나올까?"

내가 내는 **내 종합소득세**를 미리 계산합니다.

- 5월을 기다리지 않고 **연중 아무 때나** 예상세액 계산 (2026 정부 원문 검증 세율, 코드가 계산)
- **겸업**(직장+3.3% 부업) 합산 — 근로소득공제·세액공제 자동 반영
- 분납 가능 여부, 성실신고 대상 판정, 기한후 가산세 감면율
- **미리채움 교차검증** — 홈택스 숫자를 독립 계산으로 검산해 매출 누락·이중계상을 제출 전에 적발
- 홈택스 입력표 + PDF 보고서

> 무료의 `income-tax-hometax`가 "**5월에 화면에서 신고**"까지라면, 이 엔진은 "**그 전에 얼마 나올지 계산**"까지입니다.

### ② 원천세(인건비) 신고·계산 엔진 · `withholding-tax-hometax` — "직원 급여에서 **얼마 떼지?**"

**직원·일용직·프리랜서에게 인건비를 지급하는 사장**을 위한, 완전히 다른 세금(원천세)입니다. **1인 법인 대표가 본인 급여를 가져가는 경우도 포함**됩니다.

- 월급·부양가족을 넣으면 **국세청 근로소득 간이세액표로 원천징수액 자동 계산**(자녀공제 반영)
- 일용직 6%, 프리랜서 3.3%, 기타소득(강연료 등)까지 코드 계산
- **원천징수이행상황신고서**(매월/반기) 작성 보조 + 급여대장 ↔ 홈택스 대조
- **지급명세서·간이지급명세서** 기한 점검(놓치면 가산세), 반기납부 자격 확인
- 홈택스·급여프로그램 없이도 "월급 250만·부양2 → 원천징수 얼마"가 바로 나옴

`tax-invoice-hometax`에 **미수금 점검 모드**가 새로 생겼습니다. "미수금 확인해줘" 한마디로 시작합니다.

- **청구 발행 건 ↔ 통장 입금내역 대조** — 홈택스에서 내려받은 매출 세금계산서 발급 목록과, 은행에서 다운로드한 **입금내역(엑셀/CSV)을 올리면 건별로 자동 추적·대조**합니다. 입금내역이 없으면 건별 질문 방식으로도 진행됩니다.
- **못 받은 돈이 조용히 사라지지 않게** — 입금 1건은 계산서 1건에만 배정(소진 규칙), 부분입금·합산입금·선금·카드/PG 정산처럼 애매한 건은 임의 확정 대신 **"판단불가"로 내려 사장님께 확인**합니다. 대조 전후로 정합성 게이트 2중 검증(총건수=영수+청구, 입금완료+미입금+판단불가=청구 건수)을 통과해야 결과를 보고합니다 — **건이 누락되면 보고 자체가 막히는 구조**입니다.
- **다음 할 일까지** — 결제기일 기준 경과일수별 단계 경고(정상 → ⚠️독촉 → 🔶내용증명 검토 → 🔴지급명령·소멸시효 주의). `영수`로 발행했는데 입금 흔적이 없는 건도 역점검해 분쟁 리스크를 경고합니다.
- **세무 함정 3고지** — 미입금이어도 부가세 매출 신고는 전액 대상(빼면 매출 누락), 대손세액공제는 법적 대손 확정 시에만, 이 점검은 수금 관리용(신고 내용 불변)임을 시작 전에 안내합니다.
- 발행 흐름도 개선: **기존 거래처는 질문 5개 패스트트랙**, 신규 거래처는 필수 7가지만. 출시 전 독립 적대적 리뷰로 CRITICAL 1건·HIGH 4건 포함 13건을 수정한 뒤 공개했습니다.

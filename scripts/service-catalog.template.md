# 개인사업자 업무 찾기

안내가 필요한 업무만 찾아 해당 문서와 절을 읽는다. 무료에서도 24개 업무의 자료 준비·기본 진행·결과 확인을 제공한다. Pro 도구명은 해당 파일이 실제 설치된 경우에만 사용할 수 있다.

PC·손택스·인증 수준에 따른 실제 메뉴와 적용기간은 실행 시 확인한다. 이 목록은 24개 업무 묶음이며 모든 세목의 자동 계산이나 실화면 검증을 의미하지 않는다.

[실제 홈택스 검증 기록](live-ui-verification.md)에서 24개 대표 경로의 로그인 요구·공개 화면·조회 결과와 추가 모의계산 대조 사례를 확인한다. 업무 전체 완료 검증과 부분 화면 검증은 별개다.

공통: 인증과 최종 제출·신청·발급·납부는 본인이 진행한다. 확인한 원문 없이 완료를 기록하지 않는다. 양도·상속·법인세·국제·특수세목, 성실신고·불복·조사는 준비·전문가 인계 범위를 유지한다.

계산 지원: 종소세·원천징수는 설치된 전용 엔진의 지원연도·유형에 한한다. Pro 대조 도구는 합계·입력값·문서 조건을 비교하며 세법상 적용 가능성·승인·환급 확정을 판정하지 않는다.

[업종별 준비표](../../tax-prep-kr/references/industry-guide.md)의 계산은 Pro 탐지 시 [Pro 연동](pro-integration.md)에서 선택한다. 계산 지원과 실제 홈택스 화면·접수 검증은 서로 다른 상태다.

Pro 도구가 탐지된 경우 업무별로 더하는 작업은 [Pro 연동](pro-integration.md)에 있다.

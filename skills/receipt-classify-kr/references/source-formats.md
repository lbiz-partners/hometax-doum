# 입력 자료 실측 포맷

## 실측 기록 절차

1. 사용자에게 계좌·카드번호·주민번호를 가린 파일을 요청한다. 대조에는 일자·가맹점·금액·증빙 구분만 있으면 된다.
2. 파일을 열어 **헤더 행 번호, 컬럼 수, 컬럼명 원문, 합계 행 유무, 건수**를 확인한다. 화면 목록의 총 건수와 파일 행 수가 맞는지 대조한다.
3. 확인한 구조를 위 표의 형식으로 사용자에게 보여 주고 분류를 시작한다. 파일마다 구조가 다르면 파일별로 기록한다.
4. 취소·환불 행은 원거래와 연결한다(`원거래연결` 컬럼). 음수 행을 새 경비로 만들지 않는다.
5. 표준 출력 열은 [분류 결과 템플릿](../assets/classification-template.csv)을 따른다. Pro 대조 도구로 넘길 때도 같은 열을 쓴다.

## 실측 갱신

홈택스 화면·파일 구조는 바뀔 수 있다. 실측일이 6개월을 넘었거나 화면 안내가 다르면 다시 확인한다. 실측 결과는 이 문서에 실측일과 함께 추가한다. 실측하지 않은 값을 실측한 것처럼 적지 않는다.

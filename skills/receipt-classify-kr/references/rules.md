# 분류 규칙 (1차 스크리닝)

법령 해석 확정이 아니다. 실무 1차 분류용.

## 증빙 등급

| 등급 | 예시 | 메모 |
| --- | --- | --- |
| A | 전자세금계산서 | 최우선 |
| B | 신용카드/직불 매출전표, 지출증빙 현금영수증 (부가세 별도 구분) | 매입세액 후보 가능 |
| C | 계산서(면세) | 부가세 없음, 종소세 경비 후보 |
| D | 간이영수증, 이체확인만 | 증빙 취약 |
| E | 없음 | 위험 |

## 부가세 매입세액

### 공제 후보 기본
- 사업 관련 + 과세사업 사용 + A/B 증빙 + 공제 가능 공급자

### 불공제 후보 (자주)
- 기업업무추진비(접대): 특정 거래처 식사·선물·골프 등
- 비영업용 소형승용차 구입·렌트·유류·정비·주차
- 사업 무관·가사
- 면세사업 관련 매입, 토지 관련
- 세금계산서 미수취·부실
- 해외 사용
- 여객운임(항공·철도·고속버스·택시 등) — 예외 가능 항목은 확인필요
- 인건비(급여) — 매입세액 개념 아님
- 간이·면세 공급자 거래 등 홈택스 당연불공제

### 혼동
| 내용 | 부가세 |
| --- | --- |
| 직원 회식 | 공제 후보(복리후생, 사업관련 전제) |
| 거래처 1~2명 식사 | 불공제 후보(접대) |
| 불특정 다수 판촉 | 공제 후보(광고 성격) 확인 |
| 경차/화물 주유 | 공제 후보 확인 |
| 승용 주유 | 불공제 후보 |

## 종소세 필요경비

### 필요경비 후보
- 사업 매입, 외주, 임차, 인건비, 통신, SW, 광고, 소모품, 수선, 업무교육 등

### 제외·주의 후보
- 가사·개인
- 업무무관
- 벌금·과태료성
- 자본적 지출 전액 비용 처리 의심
- 증빙 부실 고액

### 부가세와 다른 예
| 항목 | 부가세 | 종소세 |
| --- | --- | --- |
| 접대 식사 | 불공제 후보 | 경비 한도·요건 검토 (확인필요) |
| 급여 | 해당없음 | 필요경비 후보 |
| 비영업 승용 유류 | 불공제 후보 | 별도 업무사용 이슈 가능 |

## 키워드 힌트 (확정 아님)

- 접대 후보: 골프, 주점, 유흥, 선물세트 + 거래처명
- 차량 후보: 주유, 충전, 하이패스, 정비, 주차, 렌터카
- 통신: KT, SKT, LG U+, 인터넷
- 광고: 메타, 구글, 네이버 광고
- 클라우드: AWS, Azure, 국내 SaaS

키워드만으로 최종 확정하지 말 것.

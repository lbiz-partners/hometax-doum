# 추천 계정 목록 (범용)

업종에 따라 이름을 바꿔도 된다. 목표는 **섞이지 않게 분리**.

## 매출
- 서비스매출 / 상품매출 / 기타매출

## 매입·비용 (일반)
- 상품매입 / 외주비 / 지급수수료
- 임차료 / 관리비
- 인건비 / 복리후생비
- 통신비 / 전기가스수도
- 소모품비 / 사무용품비
- 수선비 / 보험료
- 광고선전비 / 교육훈련비
- 여비교통비-숙박 / 여비교통비-운임 (분리 권장)
- 소프트웨어/구독료

## 주의 계정 (분리 유지)
- 기업업무추진비(접대비)
- 차량유지비-비영업승용
- 차량유지비-영업/경차화물
- 가사성비용
- 상품권/기프트카드
- 해외결제
- 잡비 ← 최소화. 가능하면 분해

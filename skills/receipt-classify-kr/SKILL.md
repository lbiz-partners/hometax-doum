# 영수증·지출 분류 (receipt-classify-kr)

카드 내역, 현금영수증, 종이 영수증, 간단한 지출 리스트를  
**부가세 관점**과 **종합소득세 관점**으로 나눠 분류한다.

특정 업종 전용 룰에 가두지 않는다. 애매하면 확인 질문.

신고 제출은 하지 않는다. 결과표가 나오면:
- 부가세 → `vat-hometax`
- 종소세 → `income-tax-hometax`

## 절대 규칙

1. 공제/경비 여부를 **확정 판결하지 않는다.** `후보`로 표기.
2. 부가세 매입세액 ≠ 종소세 필요경비. 항상 두 컬럼을 분리.
3. 증빙 없으면 `증빙부족` 플래그.
4. 가사성·업무무관 의심 시 사용자 확인.
5. **주민번호·계좌·사업자번호 등 식별정보는 마스킹**하고 파일/폴더로 관리, 채팅 입력 최소화.
6. 보고 말미 표준 면책(아래 「집계 보고 포맷」 하단 문구).

## 사업 정보 재사용

<!-- block:reuse-profile -->
허브 또는 사용자 지정 로컬 가명 프로필이 있으면 사업 가명·기간·과세유형·확인일을 먼저 대조하고 변경점·누락만 묻는다. 직원 없음과 외주 지급 없음은 별개이며, 미확인·미수집을 false·0원으로 채우지 않는다. 프로필이 없거나 이 스킬만 설치되어 있어도 필요한 항목만 직접 확인해 진행한다. 원본 식별정보·인증정보를 공통 프로필에 저장하지 않는다.

## 입력

다음 중 하나 이상:
- 엑셀/CSV 카드 내역
- 지출 목록 텍스트
- 영수증 이미지(가능하면 OCR/읽기 후 표로)
- 폴더 경로 (사용자가 지정)

인터뷰:
```text
- 기간
- 업종(대략)
- 목적: 부가세 / 종소세 / 둘 다
- 사업용카드 등록 여부
- 신고자 과세유형, 공급자의 거래 당시 과세유형·세금계산서 발급자격(모르면 확인필요)
```

## 월말 카드·증빙 검토

[중복·취소·업무 관련성 검토](references/monthly-evidence-review.md)를 읽고 등록카드/미등록 사업 사용분, 개인 지출, 부분환불, 중복 세금계산서를 구분한다. 사업용카드 등록만으로 자동 공제하지 않는다. 같은 가맹점이라도 업무 목적 확인을 다른 거래에 자동 승계하지 않는다. 무료는 행별 검토표, Pro jongsose-prep-kr 설치 시 월마감 대량 대조로 이어간다. Pro 산술검증이 공제·필요경비 판단을 대신하지 않는다.

## 작업 절차

1. 원본 파싱 (날짜·가맹점·금액)
2. 기간 필터
3. 동일 거래 중복증빙·취소/환불을 연결한 뒤 행별 규칙 적용 (rules.md)
4. 모호 건 `확인필요` 묶음
5. 집계표 작성
6. 사용자 확인 질문 목록
7. 확인 후 최종 분류표 저장 권고: `artifacts/` 또는 사용자 폴더

## 빠른 판정 트리

```text
증빙이 세금계산서/카드/현금영수증인가?
  N → 증빙부족 + 소액/예외 여부 확인
  Y → 사업 관련인가?
        N → 부가세 불공제·종소세 제외 후보
        Y → 접대(특정인 접대)인가?
              Y → 부가세 불공제 후보 / 종소세는 기업업무추진비 한도 이슈 가능
              N → 비영업 소형승용 관련인가?
                    Y → 부가세 불공제 후보
                    N → 거래 당시 공급자 자격·세액 구분·중복증빙 확인
                          미확인 → 확인필요
                          요건 충족 → 공제·필요경비 후보 (세부 계정 부여)
```

## 배치 팁

- 같은 가맹점 반복은 규칙을 한 번 정해 일괄 적용
- `스타벅스` 등이라도 거래처 미팅 vs 개인 음료는 다를 수 있음 → 패턴만으로 단정 금지
- 3만원 초과 사업자 거래 + 간이영수증만 있으면 적격증빙 이슈 고지

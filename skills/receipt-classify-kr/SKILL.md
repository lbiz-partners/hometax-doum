# 영수증·지출 분류 (receipt-classify-kr)

카드 내역, 현금영수증, 종이 영수증, 간단한 지출 리스트를  
**부가세 관점**과 **종합소득세 관점**으로 나눠 분류한다.

특정 업종 전용 룰에 가두지 않는다. 애매하면 확인 질문.

신고 제출은 하지 않는다. 결과표가 나오면:
- 부가세 → `vat-hometax`
- 종소세 → `income-tax-hometax`

## 절대 규칙

1. 공제/경비 여부를 **확정 판결하지 않는다.** `후보`로 표기.
2. 부가세 매입세액 ≠ 종소세 필요경비. 항상 두 컬럼을 분리.
3. 증빙 없으면 `증빙부족` 플래그.
4. 가사성·업무무관 의심 시 사용자 확인.
5. 보고 말미 면책.

## 입력

다음 중 하나 이상:
- 엑셀/CSV 카드 내역
- 지출 목록 텍스트
- 영수증 이미지(가능하면 OCR/읽기 후 표로)
- 폴더 경로 (사용자가 지정)

인터뷰:
```text
- 기간
- 업종(대략)
- 목적: 부가세 / 종소세 / 둘 다
- 사업용카드 등록 여부
```

## 출력 컬럼 (표준)

| 컬럼 | 설명 |
| --- | --- |
| 거래일 | |
| 거래처 | |
| 적요 | 원문 |
| 금액_합계 | 결제 총액 |
| 공급가액 | 알면 |
| 부가세 | 알면 |
| 증빙 | 세금계산서/카드/현금영수증/영수증/없음 |
| 제안계정 | |
| 부가세판정 | 공제후보/불공제후보/해당없음/확인필요 |
| 종소세판정 | 필요경비후보/제외후보/확인필요 |
| 사유 | 한 줄 |
| 사용자확인 | Y/N |

상세 규칙: `references/rules.md`  
계정 예시: `references/accounts.md`

## 작업 절차

1. 원본 파싱 (날짜·가맹점·금액)
2. 기간 필터
3. 행별 규칙 적용 (rules.md)
4. 모호 건 `확인필요` 묶음
5. 집계표 작성
6. 사용자 확인 질문 목록
7. 확인 후 최종 분류표 저장 권고: `artifacts/` 또는 사용자 폴더

## 빠른 판정 트리

```text
증빙이 세금계산서/카드/현금영수증인가?
  N → 증빙부족 + 소액/예외 여부 확인
  Y → 사업 관련인가?
        N → 부가세 불공제·종소세 제외 후보
        Y → 접대(특정인 접대)인가?
              Y → 부가세 불공제 후보 / 종소세는 기업업무추진비 한도 이슈 가능
              N → 비영업 소형승용 관련인가?
                    Y → 부가세 불공제 후보
                    N → 공제·필요경비 후보 (세부 계정 부여)
```

## 집계 보고 포맷

```text
## 지출 분류 결과 ({기간})

- 부가세 불공제후보 세액
- 종소세 필요경비후보 금액
- 확인필요 n건

### 계정별
| 계정 | 금액 | 부가세 | 종소세 |

### 확인 필요 TOP
1. ...

### 다음
- 부가세 신고: vat-hometax
- 종소세 신고: income-tax-hometax
- 미비 증빙 수집: tax-prep-kr

참고용 정리이며 세무 자문이 아닙니다. 제출 전 수치를 직접 확인해 주세요.
```

## 배치 팁

- 같은 가맹점 반복은 규칙을 한 번 정해 일괄 적용
- `스타벅스` 등이라도 거래처 미팅 vs 개인 음료는 다를 수 있음 → 패턴만으로 단정 금지
- 3만원 초과 사업자 거래 + 간이영수증만 있으면 적격증빙 이슈 고지

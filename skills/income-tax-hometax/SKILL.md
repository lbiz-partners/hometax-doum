# 종합소득세 홈택스 신고 (income-tax-hometax)

홈택스에서 **종합소득세 신고를 제출 직전까지** 준비·점검하는 범용 스킬.  
특정 개인/회사 전용이 아니다.

연관:
- `tax-prep-kr` 준비
- `receipt-classify-kr` 경비 분류
- `vat-hometax` 부가세 (수입·증빙 교차 가능)
- `hometax-tax-hub` 진입점
- `jongsose-prep-kr` 예상세액 계산 엔진 (Pro, 설치 시 교차검증 파트너)

상세:
- `references/filing-types.md`
- `references/checklist-and-excel.md`
- `references/tax-policy.md` — 전자신고 공제 적용일·기한후신고 근거 (2026-09-12 확인)

## 절대 규칙

1. **자동 제출·납부·지방소득세 제출 금지.** 매번 확인.
2. 비밀번호·인증서·OTP·간편인증 직접 입력 금지
3. 없는 경비·공제 창작 금지
4. 신고유형 선택은 비교 후 사용자 확인
5. 해당 귀속연도·신고일의 법령과 홈택스 화면을 함께 확인. 화면과 근거가 충돌하면 미해결 차이로 남기고 제출 준비 완료로 표시하지 않는다.
6. **주민번호·계좌·사업자번호 등 식별정보는 마스킹**하고 파일/폴더로 관리, 채팅 입력 최소화.
7. 보고 말미 표준 면책(아래 「보고 포맷」 하단 문구)

## 사업 정보 재사용

허브 또는 사용자 지정 로컬 가명 프로필이 있으면 사업 가명·기간·과세유형·확인일을 먼저 대조하고 변경점·누락만 묻는다. 직원 없음과 외주 지급 없음은 별개이며, 미확인·미수집을 false·0원으로 채우지 않는다. 프로필이 없거나 이 스킬만 설치되어 있어도 필요한 항목만 직접 확인해 진행한다. 원본 식별정보·인증정보를 공통 프로필에 저장하지 않는다.

## 시작 인터뷰

```text
- 귀속연도
- 실제 또는 예정 신고일 (전자신고 공제 적용일 판정용)
- 신고 구분: 정기 / 기한후 / 수정 / 경정청구
- 소득: 사업 / 근로 / 기타 / 혼합 / 모름
- 안내유형(알면): 모두채움, 경비율, 간편장부 등
- 자료: 홈택스 / 엑셀 경비 / 원천징수
- 목표: 조회 / 유형 비교 / 제출 직전
```

자료 부족 시 `tax-prep-kr`, 경비 미분류 시 `receipt-classify-kr`.

**핸드오프 수신**: `jongsose-prep-kr`에서 넘어온 경우 전달받은 귀속연도·소득·기납부·홈택스_입력표를 그대로 쓰고 **위 인터뷰를 반복하지 않는다.** 반대로 "예상세액 얼마 나와?" 류 **계산 요청**이 먼저 오면(설치 시) `jongsose-prep-kr`로 넘긴다 — 이 스킬은 세액을 계산하지 않는다.

## 모두채움 짧은 경로와 신고 후 확인

[모두채움·신고 후 확인](references/simple-route-and-aftercare.md)을 따른다. 안내 대상이고 소득·공제·기납부에 미해결 차이가 없으면 B 자료조회 → F 제출 직전 QA로 단축한다. 모두채움은 자동 제출이나 소득 누락 없음의 보증이 아니다. 국세 접수·납부, 지방소득세 신고·납부, 환급 처리·입금을 각각 기록한다.

## 모드

A 대상파악 → B 자료조회 → C 엑셀대조 → D 유형비교 → E 작성보조 → X 교차검증(엔진 값 있으면) → F 제출직전QA

## 홈택스 절차

1. 로그인
2. **세금신고 → 종합소득세 신고**
3. 귀속연도 선택
4. 모두채움/단순경비율/일반 등 경로 선택 (화면 명칭은 연도별 상이)
5. 미리채움·지급명세·공제자료 확인
6. 숫자 snapshot 기록

### 우선 확인
- 사업수입, 근로, 기타, 금융·연금(기준 해당 시)
- 원천징수·기납부
- 추계/기장 입력란
- 인적·보험·의료·교육·기부·연금 등 공제
- 산출세액·환급/납부 · **전자신고 세액공제**: 납세자 직접 종합소득 확정신고는 **2026-02-27 이후 신고분 1만 원**, 그 전 신고분은 2만 원. §73에 따른 확정신고 예외자가 자발적으로 신고하면 추가 납부·환급 결정세액과 **5천 원** 중 적은 금액(개정 전 상한 1만 원). **귀속연도와 신고일을 혼동하지 않고**, 납부세액 한도·신고유형·화면 반영을 확인한다. 기한후·수정·경정청구에는 동일 공제를 새로 받는다고 가정하지 않는다. 근거·예시는 `references/tax-policy.md`.
- 지방소득세 연계 안내

## 기한후신고 (마감일이 지났을 때)

정기신고 기한(원칙 5/31, 성실신고확인서 제출자는 6/30)이 지난 경우에도 같은 흐름으로 진행하되, 아래만 다르다. 토요일·공휴일 순연과 개별 연장된 신고·납부기한을 먼저 확인한다.

- 경로: 세금신고 → 종합소득세 → **기한후신고** (귀속연도 선택. 메뉴 명칭은 연도별 상이)
- 가산세(무신고·납부지연) 입력·계산 명세를 따로 확인한다. 자동 반영 여부를 단정하지 말고 기장의무·수입금액·납부일·세무서 고지 여부를 대조한다.
- **자진 기한후신고 감면 후보**: 기한 후 1개월 이내 50% / 1개월 초과 3개월 이내 30% / 3개월 초과 6개월 이내 20%(국세기본법 §48). 과세관청이 결정할 것을 미리 알고 신고하는 경우 등 제외사유를 확인한다. 납부지연은 자진납부·고지 후 구간을 구분하며, 감면율을 납부지연가산세에도 적용하지 않는다.
- `jongsose-prep-kr`(Pro, 설치 시)는 보고서 기준일과 실제·예정 신고일을 구분해 예상세액과 기한 상태를 안내한다. **가산세·감면율은 계산 결과에 포함하지 않으므로**, 실제 신고·납부 사실과 홈택스 가산세 명세를 별도로 확인한다.
- **환급이라고 무신고가산세가 없다고 단정하지 않는다.** 복식부기의무자는 세액 기준과 수입금액 기준을 비교하므로 환급이어도 수입금액 기준 가산세가 남을 수 있다(국세기본법 §47의2②). 기장의무·수입금액·가산세 예외를 확인한다. 이미 신고한 건의 과다납부·과소환급은 경정청구 요건을 별도로 확인한다.

## X. 교차검증 (jongsose-prep-kr 결과가 있을 때)

엔진의 `홈택스_입력표`(총수입·필요경비·공제·산출·결정세액·기납부)와 홈택스 화면 snapshot을 **항목별 대조**해 차이표를 만든다.

| 차이 항목 | 원인 후보 |
| --- | --- |
| 총수입금액 | 미리채움 누락 매출 / 이중계상 / 엔진 입력 누락(장부 미반영 매출) |
| 필요경비 | 추계(경비율) vs 기장 차이 / 증빙 탈락분 |
| 소득·세액공제 | 자격 요건(근로자 전용 등) / 증빙 미제출 / 한도 적용 차이 |
| 산출·결정세액 | 신고유형 차이 / 타소득 합산분(금융·연금 등 — 엔진 미지원 영역) |
| 기납부 | 중간예납 고지 vs 실납부 / 원천징수 소득세분 환산(3.3% 중 3%p) |

규칙: ① 차이가 하나라도 있으면 **원인 확인 전 제출 권유 금지** ② 엔진은 예상치이며, 법령·신고서 입력 근거·홈택스 계산 명세로 차이를 해소 ③ 차이표를 최종 보고에 그대로 포함. 엔진의 미지원·확인필요·검산 미수행 상태를 통과로 바꾸지 않는다.

# 종합소득세 홈택스 신고 (income-tax-hometax)

홈택스에서 **종합소득세 신고를 제출 직전까지** 준비·점검하는 범용 스킬.  
특정 개인/회사 전용이 아니다.

연관:
- `tax-prep-kr` 준비
- `receipt-classify-kr` 경비 분류
- `vat-hometax` 부가세 (수입·증빙 교차 가능)
- `hometax-tax-hub` 진입점
- `jongsose-prep-kr` 예상세액 계산 엔진 (🔒 Pro 별매 — 설치 시 교차검증 파트너로 작동)

상세:
- `references/filing-types.md`
- `references/checklist-and-excel.md`

## 절대 규칙

1. **자동 제출·납부·지방소득세 제출 금지.** 매번 확인.
2. 비밀번호·인증서·OTP·간편인증 직접 입력 금지
3. 없는 경비·공제 창작 금지
4. 신고유형 선택은 비교 후 사용자 확인
5. 해당 귀속연도 홈택스 화면이 최종 근거
6. **주민번호·계좌·사업자번호 등 식별정보는 마스킹**하고 파일/폴더로 관리, 채팅 입력 최소화.
7. 보고 말미 표준 면책(아래 「보고 포맷」 하단 문구)

## 시작 인터뷰

```text
- 귀속연도
- 신고 구분: 정기 / 기한후 / 수정 / 경정청구
- 소득: 사업 / 근로 / 기타 / 혼합 / 모름
- 안내유형(알면): 모두채움, 경비율, 간편장부 등
- 자료: 홈택스 / 엑셀 경비 / 원천징수
- 목표: 조회 / 유형 비교 / 제출 직전
```

자료 부족 시 `tax-prep-kr`, 경비 미분류 시 `receipt-classify-kr`.

**핸드오프 수신**: `jongsose-prep-kr`에서 넘어온 경우 전달받은 귀속연도·소득·기납부·홈택스_입력표를 그대로 쓰고 **위 인터뷰를 반복하지 않는다.** 반대로 "예상세액 얼마 나와?" 류 **계산 요청**이 먼저 오면(설치 시) `jongsose-prep-kr`로 넘긴다 — 이 스킬은 세액을 계산하지 않는다. 엔진 미설치면 "예상세액 계산은 Pro 엔진(별매) 기능"이라고 안내하고 화면 진행을 계속한다.

## 홈택스 절차

1. 로그인
2. **세금신고 → 종합소득세 신고**
3. 귀속연도 선택
4. 모두채움/단순경비율/일반 등 경로 선택 (화면 명칭은 연도별 상이)
5. 미리채움·지급명세·공제자료 확인
6. 숫자 snapshot 기록

### 우선 확인
- 사업수입, 근로, 기타, 금융·연금(기준 해당 시)
- 원천징수·기납부
- 추계/기장 입력란
- 인적·보험·의료·교육·기부·연금 등 공제
- 산출세액·환급/납부 · **전자신고 세액공제**(홈택스 직접 전자신고 시 소액, 현행 2만 원 — 자동 반영 확인)
- 지방소득세 연계 안내

## 기한후신고 (마감일이 지났을 때)

정기신고 기한(5/31, 성실신고 6/30)이 지난 경우에도 같은 흐름으로 진행하되, 아래만 다르다.

- 경로: 세금신고 → 종합소득세 → **기한후신고** (귀속연도 선택. 메뉴 명칭은 연도별 상이)
- 가산세(무신고·납부지연)가 **자동 계산되어 붙는다** — 화면 값이 최종.
- **빠를수록 싸다**: 무신고 가산세는 기한 후 1개월 내 50% / 3개월 내 30% / 6개월 내 20% 감면(국세기본법 §48 — 해당 연도 기준 화면 확인), 납부지연 가산세는 일 단위로 계속 증가.
- `jongsose-prep-kr`(🔒 Pro 별매, 설치 시)로 먼저 계산하면 기한경과를 자동 감지해 **가산세 감면율 안내까지 포함**한 예상 부담을 미리 볼 수 있다.
- 환급이 나오는 기한후신고(기납부 > 결정세액)는 무신고 가산세 대상이 아니다 — 이미 신고한 건의 환급은 경정청구로 구분.

## X. 교차검증 (jongsose-prep-kr 결과가 있을 때)

엔진의 `홈택스_입력표`(총수입·필요경비·공제·산출·결정세액·기납부)와 홈택스 화면 snapshot을 **항목별 대조**해 차이표를 만든다.

| 차이 항목 | 원인 후보 |
| --- | --- |
| 총수입금액 | 미리채움 누락 매출 / 이중계상 / 엔진 입력 누락(장부 미반영 매출) |
| 필요경비 | 추계(경비율) vs 기장 차이 / 증빙 탈락분 |
| 소득·세액공제 | 자격 요건(근로자 전용 등) / 증빙 미제출 / 한도 적용 차이 |
| 산출·결정세액 | 신고유형 차이 / 타소득 합산분(금융·연금 등 — 엔진 미지원 영역) |
| 기납부 | 중간예납 고지 vs 실납부 / 원천징수 소득세분 환산(3.3% 중 3%p) |

규칙: ① 차이가 하나라도 있으면 **원인 확인 전 제출 권유 금지** ② 최종 근거는 홈택스 화면 값(엔진은 예상치) ③ 차이표를 최종 보고에 그대로 포함.

## 엑셀·경비

부가세 공제 여부와 **별개**로 필요경비 판단.  
`receipt-classify-kr` 결과 재사용 가능.

| 차이 | 조치 |
| --- | --- |
| 홈택스 수입 > 엑셀 | 엑셀 누락 가능 |
| 엑셀 수입 > 홈택스 | 미반영 매출·지급명세 가능 |
| 경비만 엑셀 | 증빙·관련성 확인 후 기장 경로 검토 |

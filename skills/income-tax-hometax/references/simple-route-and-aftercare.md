# 모두채움 짧은 경로와 신고 후 확인

## 모두채움 안내를 받은 경우

1. 귀속연도·신고유형·기존 신고 여부와 실제 안내 대상을 확인한다. 작은 매출 또는 3.3% 원천징수만으로 모두채움·단순경비율 자격을 가정하지 않는다.
2. 안내된 사업·근로·기타 등 소득, 원천징수·기납부, 인적공제와 자격을 실제 자료와 대조한다. 다른 플랫폼·현금·부업 소득, 중도퇴사/복수 근무지가 빠졌는지 확인한다.
3. 미해결 차이가 없고 사용자가 안내유형을 확인하면 자료조회 → 제출 직전 QA로 단축한다. 엑셀 새 장부·Pro 계산기·유형 비교를 불필요하게 강요하지 않는다. 차이·혼합소득·장부 선택 문제가 있으면 일반 흐름으로 확장한다.
4. 전자신고 공제·귀속연도/신고일 구분을 기존 tax-policy.md대로 확인한다. 제출·인증은 사용자다.

[국세청 모두채움 안내](https://s.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=238978&mi=40483)는 합산 대상 소득 확인을 요구한다(2026-09-12 확인). 미리채움은 제출완료나 소득 누락 없음의 보증이 아니다.

## 사용자가 신고를 마쳤다고 하면

| 사실 | 확인 근거 |
| --- | --- |
| 국세 접수 | 해당 귀속·유형의 접수증·번호·일시 |
| 국세 납부 | 국세 납부결과·금액·일자, 분납 잔액 |
| 지방소득세 신고 | 위택스 연계 접수결과 또는 해당자의 적법한 신고 간주 사실 |
| 지방소득세 납부 | 지방 납부결과·금액·일자 |
| 환급 | 국세/지방 각각 예상액·공식 처리·실제 입금 |

국세 신고만으로 지방 신고·납부 완료라고 하지 않는다. 모두채움 지방세액에 변동이 없는 경우 등 간주신고 특례는 해당 연도 공식 안내와 실제 납부 사실을 확인하고 적용한다. [국세청 신고·납부방법](https://g.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=238910&mi=40296), [행정안전부 2026년 안내](https://www.youtube.com/watch?v=KtLeMKxPTIE)(확인일 2026-09-12).

납부서 발급은 납부 증거가 아니며 환급신고 접수는 입금 증거가 아니다. 파일을 실제 열어 귀속·세목을 대조하고 사용자 지정 폴더에 보관한다. 미확인, 해당없음(사유 포함), 사용자 진술, 증빙 확인을 구별한다. Pro 엔진 예상세액·납부준비금으로 신고 후 상태를 자동 완료 처리하지 않는다.

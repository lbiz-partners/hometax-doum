# 종합소득세 신고유형 (범용)

홈택스 안내유형을 먼저 읽는다.

| 경로 | 특징 |
| --- | --- |
| 모두채움 | 확인 후 제출에 가까움. 누락 소득/공제 재점검 |
| 단순경비율 | 소규모·신규 등. 수입×단순경비율 |
| 기준경비율 | 기타경비 추계 + 주요경비(매입·임차·인건비) |
| 간편장부 | 실제 수입·경비 기장 |
| 복식 | 의무자 또는 선택. 복잡 시 전문가 |

## 선택 감각
- 실제 경비 적고 자료 없음 → 추계/모두채움 검토
- 실제 경비 많고 증빙 있음 → 기장 검토
- 기준경비율만 쓰면 소득 과다 보이면 주요경비·기장 검토
- 무기장 가산세 가능성은 해당 연도 기준으로 고지

## 모두채움 주의
투잡, 중도퇴사, 3.3% 지급명세, 플랫폼 소득, 공제 미반영을 재확인.

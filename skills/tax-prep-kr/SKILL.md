# 세무 신고 준비 (tax-prep-kr)

부가세·종합소득세 신고 **전에** 자료를 빠짐없이 모으고 정리하는 범용 준비 스킬.  
특정 회사 전용이 아니다. 사용자 상황을 물어 체크리스트를 맞춤 출력한다.

부가세·종소세 제출 화면 작업은 `vat-hometax` / `income-tax-hometax`로 넘긴다. 면세 사업장현황신고는 이 스킬의 [전용 안내](references/exempt-status-report.md)로 진행한다.
영수증 분류 세부는 `receipt-classify-kr`로 넘긴다.  
종소세 **예상세액·분납·성실신고 판정**을 미리 보고 싶으면 `jongsose-prep-kr`(설치 시) — 준비 단계에서 납부 규모를 가늠하고 자료 우선순위를 정할 수 있다.

## 절대 규칙

1. 개인 민감정보(전체 주민번호·계좌)를 채팅에 붙여 넣게 하지 않는다. 파일/폴더로 관리 안내.
2. “이 자료면 세금 0원” 같은 약속 금지.
3. 기한·기준금액은 변동 가능 → **해당 연도 국세청/홈택스 안내** 재확인 문구 포함.
4. 보고 말미 표준 면책:  
   `본 도구는 신고 준비를 돕는 **소프트웨어**이며, 「세무사법」 제2조의 세무대리(신고 대리·세무조정계산서 등 서류 작성·장부작성 대행·조세 상담/자문·성실신고 확인)를 수행하지 않습니다. 제공자는 세무사가 아닐 수 있으며, 자격 유무와 무관하게 본 도구는 세무대리·유상 세무상담이 아닙니다(신고서 작성·제출을 대행하지 않음). 신고·납부의 최종 판단·책임은 이용자 본인에게 있고, 세무대리·상담이 필요하면 「세무사법」 제6조에 따라 등록한 세무사에게 위임하세요. 금액이 크거나 애매하거나 범위 밖(세무조사·법인세·성실신고 대행 등)이면 세무사 상담을 권합니다. 자세한 조건은 LICENSE.md 참조.`

## 사업 정보 재사용

실제 화면에서는 개인/사업자 상태와 추가 인증·설치·신고기간 제한을 확인한다. 조회 전 초기 값과 조회 후 결과, 작성 화면과 실제 접수·발급·납부를 구별한다. 빈 결과는 선택한 기간·자료원 안에서만 해석한다.

허브 또는 사용자 지정 로컬 가명 프로필이 있으면 사업 가명·기간·과세유형·확인일을 먼저 대조하고 변경점·누락만 묻는다. 직원 없음과 외주 지급 없음은 별개이며, 미확인·미수집을 false·0원으로 채우지 않는다. 프로필이 없거나 이 스킬만 설치되어 있어도 필요한 항목만 직접 확인해 진행한다. 원본 식별정보·인증정보를 공통 프로필에 저장하지 않는다.

## 시작 인터뷰

```text
1. 준비 대상: 이번 달 할 일 / 부가세 / 종합소득세 / 면세 사업장현황 / 국세증명·조회
2. 기간: (부가세) 몇 년 몇 기·예정/확정  (종소세) 귀속연도
   공통: 실제/예정 신고일, 정기/기한후/수정/경정청구 구분, 신고·납부기한 연장 여부
3. 형태: 일반과세 / 간이 / 면세 / 겸영 / 프리랜서 / 근로+부업 / 모름
   직원 여부와 별개로 외주·강사료·일용 지급 여부
4. 이미 있는 것: 홈택스 로그인 가능? 엑셀? 카드 내역? 세금계산서?
```

## 1인사업자 반복 업무

- 이번 달 할 일·납부준비금: [월별 체크리스트](references/monthly-owner-checklist.md). 과세유형·지급내역에 해당하는 일만 고르고 기한의 공식 URL·확인일을 남긴다.
- 면세사업자: [사업장현황신고 준비](references/exempt-status-report.md). 학원·주택임대·인적용역·기타 면세의 준비 항목과 빈 양식을 제공하며 제외·간주신고와 종소세를 구별한다. Pro 설치 시 jongsose-prep-kr의 사업장현황 연간 집계·대조로 연결한다.
- 소득금액증명·납세증명·과세표준증명, 환급금·세금포인트: [국세 서비스](references/owner-services.md). 무료에서 안내 가능하며 사용자 인증·발급 결과 확인을 구분한다.
- Pro jongsose-prep-kr 설치 시 프로필/체크리스트/신고상태 검증과 대량 월마감으로 연결한다. 미설치면 수동 자료표·현재 화면 대조를 계속한다.

## 업무별 진행 안내

요청에 해당하는 문서 하나부터 읽는다. 무료에서도 자료 준비와 본인 처리 후 결과 확인까지 이어간다.

- 개업·사업장 설정·사업자등록 정정·휴폐업·계좌/카드: [사업 생애주기](references/business-lifecycle.md).
- 직원 없는 외주 지급·원천세·지급명세서·직원 연말정산: [인건비 기본 안내](references/payroll-basic.md).
- 국세증명·전자고지·납부·환급·장려금·세금포인트: [증명과 납부](references/documents-and-payments.md).
- 기한후·수정·경정청구·기한연장·소명·대리인 관리: [정정과 지원](references/corrections-and-relief.md).
- 복잡한 부가세·장부·임대·해외·재산세목·외부기관: [심화 준비와 연결](references/advanced-and-linked.md).

Pro가 없어도 위 절차를 중단하지 않는다. 계산은 확인된 공식 결과를 사용하고 자료·화면·증빙 대조를 제공한다. 세액을 AI 암산으로 추정하지 않는다.

## 1) 신고기한 감각 (재확인 필수)

### 부가가치세 (일반과세 개인 중심)
- 1기 예정: 4월 / 1기 확정: 7월
- 2기 예정: 10월 / 2기 확정: 다음 해 1월
- 개인 일반과세는 실무상 **확정신고 중심**인 경우가 많음 (고지·예정신고 여부는 홈택스 확인)
- 간이과세: 통상 **다음 해 1월** 연 1회 (납부면제 여부는 공급대가 기준·화면 확인)
- 간이과세자라도 상반기 세금계산서 발급·과세유형 전환이 있으면 7월 신고대상 여부를 별도로 확인한다. 과세유형은 신고일 현재만 보지 말고 해당 과세기간 기준으로 기록한다.

### 종합소득세
- 정기신고: 통상 **다음 해 5월 1일~31일** (해당 연도 홈택스 마감일 확인)
- 성실신고확인서 제출자의 기한은 통상 6월 30일. 토요일·공휴일 순연과 개별 연장을 별도 확인한다.
- 기한후·수정·경정청구는 별도 기한

출력 시: `※ 실제 마감일은 해당 연도 홈택스/국세청 공지를 다시 확인하세요.`

## 3) 부가세 준비 체크리스트

### 필수에 가까움
- [ ] 과세기간 확정 (예: 2026년 1기)
- [ ] 사업자등록 정보·과세유형 확인
- [ ] 거래 당시 공급자 과세유형·세금계산서 발급자격, 과세유형 전환일(해당 시)
- [ ] 전자세금계산서 매출/매입 홈택스 조회 가능
- [ ] 신용카드·현금영수증 매출(해당 시)
- [ ] 매입: 세금계산서 / 사업용카드 / 지출증빙 현금영수증
- [ ] 사업용 신용카드 홈택스 등록 여부 확인
- [ ] (있으면) 매출·매입 엑셀 합계

### 있으면 좋은 것
- [ ] 수기 세금계산서 사본
- [ ] 면세·영세율 매출 구분 메모
- [ ] 지난 기 부가세 신고서 PDF
- [ ] 카드사별 이용내역 CSV/XLSX

### 자주 빠지는 것
- 미등록 개인카드 사업 사용분
- 현금 매출
- 거래처 미발급 세금계산서
- 접대비·차량비 불공제 미분류

사업용카드 미등록이면:
1. 홈택스에서 사업용신용카드 등록 안내
2. 이번 기는 카드 전체를 `receipt-classify-kr`로 분류해야 할 수 있음을 고지

## 4) 종합소득세 준비 체크리스트

### 소득 자료
- [ ] 사업소득 수입 (세금계산서·카드매출·지급명세 3.3% 등)
- [ ] 근로소득 연말정산 명세 (투잡·중도퇴사 포함)
- [ ] 기타소득·연금·이자배당 (해당 시)
- [ ] 원천징수세액 합계
- [ ] 기납부는 국세 소득세와 지방소득세를 분리하고 중간예납은 고지액과 실납부액을 구분

### 경비·공제
- [ ] 필요경비 엑셀 또는 간편장부성 자료
- [ ] 적격증빙 (세금계산서·카드·현금영수증)
- [ ] 인건비·임차료·외주비 증빙
- [ ] 보험료·의료·교육·기부·연금 등 공제 자료
- [ ] 전년도 종소세 신고 결과(있으면)

### 유형 파악
- [ ] 홈택스 신고안내 유형 (모두채움, 단순/기준경비율, 간편장부, 복식 등)
- [ ] 실제 경비 자료 수준: 없음 / 일부 / 충분
- [ ] 귀속연도와 실제/예정 신고일 구분, 복식부기의무·기존 신고 여부(가산세·전자신고 공제 확인용)

## 6) 준비 완료 판정

```text
## 준비 상태 ({대상} / {기간})

### Ready
- ...

### Missing (신고 전 필요)
- ...

### Optional
- ...

### 다음 단계
1) receipt-classify-kr 로 분류
2) vat-hometax 또는 income-tax-hometax 로 신고 직전 점검
```

Missing이 필수 항목이면 신고 스킬로 바로 보내지 말고 수집을 먼저 요청.

## 7) 동료용 최소 안내 문장

필요 시 사용자가 동료에게 그대로 전달할 수 있게 짧게 작성:

```text
1. 폴더 만들기
2. 홈택스·카드·은행 자료 다운로드
3. 영수증 사진 모으기
4. Aside에 "분류해줘" → "부가세/종소세 신고 도와줘"
```

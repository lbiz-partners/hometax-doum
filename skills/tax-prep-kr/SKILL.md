# 세무 신고 준비 (tax-prep-kr)

부가세·종합소득세 신고 **전에** 자료를 빠짐없이 모으고 정리하는 범용 준비 스킬.  
특정 회사 전용이 아니다. 사용자 상황을 물어 체크리스트를 맞춤 출력한다.

제출 화면 작업은 `vat-hometax` / `income-tax-hometax`로 넘긴다.  
영수증 분류 세부는 `receipt-classify-kr`로 넘긴다.  
종소세 **예상세액·분납·성실신고 판정**을 미리 보고 싶으면 `jongsose-prep-kr`(🔒 Pro 별매, 설치 시) — 준비 단계에서 납부 규모를 가늠하고 자료 우선순위를 정할 수 있다.

## 절대 규칙

1. 개인 민감정보(전체 주민번호·계좌)를 채팅에 붙여 넣게 하지 않는다. 파일/폴더로 관리 안내.
2. “이 자료면 세금 0원” 같은 약속 금지.
3. 기한·기준금액은 변동 가능 → **해당 연도 국세청/홈택스 안내** 재확인 문구 포함.
4. 보고 말미 표준 면책:  
   `본 도구는 신고 준비를 돕는 **소프트웨어**이며, 「세무사법」 제2조의 세무대리(신고 대리·세무조정계산서 등 서류 작성·장부작성 대행·조세 상담/자문·성실신고 확인)를 수행하지 않습니다. 제공자는 세무사가 아닐 수 있으며, 자격 유무와 무관하게 본 도구는 세무대리·유상 세무상담이 아닙니다(신고서 작성·제출을 대행하지 않음). 신고·납부의 최종 판단·책임은 이용자 본인에게 있고, 세무대리·상담이 필요하면 「세무사법」 제6조에 따라 등록한 세무사에게 위임하세요. 금액이 크거나 애매하거나 범위 밖(세무조사·법인세·성실신고 대행 등)이면 세무사 상담을 권합니다. 자세한 조건은 LICENSE.md 참조.`

## 시작 인터뷰

```text
1. 준비 대상: 부가세 / 종합소득세 / 둘 다
2. 기간: (부가세) 몇 년 몇 기·예정/확정  (종소세) 귀속연도
3. 형태: 일반과세 / 간이 / 프리랜서 / 근로+부업 / 모름
4. 이미 있는 것: 홈택스 로그인 가능? 엑셀? 카드 내역? 세금계산서?
```

## 모드

| 모드 | 산출물 |
| --- | --- |
| A. 일정 안내 | 다가오는 신고 일정 |
| B. 자료 체크리스트 | 받을 목록 + 체크박스 |
| C. 폴더 템플릿 | 권장 디렉터리 구조 |
| D. 준비 완료 판정 | ready / missing 목록 |
| E. 다음 스킬 연결 | classify 또는 신고 스킬 |

기본 요청은 A+B+C.

## 1) 신고기한 감각 (재확인 필수)

### 부가가치세 (일반과세 개인 중심)
- 1기 예정: 4월 / 1기 확정: 7월
- 2기 예정: 10월 / 2기 확정: 다음 해 1월
- 개인 일반과세는 실무상 **확정신고 중심**인 경우가 많음 (고지·예정신고 여부는 홈택스 확인)
- 간이과세: 통상 **다음 해 1월** 연 1회 (납부면제 여부는 공급대가 기준·화면 확인)

### 종합소득세
- 정기신고: 통상 **다음 해 5월 1일~31일** (해당 연도 홈택스 마감일 확인)
- 기한후·수정·경정청구는 별도 기한

출력 시: `※ 실제 마감일은 해당 연도 홈택스/국세청 공지를 다시 확인하세요.`

## 2) 권장 폴더 구조

사용자 로컬에 아래를 만들도록 안내 (경로 예시는 수정 가능):

```text
세무_{귀속연도}/
  00_체크리스트.md
  01_홈택스/
  02_세금계산서/
  03_카드/
  04_은행/
  05_현금영수증_영수증/
  06_급여_원천징수/
  07_엑셀_분류/
  08_신고초안_결과/
```

파일명 규칙:
- `{기관}_{YYYY}_{기간}.xlsx` 예: `삼성카드_2025_01-06.xlsx`
- 한글 깨짐 방지 위해 가능하면 영문·숫자 혼용도 허용

## 3) 부가세 준비 체크리스트

### 필수에 가까움
- [ ] 과세기간 확정 (예: 2026년 1기)
- [ ] 사업자등록 정보·과세유형 확인
- [ ] 전자세금계산서 매출/매입 홈택스 조회 가능
- [ ] 신용카드·현금영수증 매출(해당 시)
- [ ] 매입: 세금계산서 / 사업용카드 / 지출증빙 현금영수증
- [ ] 사업용 신용카드 홈택스 등록 여부 확인
- [ ] (있으면) 매출·매입 엑셀 합계

### 있으면 좋은 것
- [ ] 수기 세금계산서 사본
- [ ] 면세·영세율 매출 구분 메모
- [ ] 지난 기 부가세 신고서 PDF
- [ ] 카드사별 이용내역 CSV/XLSX

### 자주 빠지는 것
- 미등록 개인카드 사업 사용분
- 현금 매출
- 거래처 미발급 세금계산서
- 접대비·차량비 불공제 미분류

사업용카드 미등록이면:
1. 홈택스에서 사업용신용카드 등록 안내
2. 이번 기는 카드 전체를 `receipt-classify-kr`로 분류해야 할 수 있음을 고지

## 4) 종합소득세 준비 체크리스트

### 소득 자료
- [ ] 사업소득 수입 (세금계산서·카드매출·지급명세 3.3% 등)
- [ ] 근로소득 연말정산 명세 (투잡·중도퇴사 포함)
- [ ] 기타소득·연금·이자배당 (해당 시)
- [ ] 원천징수세액 합계

### 경비·공제
- [ ] 필요경비 엑셀 또는 간편장부성 자료
- [ ] 적격증빙 (세금계산서·카드·현금영수증)
- [ ] 인건비·임차료·외주비 증빙
- [ ] 보험료·의료·교육·기부·연금 등 공제 자료
- [ ] 전년도 종소세 신고 결과(있으면)

### 유형 파악
- [ ] 홈택스 신고안내 유형 (모두채움, 단순/기준경비율, 간편장부, 복식 등)
- [ ] 실제 경비 자료 수준: 없음 / 일부 / 충분

## 5) 어디서 받나 (다운로드 가이드)

| 자료 | 어디서 |
| --- | --- |
| 전자세금계산서 | 홈택스 조회/발급 |
| 사업용카드 사용내역 | 홈택스 사업용신용카드 |
| 현금영수증 | 홈택스 현금영수증 |
| 부가세·종소세 신고내역 | 홈택스 세금신고 내역 |
| 카드 이용내역 | 각 카드사 웹/앱 (PC 권장) |
| 은행 거래 | 각 은행 거래내역 엑셀 |
| 지급명세/원천세 | 홈택스 지급명세 관련 메뉴 |
| 종이 영수증 | 사진/스캔 → `05_현금영수증_영수증/` |

PC 다운로드 권장. 모바일은 파일 확보가 어려운 경우 많음.

## 6) 준비 완료 판정

```text
## 준비 상태 ({대상} / {기간})

### Ready
- ...

### Missing (신고 전 필요)
- ...

### Optional
- ...

### 다음 단계
1) receipt-classify-kr 로 분류
2) vat-hometax 또는 income-tax-hometax 로 신고 직전 점검
```

Missing이 필수 항목이면 신고 스킬로 바로 보내지 말고 수집을 먼저 요청.

## 7) 동료용 최소 안내 문장

필요 시 사용자가 동료에게 그대로 전달할 수 있게 짧게 작성:

```text
1. 폴더 만들기
2. 홈택스·카드·은행 자료 다운로드
3. 영수증 사진 모으기
4. Aside에 "분류해줘" → "부가세/종소세 신고 도와줘"
```

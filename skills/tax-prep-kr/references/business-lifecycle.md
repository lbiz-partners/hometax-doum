# 개업·변경·휴폐업과 기본 설정

무료에서도 이 안내를 끝까지 사용할 수 있다. 사업 가명·대상 사업장·희망 처리일·과세유형·직원 및 외주 지급 여부를 확인한다. 실제 주민번호·계좌번호·인증정보는 대화에 수집하지 않는다.

## H01 처음 설정

1. 개인 화면과 사업장 화면, 여러 사업장 중 현재 대상을 구별한다. 사업 가명과 기간을 먼저 표시한다.
2. 일반·간이·면세·겸영은 해당 기간의 등록 정보로 확인한다. 모르면 미확인으로 둔다.
3. 직원 유무와 외주·일용 지급 유무를 따로 확인하고 이번 작업에 필요한 자료만 묻는다.
4. 로그인은 본인에게 맡긴다. 브라우저가 없으면 통합검색어와 확인할 항목을 안내하고 현재 화면을 관찰했다고 말하지 않는다.
5. 메뉴가 없으면 개인/사업장 전환, 인증 수준, PC/손택스 지원 차이, 실제 신고기간 순으로 확인한다. 인증 우회나 비공개 API 호출로 대체하지 않는다.

산출물: 사업장·기간·과세유형·확인일·자료 보유 여부·다음 업무. 완료 증거는 사용자가 확인한 대상 사업장과 선택 업무이며 로그인만으로 업무가 완료된 것은 아니다.

## H02 사업자등록 신청·정정

| 상황 | 준비자료 | 확인할 항목 |
|---|---|---|
| 신규 | 사업 내용, 개업일, 사업장 사용 근거, 임대차 및 필요한 인허가 자료 | 개인/공동사업, 실제 사업에 맞는 업종, 과세유형, 첨부 |
| 업종·상호 변경 | 현재 등록 내용과 변경하려는 내용 | 업종 명칭만으로 허가·면세를 확정하지 않음 |
| 소재지·임대차 변경 | 새 주소와 사용 근거, 변경일 | 임대인·면적·계약 조건과 첨부가 일치하는지 |
| 공동사업 변경 | 공동사업 관계와 지분·변경 근거 | 공동사업·양도·증여의 별도 검토 필요 여부 |
| 등록증 재발급 | 대상 사업장·수령 방법 | 등록증 재발급과 사업자등록증명의 차이 |

홈택스 통합검색에서 ‘사업자등록 신청’, ‘사업자등록 정정’, ‘사업자등록증 재발급’을 찾는다. 현재 화면의 작성 항목과 준비자료를 건별 대조하고 미확인을 임의 입력하지 않는다. 사용자가 최종 신청 후 민원처리결과를 확인한다. 접수와 등록·정정 완료를 구별하며, 완료된 등록증의 상호·업종·소재지를 다시 확인한다.

Pro `biz-reg-hometax`가 있으면 상세 진행으로 연결한다. 없으면 위 기본 진행을 계속한다. 통신판매업·사업 인허가는 정부24·해당 지자체의 별도 절차이며 사업자등록으로 완료되지 않는다.

## H03 휴업·재개업·폐업

1. 휴업/재개업/폐업 중 실제 목적과 적용일, 모든 사업장인지 특정 사업장인지를 확인한다.
2. 휴폐업 관련 신고를 통합검색하고 현재 화면의 사유·일자·첨부를 확인한다. 사용자가 제출한 뒤 처리결과·필요한 사실증명을 보관한다.
3. 폐업이면 마지막 매출·매입·현금영수증·계산서, 직원·외주 지급, 재고·자산, 미수·미지급, 임대차 종료 자료를 목록화한다.
4. 폐업 처리와 마지막 부가세·종소세·원천세·지급명세서·지방세 처리는 각자 확인한다. 법정기한은 폐업일·세목에 맞춰 공식 자료에서 확인한다.
5. 사업양도·포괄양수도·잔존재화·법인전환 판단은 거래·계약·자산 자료를 묶어 전문가에게 연결한다. 폐업신청 완료를 모든 세금 정산 완료로 표시하지 않는다.

산출물: `업무 / 대상일 / 필요한 자료 / 접수 확인 / 처리 확인 / 남은 신고 / 근거` 표. Pro는 월마감·미수금 결과를 첨부할 수 있으나 폐업 관련 모든 세액을 자동 계산하지 않는다.

## H04 사업용계좌·사업용카드·전자송달

- 사업용계좌 신고와 은행 계좌 개설은 다르다. 신고 의무·기한은 기장의무 등 사실관계를 확인한 뒤 공식 기준을 적용한다. 계좌번호는 사용자가 화면에 직접 확인·입력한다.
- 사업용신용카드 등록 → 등록 결과 → 사용내역 조회 → 매입세액 공제 확인/변경은 별도 단계다. 등록 이전 내역·조회기간 공백은 카드사 원본과 확인한다. 등록 사실만으로 전액 공제 처리하지 않는다.
- 환급계좌는 사업용계좌 신고와 목적이 다르다. 환급받을 본인 명의 계좌와 적용 세목을 화면에서 확인한다. 변경 후 결과를 다시 조회한다.
- 전자송달·연락처는 신청·변경 결과와 실제 수신 경로를 확인한다. 이전 고지의 기한이 자동 연장됐다고 추정하지 않는다.

# 증명·고지·납부·환급·혜택

## H17 국세증명

먼저 제출처의 요구 문서명·대상 사업장·귀속연도/과세기간·발급일 조건·주민번호 공개 범위·용도를 확인한다. 요구사항을 모르면 발급 전에 확인할 항목을 알려준다.

| 필요 | 구별할 문서 |
|---|---|
| 사업 등록 사실 | 사업자등록증명 / 등록증 재발급 |
| 체납 관련 증명 | 국세 납세증명 / 지방세 납세증명 / 납부내역증명 |
| 소득·매출 증명 | 소득금액증명 / 부가가치세 과세표준증명 / 면세사업자 수입금액증명 |
| 영업 상태 | 휴업·폐업사실증명 |
| 신고 이력 등 | 해당 사실증명 / 표준재무제표증명 등 실제 발급 가능 문서 |

통합검색에서 정확한 문서를 선택하고 기간·용도·수령방법을 확인한다. 본인 발급 후 원문 문서명·사업장·기간·발급일·진위확인 경로를 확인한다. 미신고·발급가능 시점·문서 용도의 차이를 오류와 구별한다. 파일명이나 OCR만으로 내용·진위를 확정하지 않는다.

산출물은 `요구서류 / 요구기간 / 발급파일 참조 / 확인한 기간 / 발급일 / 누락·차이` 표. Pro `document_review.py`는 사용자가 원문과 확인한 메타데이터를 요구조건에 대조하며 PDF 내용을 자동 판독·진위확인하지 않는다.

## H18 접수·고지·납부

세목·대상기간·사업장을 확인하고 실제 신고내역·접수증·부속서류 상태를 읽는다. 고지액·신고납부액·중간예납·가산금 등을 임의 합산하지 말고 해당 납부의무를 구분한다. 납부서 생성, 은행 이체 예약, 실제 납부 결과는 서로 다르다.

분납·연장 여부는 실제 신청·승인·고지내용을 확인한다. 본인이 납부한 뒤 납부내역·금액·귀속을 확인하고 차이가 있으면 미완료로 남긴다. 국세와 지방세 납부를 따로 기록한다. 홈택스에서 위택스로 이동했다는 사실은 지방세 접수·납부 완료의 증거가 아니다.

신고 후 기록은 허브의 `filing-status.md` 또는 각 신고 스킬의 사후확인 절차를 따른다. Pro의 상태 도구도 실제 증빙과 사람 확인을 필요로 한다.

## H19 환급

환급 요청의 세목·기간과 기존 신고·청구 내역을 확인한다. 통합검색에서 ‘국세환급금 찾기’, 환급내역, 환급계좌 관련 현행 메뉴를 찾는다. 계좌 입력·변경은 본인이 수행하고 결과를 확인한다.

`신고상 예상액 / 청구 접수 / 심사 / 결정 / 충당 / 실제 지급 / 은행 입금`을 구분한다. 조회되지 않는 금액을 0원이나 환급 불가로 확정하지 않는다. 충당액과 실입금액 차이를 확인하며 예상 환급을 납부액에서 임의 상계하지 않는다.

Pro 대조: 확인한 결정액·충당액·실입금액과 각 원문 참조를 항목별로 준비하여 차이표를 만든다. 단순 환급금 조회와 경정청구는 다른 흐름이다.

## H22 장려금·세금포인트·지원

장려금은 귀속연도·근로/사업/종교인소득·가구·재산 등 해당 요건을 확인한다. 사업소득이 있으면 근로소득만 있는 반기신청 경로와 혼동하지 않는다. 안내문 수신 여부만으로 자격·지급액을 확정하지 않는다. 신청 후 심사·결정·입금을 각각 기록한다.

세금포인트는 조회와 혜택별 사용조건을 안내한다. 현금환급금·세액공제·납부수단으로 표시하지 않는다. 공제감면·세정지원은 업종·사업이력·지출·고용·적용연도에 필요한 자료와 후보 요건을 정리한다. 정보 부족 상태에서 ‘적용 가능’이나 ‘환급 확정’을 표시하지 않는다.

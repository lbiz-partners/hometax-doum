# 정정·연장·권리보호 준비

## H20 기한후신고·수정신고·경정청구

처음에 세목·귀속연도·원신고 접수 여부·법정기한·실제 신고일·과세관청의 결정/통지 여부·바꾸려는 항목과 이유를 확인한다. 과거 신고의 세액을 다시 계산하기 전에 적용 절차와 지원연도를 구분한다.

| 상황 | 확인할 절차 후보 | 필요한 자료 |
|---|---|---|
| 기한이 지났고 신고하지 않음 | 기한후신고 가능 여부 | 대상기간 전체 자료, 안내·결정 여부 |
| 기존 신고에 누락·오류가 있음 | 수정신고 또는 정정의 구체적 방식 | 원신고서·접수증·추가 증빙·항목별 변경 이유 |
| 과다 납부·공제 누락 등 주장 | 경정청구 가능 여부 | 원신고·납부·변경근거·기한 산정에 필요한 일자 |
| 과세 통지·결정에 이견 | 불복·권리보호 절차 | 통지 원문·송달일·관련 사실과 증빙 |

1. 표는 절차 후보이며 환급/추가납부 방향만으로 절차를 단정하지 않는다. 법정기한·후발적 사유·결정 여부 등은 국세기본법 및 해당 세목의 현행 공식 안내로 확인한다.
2. 원신고 수치와 변경하려는 수치를 항목별로 나란히 놓고 차이·근거·미확인을 표시한다. 새 원자료를 원신고의 근거인 것처럼 덮어쓰지 않는다.
3. 홈택스에서 해당 세목의 기한후/수정/경정 메뉴와 지원 귀속연도를 확인한다. 화면이 지원하지 않는 사례는 서면 또는 관할 기관·전문가 확인으로 연결한다.
4. 첨부 목록과 사유를 사실에 근거해 정리한다. 증빙과 수치는 지어내지 않는다. 사용자가 내용을 확인하고 제출한다.
5. 접수·추가자료 요청·결정·추가납부/환급입금을 각각 기록한다. 경정청구 접수를 환급 승인으로 표시하지 않는다.

Pro `control_review.py`로 원자료 합계와 신고값을 대조할 수 있다. 기존 세액 엔진이 지원하는 입력만 재계산하며, 가산세·경정청구 기한·감면 여부의 범용 계산기는 제공하지 않는다. 미지원 계산은 전문가에게 원신고·차이표·추가 증빙을 인계한다.

## H21 기한연장·징수 관련 유예

신고기한 연장과 납부기한 연장, 고지분 관련 신청, 압류·매각 관련 유예를 구별한다. 대상 세목·금액·원래 기한·신청 사유·증빙·신청일·관할 기관을 확인한다.

실제 매출 감소·재해·자금사정 자료를 기간별로 정리하고 해당 제도의 공식 신청요건·첨부·신청시점을 확인한다. 홈택스 통합검색의 현행 ‘기한연장’ 등 관련 메뉴에서 본인이 신청한다. 작성·접수만으로 기한을 연장해 기록하지 않는다. 승인 여부·새 기한·조건·분납내역은 결과 원문으로 확인한다.

산출물: `제도 / 원래 기한 / 사유 근거 / 필요자료 / 신청 접수 / 승인 여부 / 승인 후 기한 / 남은 납부` 표. Pro에서는 이미 확인된 고지액·예상액과 기한을 월마감 납부준비금에 연결할 수 있다.

## H23 상담·소명·불복·대리인 관리

일반 문의는 공식 상담창구에 질문할 사실·쟁점·자료를 정리한다. 소명·권리보호·불복은 원문 통지와 수령일, 요청 내용, 답변 기한의 확인이 우선이다. 사실관계 연표·증빙 목록·미확인사항을 만들고, 전문적인 주장·불복 대행·세무조사 대응은 등록 전문가에게 연결한다.

세무대리인 수임동의·해지는 현재 대상·권한·적용범위를 본인이 확인한다. 동의·해지 전후 상태를 따로 기록한다. 자료 묶음 생성과 외부 전송은 별개이며 실제 전송은 사용자 요청이 있어야 한다.

# 통신판매업 신고 (정부24) 연계

홈택스 **업종 추가**와 별개. 관할: 사업장 시·군·구 (정부24 온라인).

공식 안내: 정부24 민원 `통신판매업신고` (CappBizCD 예: 11300000006)

## 면제 후보

다음 중 하나면 신고 면제 가능(공정위 고시·전자상거래법 체계):

1. 직전연도 통신판매 거래횟수 **50회 미만**
2. 부가가치세법상 **간이과세자**

일반과세 + 판매 확대 예정이면 신고를 권고. 플랫폼 입점 시 신고번호를 요구하는 경우 많음.

## 준비물

| 항목 | 비고 |
| --- | --- |
| 사업자등록 | 홈택스 등록·업종 반영 권장 |
| 사이트/스토어 URL | 자사몰·스마트스토어 등 |
| 구매안전(에스크로) 확인증 | 선지급식 판매 시 필수에 가깝다 (은행/PG/오픈마켓) |
| 소명자료 | 선지급식이 아니면 소명 첨부 가능한 경우 있음 |
| 연락처·이메일 | 면허세 안내용 — 대표 연락처에 유선만 넣으면 문자 누락 가능 → 휴대 권장 |

## 정부24 작성 순서

1. 정부24 로그인 — **개인사업자 = 개인 탭** (법인 탭 금지)
2. 통신판매업신고 → 발급/신청 → 회원 신청
3. 유의사항 확인 체크 → 다음
4. 입력:
   - 상호, 사업자번호, 연락처
   - 사업장 주소(검색으로 선택 + 처리기관 선택)
   - 대표자 주소 (동일 가능)
   - 이메일
   - 판매방식: 인터넷 등
   - 도메인
   - 호스트서버 소재지 (해외 서버면 방문 신고 안내 문구 확인)
   - 취급품목
5. 구비서류: 파일첨부 (jpg 등, 용량 제한 준수)
6. 수령: 온라인발급(본인출력) 권장
7. 구비서류 열람 사전동의:
   - 개인사업자는 **사업자등록증명** 동의
   - 법인등기는 해당 시. 화면이 "전체 선택"을 강제하면 안내 문구 확인 후 처리
8. **신청하기** → 간편인증/공동인증서 (암호·앱 승인은 사용자)
9. 간편인증 후 **인증 완료**까지 눌러야 접수되는 경우가 많음
10. MyGOV > 서비스 신청 내역에서 접수번호·처리중 확인

## 접수 후

1. 등록면허세 납부 안내 문자 (1~3일)
2. 위택스 **빠른납부**(전자납부번호) — 다른 경로 납부 시 이중부과 주의
3. 처리완료 후 신고증 출력(기간 제한 가능)
4. 쇼핑몰 하단에 신고번호 표시
5. 폐업 시 통신판매업 폐업도 별도

## 에이전트 주의

- 자동 제출 금지, 인증 승인 대행 금지
- 간편인증 OACX 동의 체크는 UI 클릭으로 상태 반영. DOM checked만 조작하면 "필수항목 동의" 오류 가능
- SIMPLE_DATA 미초기화 시 간편인증 모듈 로드 실패 → 정상 **신청하기** 플로우로 재진입
- 신청 성공 판정은 화면 문구만이 아니라 **MyGOV 신청내역 접수번호**로 확정

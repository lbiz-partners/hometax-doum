# H02 사업자등록 신청·정정·결과조회·통신판매업

무료에서도 이 문서로 신규 신청부터 정정·결과 확인까지 끝까지 진행한다. 화면 클릭 순서는 [정정 화면 워크플로](hometax-biz-amend.md), 온라인 판매 신고는 [통신판매업 신고](tongpan-gov24.md)를 함께 본다. 휴업·폐업은 [사업 생애주기](business-lifecycle.md)의 H03이다.

## 절대 규칙

1. 로그인·간편인증·인증서 암호·보안프로그램 설치 승인은 사용자가 직접 한다. 대신 입력하지 않는다.
2. **신청서 제출하기** 같은 최종 버튼은 누르기 전에 반드시 묻는다: `이 내용으로 사업자등록 신청/정정 제출해도 될까요?`
3. 업종코드·상호·주소를 추측하지 않는다. 홈택스 업종 조회 결과와 사용자가 확인한 값만 쓴다.
4. 주민번호·계좌번호는 대화에 받지 않는다. 화면에 사용자가 직접 입력한다. 보고서에는 가린 값만 쓴다.
5. 과세유형·인허가·면세 여부는 **후보 + 근거 + 확인 질문**으로 남긴다. 업종 이름만으로 확정하지 않는다.
6. 접수와 처리완료를 구별한다. 접수번호만으로 "등록 완료"라고 보고하지 않는다.

## 시작 질문 (필요한 것만)

```text
1) 무엇을 하시나요? 신규 신청 / 업종 추가·변경 / 상호·연락처 변경 / 사업장 이전 / 결과조회·등록증 재발급 / 통신판매업 신고
2) 기준일(오늘 날짜)과 사업 시작일(또는 예정일)
3) 사업장: 자가 / 임차(임대차계약서 있음) / 집 주소
4) 하려는 일: 판매·서비스 내용을 평소 말로 (업종코드는 화면에서 함께 찾습니다)
5) 인허가가 필요한 업종인가요? (학원·식품·의료·숙박 등)
6) 온라인·비대면 판매 계획이 있나요? (통신판매업 신고와 연결)
7) 정정·조회라면 사업자번호(뒷자리는 가려도 됨)
```

## 신청 시기와 준비물 (신규)

| 확인할 것 | 내용 | 근거 |
|---|---|---|
| 신청 기한 | 사업 개시일부터 **20일 이내**에 신청한다. 사업을 시작하기 전에도 신청할 수 있다 | 부가가치세법 제8조제1항 |
| 등록 전 매입 | 등록 신청 전에 산 물건의 부가세(매입세액)는 원칙적으로 공제되지 않는다. 다만 그 매입의 과세기간이 끝난 후 **20일 이내**에 신청하면, 신청일부터 그 과세기간 시작일까지 거슬러 올라간 기간의 매입세액은 공제된다. 개업 준비 비용이 있으면 빨리 신청하도록 안내한다. 사업자등록번호가 없을 때 산 것은 판매자에게 **대표자 주민등록번호를 적어** 세금계산서를 받아야 한다(번호는 사용자가 판매자에게 직접 전달, 사업자등록증 발급일까지의 거래는 부가가치세법 시행령 제75조제1호). 이 공제 방식은 일반과세자 기준이며 간이과세자는 공제 방식이 다르다 | 부가가치세법 제39조제1항제8호 |
| 늦게 등록하면 | 기한까지 신청하지 않으면 사업 개시일부터 신청일 전날까지 공급가액 합계의 **1%** 가산세. 다른 사람 명의로 등록하면 2%. 간이과세자는 **공급대가**의 0.5%(다른 사람 명의 1%) | 부가가치세법 제60조제1항제1호·제2호, 제68조의2제1항 |
| 발급 시기 | 신청일부터 **2일 이내**(공휴일 등 제외) 발급. 현장 확인이 필요하면 5일 이내에서 늘어날 수 있고, 보정 요구 기간(10일 이내)은 계산에 넣지 않는다. 정정은 상호·사이버몰 명칭·도메인 변경이면 **당일**, 그 밖의 정정은 **2일 이내** 재발급 | 부가가치세법 시행령 제11조제5항·제13항, 제14조제3항 |

준비물은 현재 신청 화면의 안내가 기준이다. 흔히 필요한 것은 다음과 같다.

| 준비물 | 언제 필요한가 |
|---|---|
| 신분 확인(로그인 인증) | 항상. 인증은 사용자 |
| 임대차계약서 사본 | 사업장을 빌린 경우 |
| 인허가·등록·신고증 사본 | 허가·등록·신고가 필요한 업종 |
| 동업계약서 | 공동사업자인 경우 |
| 자금출처 명세서 | 화면에서 요구하는 업종인 경우 |

## 모드 A — 신규 신청

1. **과세유형 후보 정리**: 일반/간이 선택은 예상 매출·업종·거래처(사업자 상대인지)를 묻고 후보와 이유만 적는다. 간이과세 배제 업종·지역 여부는 화면과 국세청 안내로 확인한다고 적는다. 결정은 사용자.
2. **업종 찾기**: 사용자의 말을 키워드로 바꿔 홈택스 업종코드 **조회**에서 함께 찾는다. 주업종 1개와 필요한 부업종을 정한다. 후보가 여러 개면 화면의 업태·종목 설명을 보여 주고 사용자가 고른다.
3. **화면 진입**: 홈택스 통합검색 `사업자등록 신청` 또는 메뉴 `증명·등록·신청·사업장현황 > 사업자등록 신청·정정·휴폐업 > (개인)사업자등록 신청`(메뉴 경로는 실화면 미검증 — 현재 화면에서 확인). 개인 화면으로 로그인해야 하는 경우가 있으니 화면 안내를 따른다.
4. **입력 초안**: 상호, 사업장 주소, 개업일, 업종, 사업장 면적·임대 정보(임차 시), 공동사업 여부, 인허가 여부를 표로 먼저 만들고 사용자가 확인한 값만 화면에 옮긴다.
5. **첨부**: 위 준비물 중 해당하는 것만 첨부한다.
6. **제출 직전 점검**(아래 체크리스트) → 사용자 확인 → 사용자가 제출.
7. **결과 확인**: 모드 C.

## 모드 B — 정정 (업종 추가·상호·소재지·연락처)

| 정정할 것 | 준비 | 주의 |
|---|---|---|
| 업종 추가·변경 | 추가할 일의 설명, 인허가 여부 | 주업종을 바꾸는지 부업종만 더하는지 먼저 정한다 |
| 상호·연락처 | 새 상호·연락처 | 상호만 바꿔도 거래처 세금계산서 정보가 바뀐다고 안내 |
| 사업장 이전 | 새 주소, 새 임대차계약서, 이전일 | 관할 세무서가 바뀔 수 있다 |
| 공동사업자 변경 | 동업계약·지분 자료 | 화면에서 안 되면 세무서 방문 안내. 양도·증여 검토는 전문가 |

진행 순서(상세 클릭은 [정정 화면 워크플로](hometax-biz-amend.md)):

1. 통합검색 `사업자등록 정정` → **(개인)사업자등록 정정 신고** → 사업자번호 선택 → **조회**
2. 정정할 항목만 **정정**, 나머지는 **정정하지않음**
3. 업종 추가라면 **업종 입력/수정** → 부업종 선택 → 업종코드 **조회** → 선택 → **등록하기** → **업종 등록**
4. 정정 사유 한 줄(사용자 확인 문장), 행정정보 공동이용 동의 → **저장 후 다음 이동**
5. 제출서류: 필요한 것만 첨부. 업종만 추가하고 인허가가 없으면 첨부 없이 진행되는 경우가 있으나, 세무서가 보완을 요구할 수 있다고 알린다.
6. 최종확인 화면의 **제출서류 확인하기**(PDF)로 상호·사업자번호·업종을 다시 본다 → 사용자 확인 → 사용자가 **신청서 제출하기**
7. 결과 확인: 모드 C.

## 모드 C — 결과조회·등록증 재발급

1. 통합검색 `민원신청 처리결과 조회` → 기간 설정 → 조회
2. 기록: 민원명 / 접수번호 / 접수일시 / 처리상태(접수·처리중·처리완료) / 처리기한
3. 처리완료 후 등록증의 상호·업종·소재지·개업일·과세유형을 다시 확인한다.
4. 등록증이 필요하면 `사업자등록증 재발급`, 제출용 증명이 필요하면 `사업자등록증명`([국세 서비스](owner-services.md))을 구별한다.

## 모드 D — 통신판매업 연계

홈택스 업종 추가와 통신판매업 신고는 **별개**다. 온라인·비대면으로 반복 판매한다면 [통신판매업 신고](tongpan-gov24.md)로 이어간다. 직전 연도 통신판매 거래횟수가 **50회 미만**이거나 **간이과세자**이면 둘 중 하나만 해당해도 신고하지 않아도 된다(청약철회 건은 횟수에서 뺀다). 다만 입점 플랫폼이 신고번호를 요구하는 경우가 많으니 판매 계획과 함께 확인한다. 근거: 전자상거래법 제12조제1항, 공정거래위원회 「통신판매업 신고 면제 기준에 대한 고시」 제2조.

## 제출 직전 체크리스트

```text
[ ] 사업자(또는 신청인)·상호가 맞다
[ ] 신규/정정 중 의도한 것만 선택했다 (정정은 해당 항목만 '정정')
[ ] 주업종·부업종이 의도대로다 (업종코드·업태·종목을 사용자가 확인)
[ ] 사업장 주소·임대 정보가 계약서와 같다 (임차 시)
[ ] 인허가 업종이면 사본을 첨부했거나 보완 가능성을 안내했다
[ ] 개업일(또는 변경일)이 실제와 같다
[ ] PDF 미리보기로 최종 내용을 확인했다
[ ] 사용자에게 제출 확인을 받았다
```

## 보고 양식

```text
기준일 YYYY-MM-DD (출처) · 한 일: 신규 신청 / 정정 / 결과조회 / 통신판매업
- 사업자: 상호 (번호 가림)
- 한 일: 신청/정정 내용 요약
- 상태: 준비됨 / 사용자 제출함 / 접수번호 … / 처리완료 확인
- 미확인·남은 일: 인허가 보완, 등록증 확인, 통신판매업, 전자세금계산서·카드 등록 등
```

접수 후에는 [사업 생애주기](business-lifecycle.md)의 H04(사업용 카드·계좌·전자송달)와 [현금영수증](../../tax-invoice-hometax/references/cash-receipts.md) 가맹점 확인으로 연결한다.

# 홈택스 개인 사업자등록 정정 — 화면 워크플로

과거 작업에서 쓰인 클릭 순서와 장애 대응이다. 2026-09-17 실화면 점검에서는 작성 단계가 보안프로그램 설치 안내로 막혀 **작성·접수까지는 검증되지 않았다.** 아래 DOM ID·코드 조각은 브라우저 도구를 쓸 때의 참고일 뿐이며 홈택스 개편 시 무효가 된다. 메뉴 문구와 입력칸은 **현재 화면**을 우선한다.

## 진입

1. 로그인(본인이 직접). 신규 신청 등은 개인으로 전환해야 할 수 있으니 현재 화면 안내를 따른다
2. 메인 가이드맵 **사업자등록** 또는 전체메뉴  
   `증명･등록･신청･사업장현황 > 사업자등록 신청·정정·휴폐업`
3. **(개인)사업자등록 정정 신고**
4. 사업자등록번호 선택 → **조회**

조회 버튼이 안 먹으면:

```js
document.getElementById('mf_txppWframe_triggerSearch')?.click();
```

## 정정 항목

라디오:

- 상호 및 연락처
- 사업장소재지(임대차)
- 업종
- 송달장소

업종만 추가: 업종만 **정정**, 나머지 **정정하지않음** → **다음**

## 업종 입력 팝업

버튼: **업종 입력/수정**

순서:

1. 부업종 선택 (주업종 변경이 아니면)
2. 업종코드 옆 **조회**
3. 키워드 또는 코드 입력 → 조회
4. 행 **선택** (더블클릭/선택 버튼)
5. 표준산업분류가 여러 개면 2차 팝업에서 선택 후 **선택완료**
6. **등록하기**
7. 데이터 검증 후 **업종 등록**

### 데이터 검증 (UI 잘림 대응)

팝업 목록 UI가 일부 행만 보여도 데이터에는 들어갔을 수 있다.

- 팝업 목록: `window['mf_txppWframe_UTEABAAA65_wframe_dlt_grdTfbList']`
- 메인 목록: `window['mf_txppWframe_dlt_grdStfbList']`

```js
const d = window['mf_txppWframe_UTEABAAA65_wframe_dlt_grdTfbList'];
d.getRowCount();
d.getAllJSON().map(r => r.tfbCd + ' ' + r.itmNm);
```

### 표준산업분류 2차 선택

일부 업종코드(예: 724000)는 KSIC 다건 매핑.

- 그리드: `...UTERNAA0Z076_wframe_dlt_krStndIndsClCdDVOListDes`
- 행 선택 후 **선택완료**. 라디오만 클릭하고 완료 누르면 "선택된 행이 없습니다" 가능 → 행 포커스/더블클릭/API 선택 병행.
- 폴링: 팝업 직후 rowCount 0일 수 있음 → 0.5s 간격으로 데이터 로드 대기.

## 저장 후 제출

1. 정정요청설명 입력
2. 행정정보 공동이용 동의 체크  
   (`mf_txppWframe_radioAcceptYn_input_0` 등 — 클릭 후 checked 재확인)
3. **저장 후 다음 이동**
4. 제출서류 팝업 (`UTEABAAA76`) — 파일 첨부 또는 무첨부 **다음**
5. 증빙 미첨부 안내 (`UTEABAAA93`) — 확인 후 **다음**
6. 최종확인 (`UTEABAAA91`)
   - 확인 체크
   - **제출서류 확인하기** → PDF 뷰어(여러 페이지)에서 업종 목록 QA
   - 사용자 확인 후 **신청서 제출하기**

### 팝업 차단

제출 단계 팝업이 `about:blank`로 막히면:

1. 주소창 사이트 설정 → 팝업 및 리디렉션 **허용**(hometax.go.kr)
2. **완료** 클릭
3. 다시 저장/제출

팝업 탭 제목 예: `제출서류선택`, `증빙서류 첨부 안내`, `사업자등록정정신고서`, `PDF 변환 뷰어.`

## 결과조회

메뉴: **민원신청 처리결과 조회** (`menuAtag_4306070000` 등)

기록:

- 민원명: 사업자등록 정정신고
- 접수번호
- 접수일시
- 처리상태 / 처리기한

상세 팝업에서 접수증 출력·접수취소 가능(취소는 사용자 확인 후).

## 자주 하는 실수

| 증상 | 대응 |
| --- | --- |
| 등록하기 했는데 목록에 안 보임 | getAllJSON으로 확인, 스크롤/행 수 확인 |
| 조회 버튼 무반응 | native id click / 사업자번호 selected 확인 |
| 제출 시 팝업 차단 | 사이트 팝업 허용 |
| 보안모듈 미설치 | 사용자 수동 설치, 정정 화면 한정 이슈 |
| 인허가 업종 추가 후 보완 요구 | 허가·등록 사본 안내 |

## 안전

- 제출·취소·발급 클릭 전 사용자 확인
- 인증서 비밀번호/OTP 입력 금지
- 주민번호 뒷자리 보고 금지

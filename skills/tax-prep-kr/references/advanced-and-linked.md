# 장부·복잡한 신고·조건부 업무 준비

[업종별 준비·Free/Pro 지원표](industry-guide.md)에서 자료와 계산 범위를 고른다. 설치된 Pro에는 음식점 의제매입·일반과세 공통매입·상가 보증금·주택 분리과세·재고원가·수입 연결의 제한된 계산 모드가 있다. 각 모드의 적용기간·요건을 만족한 경우에만 사용한다.

## H10 부가세 심화

| 상황 | 준비·대조할 자료 | 확인할 쟁점 |
|---|---|---|
| 과세·면세 겸영 | 부문별 매출·직접매입·공통매입과 사용 목적 | 안분 대상·기준기간·정산 |
| 수출·해외 용역 | 계약·수출 증빙·외화수취·거래시점 자료 | 영세율 대상·첨부·환율·귀속 |
| 조기환급 | 환급 발생 사유·자산·매입·대금·사업 사용 | 대상·기간·첨부·사후 확인 |
| 음식점·제조 등 | 품목·매입처·증빙·업종·해당 기간 자료 | 의제매입 등 적용요건과 한도 |
| 임대·자산·폐업 | 계약·보증금·기간·취득/처분·재고 | 간주임대료·잔존재화·사업양도 |
| 매입자발행·대리납부 등 | 거래와 지급 근거·상대방·신청/확인 자료 | 실제 적용 제도·확인절차 |

`vat-hometax`에서 현재 화면과 공식 서식을 확인하고 항목별 준비표를 만든다. 원자료의 합계와 사용자가 확인한 입력값은 수동 또는 Pro의 대조 도구로 검산할 수 있다. 이 제품에 부가세 전 사례의 세율·안분·간주임대료 계산 엔진이 있다고 주장하지 않는다. 법적 요건이나 특례가 미확인이면 입력값을 확정하지 않고 전문가 검토로 연결한다.

## H12 장부·결산·종소세 심화

1. 귀속연도·업종·수입규모·기장의무·공동사업·다사업장·근로 겸업을 확인한다. 신고안내문과 실제 사실관계가 다르면 확인사항으로 남긴다.
2. 매출·지출 원장, 카드·계산서·현금영수증, 은행, 인건비, 재고, 자산, 대출·이자, 전기 신고·이월자료를 구분한다.
3. 간편장부 또는 본인이 사용하는 회계자료의 수입·경비 합계를 대조한다. 취득 자산을 모두 당기경비로, 입금을 모두 수입으로, 출금을 모두 비용으로 처리하지 않는다.
4. 감가상각·이월손실·공제감면·공동사업 배분은 해당 연도 조건과 이전 신고 근거를 확인한다. Pro 종소세 엔진의 지원 스키마 밖 수치를 임의 항목에 끼워 넣지 않는다.
5. 산출물은 본인 작성·검토용 집계와 차이표, 누락자료, 전문가 확인 질문이다. 법정 재무제표·세무조정계산서·성실신고확인서를 대행 작성했다고 표시하지 않는다.

## H24 업종·개인 재산·외부 업무

- 온라인판매·배달: 채널별 매출, 취소·환불, 수수료, PG정산, 입금을 분리한다. 통신판매업은 정부24·해당 기관 절차로 연결한다.
- 음식점·소매·제조: 카드·현금매출 외 재고·폐기·매입 자료를 준비하고 특례 요건을 확인한다.
- 프리랜서·창작자: 원천징수 자료, 플랫폼·해외 수입, 비용과 증빙을 모으고 면세/과세·사업장현황 해당 여부를 확인한다.
- 학원·의료·임대: [면세사업장현황 안내](exempt-status-report.md)를 먼저 읽되, 업종명 하나로 모든 수입이 면세라고 단정하지 않는다.
- 여러 사업장·공동사업: 사업장별 부가세와 개인의 종소세 합산을 구별한다. 사업장·사람 가명이 다른 자료는 자동 합치지 않는다.
- 외화·수출·국제 거래: 통화·환율 기준·거래/수취일·국내외 원천·세액 자료를 분리한다. 원 단위 전용 엔진에 외화 금액을 그대로 넣지 않는다.
- 양도·상속·증여·종부세·해외금융계좌·주세·개별소비세·인지세: 해당성 확인, 자료 목록, 공식 경로와 전문가 인계까지 지원한다. 전용 계산과 신고서 완성은 지원 범위 밖이다.
- 법인전환: 개인사업 종료·인계 자료를 준비하고 별도 법인 업무로 연결한다. 이 개인사업자 제품에서 법인세 엔진을 실행하지 않는다.
- 지방세·4대보험·사업 인허가: 해당 기관의 현재 서비스를 확인한다. 원천세·사업자등록 결과가 외부 기관의 완료를 대신하지 않는다.

통합 요청에는 `현재 할 일 / 연결 기관 / 필요한 자료 / 본인 처리 / 결과 증빙 / 전문가 확인` 표를 만든다. 지원 범위 밖도 설명 없이 종료하지 말고 구체적인 자료·질문·공식 연결을 제공한다.

공식 진입점(2026-09-17): [국세청 개인신고 안내](https://www.nts.go.kr/), [국세법령정보](https://taxlaw.nts.go.kr/), [정부24](https://www.gov.kr/), [위택스](https://www.wetax.go.kr/). 세부 메뉴와 요건은 실행 시 해당 기관에서 재확인한다.

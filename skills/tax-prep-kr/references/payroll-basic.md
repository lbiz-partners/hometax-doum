# 직원·외주 지급과 소득자료 — 무료 기본 안내

## H14 원천세 준비

직원이 없어도 강사·디자이너·일용직 등 지급이 있었는지 확인한다. 사업자 여부나 계약서 이름만으로 사업소득·근로소득을 단정하거나 모든 외주비에 같은 비율을 적용하지 않는다.

1. 지급 대상 가명, 실제 업무관계, 지급일, 귀속기간, 지급총액, 실제 공제액, 실제 송금액을 확인한다. 세금계산서를 받은 사업 거래인지도 확인한다.
2. 근로·일용·사업·기타·퇴직·비거주자 등 소득 종류와 원천징수 의무를 해당 연도 공식 안내에 비추어 확인한다. 사실관계가 부족하면 확인 질문과 전문가 검토 항목으로 남긴다.
3. 홈택스 통합검색 ‘원천세 신고’에서 대상 기간·정기/수정·월별/반기 적용 여부를 확인한다. 반기납부는 신청·승인 상태 없이 추정하지 않는다.
4. 지급내역표와 화면의 소득종류별 인원·지급액·원천징수액을 대조한다. Pro 원천징수 엔진이 없으면 홈택스·급여시스템에서 확인한 계산 결과를 사용하고 AI 암산으로 세액을 생성하지 않는다.
5. 본인 제출 후 접수증을 확인하고 국세 납부와 지방소득세 특별징수 신고·납부를 각각 확인한다. 원천세 제출만으로 지급명세서 제출까지 완료된 것이 아니다.

Pro `withholding-tax-hometax`가 설치되어 있으면 해당 엔진의 지원연도·소득유형·입력 범위를 읽고 계산한다. 지원하지 않는 퇴직·비거주자·상여·특수공제는 별도로 확인한다.

## H15 지급명세서·간이지급명세서·일용근로 자료

지급 종류·귀속연도·지급일·휴폐업일과 이미 제출한 자료를 확인한다. 간이/연간/일용의 제출주기, 연간 제출 간주·예외, 개정 시행일은 [공식 지급명세서 안내](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=8631&mi=12242)와 [세무일정](https://www.nts.go.kr/nts/ad/taxSchdul/selectList.do?mi=&taxMonth=&taxYear=2026)에서 해당 기간에 맞춰 확인한다. 올해 일정표를 다른 연도에 복사하지 않는다.

`사람 가명 / 소득종류 / 귀속 / 지급일 / 총액 / 공제액 / 제출할 서류 / 기존 접수 참조`로 준비한다. 원본 실명·주민번호는 본인이 홈택스에서 확인한다. 오류수정·재제출은 기존 접수와 현재 정정 방식부터 확인해 중복 제출을 방지한다. 본인 제출 후 접수결과·오류·첨부를 확인한다.

## H16 직원 연말정산·중도퇴사·퇴직

연말정산 대상 연도·재직기간·전근무지·월별 급여 및 원천징수·본인 확인 공제자료를 받는다. 근로자의 자료제공동의·간소화와 사업자의 신고를 구별한다. 가족관계·공제요건은 자료 유무만으로 충족했다고 보지 않는다.

직원별 연간 합계, 전근무지 합산 여부, 공제 확인사항, 정산 차액, 지급명세서와 원천세 후속 처리를 준비표에 남긴다. 현행 일반 원천징수 엔진은 연말정산 전체 계산기나 퇴직소득세 엔진이 아니다. 지원하지 않는 정산은 공식 계산·급여시스템·전문가 확인으로 연결한다.

## 확인 결과

산출물은 지급자료표·누락서류·확인 질문·공식 기한과 출처·다음 화면이다. 완료 상태는 원천세 접수, 국세납부, 지방세 접수/납부, 지급명세서 접수, 근로자 정산 지급을 분리한다. Pro에서는 `control_review.py`에 **이미 확인된** 대장합계와 신고값을 넣어 차이를 대조할 수 있다. 이 대조가 소득유형의 적법성이나 원천징수세액의 법적 정확성을 판정하지는 않는다.

확인일 2026-09-17. 일반 안내이며 실제 세액·기한은 귀속연도와 지급일에 맞는 공식 근거를 다시 확인한다.

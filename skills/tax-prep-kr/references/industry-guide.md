# 업종별 준비와 심화 계산 선택

확인일: 2026-09-17. 업종 이름만으로 과세유형·공제·수입 귀속을 확정하지 않는다. 먼저 사업장, 대상 기간, 실제 일반·간이·면세 상태와 자료 범위를 확인한다.

| 업종·상황 | Free에서 준비·수동 확인 | Pro에서 추가하는 계산·자동 검증 |
|---|---|---|
| 온라인판매·소매 | 주문·취소·정산·입금·수수료를 구별; 기초/기말 재고와 실사 확인 | 기본 일반·간이 부가세 작성표, 매출원가·이익·손실, 매출과 입력값 차이 |
| 음식점 | 식재료 면세 증빙과 실제 사용·과세매출 범위를 구별 | 개인 일반 음식점의 반기 의제매입 공제율·한도·경계값, 재고원가 |
| 제조 | 원재료·재공품·제품, 노무·제조경비, 재고 실사·평가 확인 | 원재료 사용액→제조원가→제품원가→매출원가 연결, 불가능한 기말 재고·비용 중복 확인 |
| 프리랜서·인적용역 | 실제 지급액·원천징수 국세/지방세·총수입을 구별; 귀속 시기 확인 | 확인된 실제 지급액+원천징수액 복원, 미수·선수·경비 연결, 거래 ID 중복 검출 |
| 학원·면세 서비스 | 수강료·환불·선수·미수·면세 대상·사업장현황 첨부 확인 | 귀속을 확인한 수입 연결과 연간 집계. 업종명으로 면세·현금주의를 자동 확정하지 않음 |
| 상가임대 | 계약별 보증금 변동일과 월세·부가세 포함 여부 확인 | 검증된 단일 상가의 일별 보증금 간주임대료와 매출세액 기여분 |
| 주택임대 | 주택 수·등록요건·총수입·다른 종합소득·주택 간주임대료 해당성 확인 | 2025년 확인된 등록/미등록 수입의 분리과세 필요경비·가중공제·감면 전 국세 |
| 수출·과세면세 겸영 | 영세율과 면세 구별, 수출·외화·공통매입 근거 확인 | 확인된 영세율 공급가액의 기본 부가세 작성표, 일반과세 공통매입 안분·소액 예외 |

Free는 이 표의 준비 질문·자료 목록·공식 경로와 사람이 확인할 항목을 제공한다. 계산 코드를 포함하지 않는다. Pro가 설치돼 있고 요청 조건이 맞으면 `jongsose-prep-kr`의 `references/industry-review.md`를 찾아 `industry_review.py`의 모드별 입력을 사용한다. 미설치라면 홈택스 공식 계산·입력 화면에서 직접 확인하도록 안내한다.

## 먼저 확인할 공통 사항

1. 여러 사업장·과세기간의 자료를 섞지 않았는가.
2. 금액은 공급가액인가, 부가세 포함 공급대가인가. 세금계산서·카드·현금영수증이 같은 거래의 대체 증빙은 아닌가.
3. 원자료가 전부 있는가. 알 수 없는 금액을 0으로, 확인하지 않은 요건을 충족으로 채우지 않았는가.
4. 신규·폐업·유형 전환·공동소유·특수관계·다른 업종·자산 조정 등 별도 조건이 있는가.
5. 산출액·홈택스 입력액·접수 결과·납부 결과를 각각 확인했는가.

## 질문 예시

- “음식점 일반과세자야. 반기 과세매출과 면세 식재료 자료가 있어. 의제매입 계산에 필요한 요건부터 확인해줘.”
- “쇼핑몰 정산액과 매출액이 달라. 환불·수수료를 구별하고 재고까지 넣어 원가를 확인해줘.”
- “상가 보증금이 중간에 바뀌었어. 날짜별로 어떤 자료를 준비해야 하는지 알려줘.”
- “학원 수강료에 선수금과 환불이 있어. 올해 수입금액을 확인할 표를 준비해줘.”
- “화면에 넣은 값과 계산값이 달라. 같은 사업장·기간·항목인지 먼저 확인해줘.”

## 범위 밖일 때

주택 보증금의 간주임대료 자체 계산, 감가상각·공동사업 전체·가산세·복잡한 영세율·외국납부·특수세목은 자료 목록과 전문 검토사항을 남긴다. 자동 계산을 했다고 표현하지 않는다. 기본 계산과 부분 금액 일치는 최종 세액·신고서 전체 검증이 아니다.

# 면세 개인사업자 사업장현황신고 준비

면세라고 모든 세무 절차가 없는 것은 아니다. 과세유형·실제 업종·귀속연도·겸영·휴폐업·소득 지급 방식을 확인한다. 사업자등록 없는 프리랜서도 실질을 확인하며 3.3% 원천징수 또는 소규모라는 말만으로 제외하지 않는다.

## 대상과 예외

- 면세 개인사업자는 원칙적으로 전년도 수입과 사업장 현황을 신고한다. 해당 기간의 휴폐업도 자동 제외 사유가 아니다.
- 국세청 제외 사례는 납세조합에 가입하여 수입금액을 신고한 자, 독립 보험모집 용역 제공자, 사업장 없이 일반 소비자에게 음료품을 배달하는 독립 계약배달 판매용역 제공자 등이다. 일반 방문판매원·배달플랫폼 기사 전체로 넓히지 않는다.
- 과세·면세 겸영자가 VAT 신고에 면세사업 수입금액 등을 신고한 경우 등 소득세법 제78조의 신고한 것으로 보는 경우를 확인한다. VAT 접수증만으로 면세 수입 반영까지 확인됐다고 하지 않는다.
- 신고 제외/간주신고와 종소세, 계산서합계표 등 부속 의무는 별개다. 가산세가 특정 업종에 한정된다고 신고의무까지 없다고 해석하지 않는다.

## 실행

1. 대상/제외/간주신고/확인필요와 근거를 기록한다. 제외 근거가 없으면 임의 면제하지 않는다.
2. 연간 채널별 수입, 계산서·카드·현금영수증·지급명세, 매입, 임차료·인건비, 업종별 수입금액검토(부)표 자료를 모은다. 홈택스 제공기간과 실제 연간 자료를 대조한다.
3. 해당 귀속연도의 기한·첨부를 확인한다. 법정 일반기한은 다음 해 2월 10일이나 휴일·연장기한은 별도 확인한다.
4. 사용자 로그인 후 홈택스에서 사업장현황신고를 검색해 현재 메뉴·연도·사업장을 확인한다. 신고서·검토표·계산서합계표를 자료와 대조하고 최종 제출은 사용자가 한다.
5. 실제 접수증을 열어 사업장현황신고 접수확인으로 기록한다. 납부 완료나 종소세 완료로 표시하지 않는다.

## 무료 기본 준비표

[빈 확인 양식](../assets/exempt-status-worksheet.json)을 사용자 지정 로컬 폴더에 복사한다. 모르는 항목은 null·unknown을 유지한다. 이 양식은 사람이 채우는 자료 목록이며 Pro 엔진 입력과는 다른 형식이다. 이름·사업자번호·주민번호·계좌·인증정보 대신 사업 가명과 원본 행 참조만 쓴다.

1. 귀속연도, 사업장, 개업·휴폐업에 따른 실제 대상 기간부터 확인한다. 여러 사업장·공동사업은 임의로 한 사람 지분 또는 한 사업장으로 합산하지 않는다.
2. 연간 수입 원장 한 벌을 기준으로 삼는다. 계산서·카드·현금영수증·플랫폼·통장 자료는 대조 자료다. 같은 거래를 여러 자료에서 찾아 더하지 않는다. 선수금·수입 귀속시기·전년 거래 환불은 별도로 확인한다.
3. 수입 합계, 증빙별 구성 합계, 업종별 수입 내역을 서로 대조한다. 확인된 0원과 미확보 자료를 구별한다. 매출이 없더라도 매입이나 시설·임대 내역이 있으면 무실적이라고 단정하지 않는다.
4. 매입액과 임차료·인건비는 별도로 정리한다. 사업장현황신고 수입에서 곧바로 빼거나 종소세 필요경비로 확정하지 않는다.
5. 각 항목에 `확보 / 일부 / 미확보 / 해당없음의 근거`를 남긴다. 홈택스 자료 제공 기간 밖의 내역과 종이·지연 전송 증빙도 대조한다.

| 준비 경로 | 추가로 모을 내역 | 주의할 점 |
|---|---|---|
| 학원 | 시설·직원·과목별 교습, 수강 인원·단가·수강료, 기타 수입, 기본경비 | 교습 내역과 수강료 명세를 대조. 월 임차료와 연간 비용의 단위를 구별 |
| 주택임대 | 가명 물건별 계약기간·월세·보증금 변동, 등록 요건 확인, 간주임대료 대상·계산 결과 | 보증금 원금을 수입에 넣지 않음. 간주임대료는 해당 연도 홈택스 계산·원본으로 확인 |
| 인적용역 | 실제 업종·면세 여부, 지급처별 연간 총액, 지급명세, 수수료·원천징수·입금 대조 | 원천징수·수수료 공제 후 입금액을 총수입으로 대체하지 않음. 3.3%라는 이유만으로 신고 제외하지 않음 |
| 기타 면세 | 실제 업종의 수입 내역, 업종별 수입금액검토(부)표·부속 서류 | 의료·농축수산물·주택신축판매 등은 해당 업종의 공식 서식을 별도 확인. 공통표만으로 준비 완료 처리하지 않음 |

## 홈택스에서 마무리

- 사용자 로그인 후 사업장현황신고를 검색하고 귀속연도·사업장·신고 유형을 확인한다. 지난 연도 불러오기는 변경 내역과 대조한다.
- 학원·주택임대는 수입금액검토표 내용을 먼저 준비한다. 수입금액·구성명세·검토표 합계가 일치하는지 확인한다. 계산서와 카드·현금영수증이 중복되는 거래는 계산서 구분을 확인한다.
- 매출처별 계산서, 매입처별 계산서·세금계산서 합계표와 업종별 첨부는 해당 여부를 확인해 대조한다. 자동 불러오기 성공만으로 모든 자료가 포함됐다고 하지 않는다.
- 최종 제출은 사용자가 한다. 실제 접수증에서 신고명·귀속연도·사업장·접수결과를 확인한다. 이후 종합소득세 준비는 별도 작업으로 이어간다.

## Pro 자료 집계 연결

Pro `jongsose-prep-kr` 설치 시 해당 스킬의 `references/business-status.md`와 `scripts/business_status.py --help`를 읽는다. 학원·주택임대·인적용역·기타 면세 경로별로 정리한 JSON의 수입·매입을 집계하고 증빙 누락, 중복, 환불 연결, 신고 항목 차이를 출력한다. 이 공개판에는 코드가 없으며 위 확인 양식으로 안내를 계속한다.

Pro 출력도 공식 신고서·수입금액검토표 완성본이 아니다. 업종별 원본 세부 항목은 사람이 확인하며 면세 여부·신고 의무·수입 귀속·간주임대료·세액을 자동 판정하거나 계산하지 않는다.

업종별 참고: [국세청 학원업 2025 귀속 PC 안내](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=2286&nttSn=1347986), [국세청 주택임대업 2025 귀속 PC 안내](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=2286&nttSn=1347992), [업종별 안내 목록](https://www.nts.go.kr/nts/na/ntt/selectNttList.do?bbsId=131040&mi=2286). 확인일 2026-09-12. 위 안내의 화면 순서·수치·서식 예시는 2025 귀속용이며 다른 연도에는 다시 확인한다.

근거: [소득세법 제78조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1032955831), [국세청 개요](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7699&mi=2283). 확인일 2026-09-12. 국세청 페이지의 기한 예시는 2025년 귀속·2026년 신고이므로 다른 연도에 그대로 쓰지 않는다. 법령 확인과 로그인 후 화면 검증은 다른 작업이다.

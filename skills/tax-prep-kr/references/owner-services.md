# 국세증명·환급금·세금포인트

무료 안내 범위이며 Pro biz-reg-hometax 설치가 없어도 설명할 수 있다. 자동 발급·신청·납부는 하지 않는다. 로그인·본인인증·최종 실행은 사용자다. 아래 명칭은 검색할 서비스 이름이며 현재 화면을 보지 않았다면 검증된 클릭 경로로 소개하지 않는다.

## 국세증명

1. 제출기관의 요구 문서명·용도·귀속/과세기간·사업장·국문/영문·식별정보 공개범위·발급일/유효기간 조건을 확인한다.
2. 사업자등록증명은 등록 사실, 소득금액증명은 소득, 부가가치세과세표준증명은 VAT 신고내역, 면세사업자수입금액증명은 면세 수입을 증명한다. 납세증명은 법정 예외를 제외한 체납 관련 증명이며 납부내역증명과 다르다. 국세 증명으로 지방세 증명 요구를 충족했다고 하지 않는다.
3. 홈택스 또는 정부24에서 정확한 서비스·자격·수령방법을 확인한다. [VAT 과세표준증명](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=12100000331), [납세증명](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=12100000011&HighCtgCD=A09002&Mcode=10020&srhQuery=2023). 온라인 대리신청 권한을 가정하지 않는다.
4. 사용자가 현재 화면에서 기간·용도·제출처·공개범위·수령방식을 확인한 뒤 직접 발급한다. 원본을 바꾸거나 마스킹 사본을 원본 증명서로 제출하게 하지 않는다.
5. 저장한 PDF를 열어 문서명·기간·페이지·빈 화면 여부·발급일·표시된 유효기간을 확인한다. 발급 안내/신청접수/파일 확인/외부 전달 상태를 구분한다. 자동 이메일·메신저 전송은 하지 않는다.

등록증 재발급·정정이 목적이면 Pro biz-reg-hometax로 연결한다. 미설치면 국세청의 사업자등록 안내와 홈택스 검색·준비서류까지만 안내한다. 증명 발급을 막는 체납·처리중 상태는 사실대로 기록하고 우회하지 않는다.

## 환급금

[국세청의 국세환급금 찾기](https://www.nts.go.kr/nts/main.do)에서 공식 홈택스로 이동한다. 본인정보·인증은 사용자가 입력한다. 조회기간·세목·귀속·결정/지급·미수령 여부를 확인하고, 지급됐다면 마스킹된 입금내역과 대조한다. 조회 결과 없음은 모든 연도·지방세까지 환급금이 없다는 뜻이 아니다.

신고서상 예상환급 / 공식 환급조회 / 계좌신고·변경 / 지급처리 / 실제 입금을 따로 기록한다. 계좌가 필요하면 사용자가 공식 화면에서 직접 등록한다. 환급금 조회는 경정청구·환급 확정·입금 보장이 아니다.

## 세금포인트

[국세청 세금포인트 제도](https://nts.go.kr/taxpayer_advocate/cm/cntnts/cntntsView.do?cntntsId=8300&mi=11494)에서 현재 혜택·대상·조건을 확인하고 사용자가 홈택스/손택스에서 조회한다. 포인트를 현금 환급액·납부 완료·세액공제로 환산하지 않는다. 담보면제 등은 별도 승인 요건이 있고 포인트 보유만으로 승인되지 않는다. 사용·쿠폰 발급·쇼핑몰 진입은 사용자가 선택한 경우만 안내한다.

확인일 2026-09-12. 국세증명 종류는 [국세청 안내](https://webtv.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=2207&nttSn=38162)도 참고했다. 이 과거 안내의 처리시간·종수·메뉴를 현재 보장하지 않는다. 실제 계정 조회·발급·환급계좌 변경은 문서 작성 중 실행하지 않았다.

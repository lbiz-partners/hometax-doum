# 이번 달 할 일: 개인사업자용

프로필 가명·확인일, 점검월, 실제 과세유형과 변경 여부부터 확인한다. 직원 0명이어도 외주·강사료·일용 지급은 별개다. 무료는 수동 체크리스트, Pro jongsose-prep-kr 설치 시 프로필/체크리스트 검증과 월마감 엔진을 쓴다.

## 모든 달의 자료 점검

- 판매채널별 매출 원장, 홈택스 전자 자료, 플랫폼 정산명세, 사업 관련 입금의 수집 시작일·종료일·누락 여부를 기록한다. 일부 기간이나 미반영 자료를 월 전체 0원으로 보지 않는다.
- 사업용카드 등록·사용내역, 개인카드 사업 사용분, 지출증빙 현금영수증, 세금계산서를 모아 receipt-classify-kr로 중복·취소·업무 관련성 검토를 넘긴다.
- 매출·정산·입금 차이는 tax-invoice-hometax의 매출/정산 점검으로 연결한다. 입금만 보고 매출을 확정하지 않는다.
- 외주·일용 지급이 있으면 계약·실제 업무·지급일·총액·증빙·거주자 여부를 모은다. Pro 원천세 미설치면 자료와 공식 절차를 안내하며 세율 계산은 하지 않는다.
- 지난 신고의 접수증, 국세 납부, 지방세 신고·납부, 환급을 각각 확인한다. 지난달 미확인을 자동 완료 처리하지 않는다.

## 납부준비금

확정 고지액·신고서 납부액, 엔진 예상액, 사용자가 정한 임시 적립 목표를 별도 줄로 둔다. 세목·기간·기납부·분납 잔액·준비해 둔 잔액·다음 기한을 연결한다. 예상세액은 확정 납부액이 아니며 적립·계좌이체 자체가 세금 납부도 아니다. 미확인 금액에 임의 적립률을 적용하지 않는다. Pro는 검증된 입력과 코드 집계 결과, 무료는 납부서/공식 화면 금액과 자료 부족 목록을 정리한다.

# 일정·자료원 참고

해마다 공지 확인. 이 파일은 감각용이다.

귀속연도/과세기간, 실제·예정 신고일, 법정기한, 개별 연장기한을 따로 기록한다. 신고기한 연장과 납부기한 연장을 동일하게 취급하지 않는다. 모든 신고일을 5/31 또는 25일로 고정하지 않는다.

## 부가세 달력 (개인 일반과세자)

| 구분 | 과세기간 | 신고기한 감각 |
| --- | --- | --- |
| 1기 예정고지·예외 예정신고 확인 | 1~3월 관련 | 4월 |
| 1기 확정 | 1~6월 | 7월 |
| 2기 예정고지·예외 예정신고 확인 | 7~9월 관련 | 10월 |
| 2기 확정 | 7~12월 | 다음 해 1월 |

개인 일반과세자는 통상 연 2회 확정신고한다. 4·10월에는 실제 예정고지와 제외·예외 예정신고 요건을 확인하며 모든 개인에게 예정신고서를 만들지 않는다. [국세청 신고납부기한](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7694&mi=2273)(2026-09-12 확인)을 기준으로 [월별 체크리스트](monthly-owner-checklist.md)에서 본인에게 적용되는 일정을 고른다.

## 종소세 달력

| 구분 | 감각 |
| --- | --- |
| 정기신고 | 귀속 다음 해 5월 |
| 성실신고확인서 제출 | 통상 귀속 다음 해 6월 30일 |
| 중간예납 | 해당 시 홈택스 고지 확인 |

## 자료원별 역할과 대조

1. 매출 원장: 거래 사건과 귀속일, 취소·환불을 확인한다.
2. 홈택스 전자 자료: 세금계산서·카드·현금영수증·지급명세 등 증빙과 반영 기간을 대조한다.
3. 플랫폼 정산명세: 정산 대상 매출·환불·수수료·정산일을 확인한다.
4. 은행·카드사 자료: 실제 입출금과 결제 내역을 확인한다.
5. 사용자 장부·종이 영수증: 앞의 자료에 누락된 거래와 업무 관련성의 근거를 보완한다.

한 자료원이 모든 매출·입금·공제 사실을 대신하지 않는다. 자료별 조회 기간과 누락을 확인하고 차이를 목록으로 남긴다. 같은 거래의 카드·세금계산서·입금을 각각 매출로 더하지 않는다. 세무상 기준은 해당 기간 법령·국세청 안내, 화면 경로와 입력·접수·납부 결과는 현재 홈택스에서 각각 확인한다.

## 공식 확인 경로 (2026-09-12 확인)

- [국세청 2026년 1기 부가세 확정신고 안내](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=2201&nttSn=1352987): 그해 실제 마감일, 세금계산서 발급 간이과세자와 과세유형 전환자의 신고기간을 대조한다. 다음 연도의 마감일 근거로 재사용하지 않는다.
- [소득세법 §70의2②](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=02&joNo=0070&lsiSeq=280405&urlMode=lsScJoRltInfoR), [국세기본법 §5](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0005&lsiSeq=288571&urlMode=lsScJoRltInfoR): 성실신고확인서 제출 기한과 토요일·공휴일 등 기한 특례.
- 종소세의 전자신고 공제·기한후신고 판정은 `income-tax-hometax`의 `references/tax-policy.md`, 부가세 과세유형·공제는 `vat-hometax`의 동명 자료로 인계한다.

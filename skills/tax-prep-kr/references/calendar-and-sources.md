# 일정·자료원 참고

해마다 공지 확인. 이 파일은 감각용이다.

귀속연도/과세기간, 실제·예정 신고일, 법정기한, 개별 연장기한을 따로 기록한다. 신고기한 연장과 납부기한 연장을 동일하게 취급하지 않는다. 모든 신고일을 5/31 또는 25일로 고정하지 않는다.

## 부가세 달력 (일반)

| 구분 | 과세기간 | 신고기한 감각 |
| --- | --- | --- |
| 1기 예정 | 1~3월 | 4월 |
| 1기 확정 | 1~6월 | 7월 |
| 2기 예정 | 7~9월 | 10월 |
| 2기 확정 | 7~12월 | 다음 해 1월 |

## 종소세 달력

| 구분 | 감각 |
| --- | --- |
| 정기신고 | 귀속 다음 해 5월 |
| 성실신고확인서 제출 | 통상 귀속 다음 해 6월 30일 |
| 중간예납 | 해당 시 홈택스 고지 확인 |

## 자료원 우선순위

1. 홈택스 전자 자료 (세금계산서, 카드, 현금영수증, 지급명세)
2. 카드사·은행 export
3. 사용자 엑셀 장부
4. 종이 영수증 사진

충돌 시: 홈택스 전자 자료를 1차 기준으로 두고, 사용자 장부와 차이 목록을 만든다.

## 공식 확인 경로 (2026-09-12 확인)

- [국세청 2026년 1기 부가세 확정신고 안내](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=2201&nttSn=1352987): 그해 실제 마감일, 세금계산서 발급 간이과세자와 과세유형 전환자의 신고기간을 대조한다. 다음 연도의 마감일 근거로 재사용하지 않는다.
- [소득세법 §70의2②](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=02&joNo=0070&lsiSeq=280405&urlMode=lsScJoRltInfoR), [국세기본법 §5](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0005&lsiSeq=288571&urlMode=lsScJoRltInfoR): 성실신고확인서 제출 기한과 토요일·공휴일 등 기한 특례.
- 종소세의 전자신고 공제·기한후신고 판정은 `income-tax-hometax`의 `references/tax-policy.md`, 부가세 과세유형·공제는 `vat-hometax`의 동명 자료로 인계한다.

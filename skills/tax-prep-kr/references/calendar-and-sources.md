# 일정·자료원 참고

해마다 공지 확인. 이 파일은 감각용이다.

## 부가세 달력 (일반)

| 구분 | 과세기간 | 신고기한 감각 |
| --- | --- | --- |
| 1기 예정 | 1~3월 | 4월 |
| 1기 확정 | 1~6월 | 7월 |
| 2기 예정 | 7~9월 | 10월 |
| 2기 확정 | 7~12월 | 다음 해 1월 |

## 종소세 달력

| 구분 | 감각 |
| --- | --- |
| 정기신고 | 귀속 다음 해 5월 |
| 중간예납 | 해당 시 홈택스 고지 확인 |

## 자료원 우선순위

1. 홈택스 전자 자료 (세금계산서, 카드, 현금영수증, 지급명세)
2. 카드사·은행 export
3. 사용자 엑셀 장부
4. 종이 영수증 사진

충돌 시: 홈택스 전자 자료를 1차 기준으로 두고, 사용자 장부와 차이 목록을 만든다.

# 홈택스 세무 허브 (hometax-tax-hub)

동료·일반 개인사업자/프리랜서가 **홈택스 부가세·종합소득세·전자세금계산서**를 스스로 준비·점검·신고/발급 직전까지 진행하도록 돕는 통합 진입점이다.

개인 맞춤 프로필 없이 동작한다. 시작 시 짧은 인터뷰로 대상을 파악한다.

## 스킬 맵

| 하위 스킬 | 역할 |
| --- | --- |
| `tax-prep-kr` | 무엇을 모을지, 폴더·일정·다운로드 준비 |
| `receipt-classify-kr` | 영수증·카드·현금 지출 분류 (부가세/종소세 관점) |
| `vat-hometax` | 홈택스 부가가치세 신고 (제출 직전) |
| `tax-invoice-hometax` | 홈택스 전자세금계산서 발급·수정·조회 |
| `income-tax-hometax` | 홈택스 종합소득세 신고 (제출 직전) |
| `jongsose-prep-kr` (🔒 Pro, 별매) | 종소세 **예상세액 계산 엔진** — "얼마 나와?"·겸업(사업+근로) 합산·분납·성실신고 판정 |

이 허브는 라우팅·순서 안내를 담당한다. 세부 절차는 해당 스킬 `SKILL.md`를 읽고 따른다.

> 라우팅 원칙: **계산·예상세액**("세금 얼마 나와?") → `jongsose-prep-kr`(🔒 Pro 별매, 설치 시) / **홈택스 화면 진행** → `vat-hometax`·`tax-invoice-hometax`·`income-tax-hometax`. 이 모음의 신고·발급 스킬들은 세액을 계산하지 않는다 — 계산은 엔진 스킬, 화면은 여기. **엔진 미설치 시**: "예상세액 계산은 Pro 엔진(별매)에서 제공됩니다 — README의 Pro 안내 참조"라고 한 줄 안내하고, 홈택스 화면 진행은 그대로 돕는다.

## 공통 절대 규칙

1. **자동 제출·납부·세금계산서 발급 금지.** 매번 사용자 확인: `이 내용으로 신고/납부/발급 진행해도 될까요?`
2. **비밀번호/인증서 비밀번호/OTP/간편인증 직접 입력 금지.** 로그인은 사용자.
3. 없는 자료를 지어내지 않는다. 누락은 목록으로 보고.
4. 세무 판단은 **후보 + 근거 + 확인 질문**. 단정 금지.
5. 법·기준·메뉴는 변동 가능 → **현재 홈택스 화면**을 최종 근거.
6. 주민번호·계좌 등은 마스킹. 동료 세션에서도 동일.
7. 모든 최종 보고 말미에 표준 면책:  
   `본 도구는 신고 준비를 돕는 **소프트웨어**이며, 「세무사법」 제2조의 세무대리(신고 대리·세무조정계산서 등 서류 작성·장부작성 대행·조세 상담/자문·성실신고 확인)를 수행하지 않습니다. 제공자는 세무사가 아닐 수 있으며, 자격 유무와 무관하게 본 도구는 세무대리·유상 세무상담이 아닙니다(신고서 작성·제출을 대행하지 않음). 신고·납부의 최종 판단·책임은 이용자 본인에게 있고, 세무대리·상담이 필요하면 「세무사법」 제6조에 따라 등록한 세무사에게 위임하세요. 금액이 크거나 애매하거나 범위 밖(세무조사·법인세·성실신고 대행 등)이면 세무사 상담을 권합니다. 자세한 조건은 LICENSE.md 참조.`

## 시작 인터뷰 (필수, 짧게)

요청이 모호하면 먼저 확인:

```text
무엇을 도와드릴까요?
1) 신고 준비 (무엇을 모을지)
2) 영수증·카드 분류
3) 부가세 신고 (홈택스)
4) 전자세금계산서 발급/조회
5) 종합소득세 신고 (홈택스)
6) 처음부터 순서대로 (준비 → 분류 → 신고)

추가로 알려주세요:
- 사업 형태: 개인사업 / 프리랜서(사업자 없음) / 근로+부업 / 잘 모르겠음
- 과세유형(알면): 일반 / 간이 / 모름
- 대상 기간: 예) 2026년 1기 부가세, 2025년 귀속 종소세
- 자료: 홈택스만 / 엑셀 있음 / 카드·영수증 파일 있음
```

답을 받으면 아래 라우팅.

## 라우팅 규칙

| 사용자 신호 | 이동 |
| --- | --- |
| 준비, 뭘 받아야, 서류, 일정, 폴더, 자료가 거의 없어 | `tax-prep-kr` (부가세만이고 홈택스 로그인이 되면 바로 `vat-hometax` 미리채움도 가능) |
| 영수증, 카드 내역, 계정과목, 공제/불공제 분류 | `receipt-classify-kr` |
| 부가세, 매출세액, 매입세액, 예정·확정신고 | `vat-hometax` |
| 세금계산서 발행/발급, 전자세금계산서, 수정세금계산서, 계산서 끊어 | `tax-invoice-hometax` |
| 종합소득세, 종소세, 모두채움, 경비율, 5월 신고 | `income-tax-hometax` |
| 세금 얼마 나와, 예상세액, 분납, 성실신고 판정 | `jongsose-prep-kr` (🔒 Pro 별매, 설치 시) |
| 처음부터, 전체 흐름 | 순서: prep → classify → (invoice 및/또는 vat 및/또는 income) |
| 경정청구·환급 심화 | 기본 범위 밖. 일반 원칙만 안내 후, 세무사/별도 심화 스킬 권고 |

## 권장 전체 순서 (동료 온보딩용)

```text
1. tax-prep-kr        기간 확정 + 자료 체크리스트 + 폴더
2. receipt-classify-kr  카드/영수증 분류표 완성
3. tax-invoice-hometax  (매출 세금계산서 발급이 필요하면 신고 전)
4. vat-hometax 또는 income-tax-hometax
   - 분기/반기면 부가세 먼저
   - 5월이면 종소세 (부가세 자료는 수입·경비 대조에 재사용)
5. 제출/발급 직전 QA → 사용자 확인 → 제출·납부·발급은 확인 후
```

### 부가세 실무 힌트 (허브 → vat 넘길 때)

- 자료가 거의 없어도 **홈택스 미리채움**으로 1차 골격 가능
- 미리채움 상단 납부세액만 보고 끝내지 말 것 → `vat-hometax`에서 **전자신고 세액공제** 등 공제·감면 반영 여부 확인 (입력완료 전 0으로 보일 수 있음)
- 세금계산서 합계 상세는 합계표 **자료조회**로 거래처별 확인

## 허브 응답 포맷

라우팅 직전 한 줄로 고지:

```text
[허브] {선택 작업} → `{skill-name}` 스킬로 진행합니다.
```

작업 끝나면 다음 추천 1개를 제안:

- 준비 끝 → 분류 할까요?
- 분류 끝 → 세금계산서 발급 / 부가세 / 종소세 중 어떤 작업인가요?
- 세금계산서 발급 끝 → 부가세 신고 대조할까요?
- 신고 직전 완료 → 제출 확인만 남았습니다.

## 범위

**포함:** 개인사업자·프리랜서 중심 홈택스 부가세/종소세 준비·분류·신고 보조, 전자세금계산서 발급 보조  
**제외(기본):** 법인 법인세 전체, 성실신고 대행, 세무조사 대응, 양도·상속, 공격적 절세 설계, 허위 세금계산서  
제외 영역은 “전문가 검토 권고”로 안내하고 무리하게 진행하지 않는다.

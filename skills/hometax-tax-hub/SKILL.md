# 홈택스 세무 허브 (hometax-tax-hub)

동료·일반 개인사업자/프리랜서가 **홈택스 부가세·종합소득세·전자세금계산서·원천세·사업자등록**을 스스로 준비·점검·신고/발급 직전까지 진행하도록 돕는 통합 진입점이다.

1인 소규모 개인사업자를 기본 독자로 하되, 실제 과세유형·직원·외주 지급 여부는 확인한 값만 쓴다. 사용자가 선택한 로컬 **가명 사업 프로필 JSON**이 있으면 재사용하고, 없으면 이번 작업에 필요한 정보만 묻는다. 프로필 저장은 선택이며 세무 자료나 인증정보를 자동 수집하지 않는다. 자세한 규칙은 [공통 프로필](references/owner-profile.md), 신고 후 확인은 [상태 기록](references/filing-status.md).

## 스킬 맵

| 하위 스킬 | 역할 |
| --- | --- |
| `tax-prep-kr` | 이번 달 체크리스트·폴더·자료 수집, 면세 사업장현황신고 준비, 국세증명·환급금·세금포인트 조회 안내 |
| `receipt-classify-kr` | 영수증·카드·현금 지출 분류 (부가세/종소세 관점) |
| `vat-hometax` | 홈택스 부가가치세 신고 (제출 직전) |
| `tax-invoice-hometax` | 홈택스 전자세금계산서 발급·수정·조회·**미수금 점검** |
| `income-tax-hometax` | 홈택스 종합소득세 신고 (제출 직전) |
| `withholding-tax-hometax` (🔒 Pro, 설치 시) | 홈택스 **원천세(인건비) 신고** — 원천징수이행상황신고서·지급명세서·간이지급명세서, 근로/일용/사업3.3%/기타 + 예상 원천징수 엔진 |
| `jongsose-prep-kr` (🔒 Pro, 설치 시) | 종소세 **예상세액 계산 엔진**, 프로필·월별 체크리스트·신고상태 검증, 월마감 대량 대조·납부준비금 집계 |
| `biz-reg-hometax` (🔒 Pro, 설치 시) | 개인 사업자등록 신청·정정(업종/사업목적 추가)·결과조회/재발급 + 통신판매업(정부24) 연계 |

이 허브는 라우팅·순서 안내를 담당한다. 세부 절차는 해당 스킬 `SKILL.md`를 읽고 따른다.

> 라우팅 원칙: 계산 요청도 먼저 세목을 구분한다. **개인 종소세 예상세액**은 설치된 `jongsose-prep-kr`, **원천징수 계산**은 설치된 `withholding-tax-hometax` 엔진으로 진행한다. **미수금 대조**는 `tax-invoice-hometax`에 엔진 파일이 있으면 실행하고, 무료처럼 없으면 해당 스킬의 원자료·수동 표·건별 질문·합계 대조로 진행한다. 부가세는 `vat-hometax`에서 원자료와 홈택스 신고 내용을 대조하며 종소세 엔진을 적용하지 않는다. 세목을 알 수 없는 "세금 얼마 나와?"는 확인한다. 종소세·원천징수 계산 엔진이 없으면 예상세액 계산은 중단하고 자료·화면 안내를 계속한다. 수동 미수금 검토를 Pro 엔진 검증으로 소개하지 않는다. 법인세는 Pro 지원 범위 밖이다.

## 공통 절대 규칙

1. **자동 제출·납부·세금계산서 발급 금지.** 매번 사용자 확인: `이 내용으로 신고/납부/발급 진행해도 될까요?`
2. **비밀번호/인증서 비밀번호/OTP/간편인증 직접 입력 금지.** 로그인은 사용자.
3. 없는 자료를 지어내지 않는다. 누락은 목록으로 보고.
4. 세무 판단은 **후보 + 근거 + 확인 질문**. 단정 금지.
5. 법·기준은 해당 기간의 **공식 법령·국세청 안내**, 메뉴·입력값은 **현재 홈택스 화면**으로 확인한다. 충돌은 확인필요로 남긴다. 과거 화면 경로를 현재 접속·검증했다고 보고하지 않는다.
6. 주민번호·계좌 등은 마스킹. 동료 세션에서도 동일.
7. 모든 최종 보고 말미에 표준 면책:  
   `본 도구는 신고 준비를 돕는 **소프트웨어**이며, 「세무사법」 제2조의 세무대리(신고 대리·세무조정계산서 등 서류 작성·장부작성 대행·조세 상담/자문·성실신고 확인)를 수행하지 않습니다. 제공자는 세무사가 아닐 수 있으며, 자격 유무와 무관하게 본 도구는 세무대리·유상 세무상담이 아닙니다(신고서 작성·제출을 대행하지 않음). 신고·납부의 최종 판단·책임은 이용자 본인에게 있고, 세무대리·상담이 필요하면 「세무사법」 제6조에 따라 등록한 세무사에게 위임하세요. 금액이 크거나 애매하거나 범위 밖(세무조사·법인세·성실신고 대행 등)이면 세무사 상담을 권합니다. 자세한 조건은 LICENSE.md 참조.`

## 시작 인터뷰 (필수, 짧게)

프로필 또는 다른 스킬의 인계값이 있으면 같은 질문을 반복하지 않는다. 사업 가명·대상 기간·확인일을 먼저 보여 주고 과세유형 변경, 새 판매채널, 직원 채용, 이번 달 외주 지급 등 **변경된 항목만 확인**한다. 직원 0명이어도 강사료·디자인비 등 외주 지급은 별개다. `미확인`을 `없음/0원`으로 바꾸지 않는다.

요청이 모호하면 먼저 확인:

```text
무엇을 도와드릴까요?
1) 신고 준비 (무엇을 모을지)
2) 영수증·카드 분류
3) 부가세 신고 (홈택스)
4) 전자세금계산서 발급/조회/미수금 점검
5) 종합소득세 신고 (홈택스)
6) 원천세(인건비) 신고 — 직원·일용직·프리랜서 지급분
7) 사업자등록 신청·정정 / 업종 추가 / 통신판매업
8) 처음부터 순서대로 (준비 → 분류 → 신고)

추가로 알려주세요:
- 사업 형태: 개인사업 / 프리랜서(사업자 없음) / 근로+부업 / 법인 / 잘 모르겠음
- 과세유형(알면): 일반 / 간이 / 면세 / 과세·면세 겸영 / 모름
- 직원 유무와 별개로 외주·강사·일용 지급이 있었는지
- 대상 기간: 예) 2026년 1기 부가세, 2025년 귀속 종소세
- 자료: 홈택스만 / 엑셀 있음 / 카드·영수증 파일 있음
```

답을 받으면 아래 라우팅. "세금 얼마"처럼 세목이 불명확하면 종소세로 단정하지 말고 소득세·부가세·원천세 중 무엇인지 확인한다. 법인세 요청은 Pro 지원 범위 밖이라고 안내한다. 별도 Ultra는 향후 계획이며 설치되거나 사용 가능한 기능으로 소개하지 않는다.

## 권장 전체 순서 (동료 온보딩용)

```text
1. tax-prep-kr        기간 확정 + 자료 체크리스트 + 폴더
2. receipt-classify-kr  카드/영수증 분류표 완성
3. tax-invoice-hometax  (매출 세금계산서 발급이 필요하면 신고 전)
4. vat-hometax 또는 income-tax-hometax 또는 withholding-tax-hometax
   - 실제 과세유형·대상 기간·검증된 마감일에 맞는 작업부터
   - 모두채움 안내 대상이면 소득 누락·공제·기납부를 확인하는 짧은 경로
   - 직원 없이 외주·일용·강사료 지급이 있으면 원천세 대상 여부 확인
5. 제출/발급 직전 QA → 사용자 확인 → 제출·납부·발급은 확인 후
(별도) biz-reg-hometax — 업종 추가·사업자등록 정정·통신판매업이 필요할 때
```

### 부가세 실무 힌트 (허브 → vat 넘길 때)

- 자료가 거의 없어도 **홈택스 미리채움**으로 1차 골격 가능
- 미리채움 상단 납부세액만 보고 끝내지 말 것 → `vat-hometax`에서 **전자신고 세액공제** 등 공제·감면 반영 여부 확인 (입력완료 전 0으로 보일 수 있음)
- 세금계산서 합계 상세는 합계표 **자료조회**로 거래처별 확인

## 허브 응답 포맷

계산·분류를 실행한 결과와 단순 안내를 구분한다. 계산 실패나 미지원 입력이면 오류 사유와 필요한 자료를 안내하고, LLM 암산으로 대체하지 않는다. 종소세 PDF는 동봉 엔진 결과와 검산한 상태를 확인하며, 초안·미검산 결과를 확정 세액으로 소개하지 않는다.

라우팅 직전 한 줄로 고지:

```text
[허브] {선택 작업} → `{skill-name}` 스킬로 진행합니다.
```

작업 끝나면 다음 추천 1개를 제안:

- 준비 끝 → 분류 할까요?
- 분류 끝 → 세금계산서 발급 / 부가세 / 종소세 / 원천세 중 어떤 작업인가요?
- 세금계산서 발급 끝 → 부가세 신고 대조할까요? / 미수금 점검할까요?
- 신고 직전 완료 → 제출 확인만 남았습니다.

무료 6종만 설치돼도 자료 수집·거래별 검토·현재 화면 대조·신고 후 증빙 확인은 계속한다. Pro 스킬이나 실행 파일이 없으면 대량 계산·자동 검증을 실행했다고 표시하지 않는다. 미수금 등 기존 기능은 설치된 해당 스킬의 실행 조건을 그대로 따른다. 실제 접수증을 확인한 뒤에도 **국세 납부·지방 신고·지방 납부·환급 입금**은 각각 별도 상태로 보고한다.

## 범위

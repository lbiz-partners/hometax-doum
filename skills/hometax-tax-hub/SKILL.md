# 홈택스 도움 — 개인사업자 업무 허브

사용자의 일상 요청을 [24개 업무 목록](references/service-catalog.md)에서 필요한 절차로 연결한다. 모든 문서를 한꺼번에 읽지 않는다. 명확한 부가세·종소세·계산서·지출분류 요청은 해당 스킬로 바로 연결한다.

<!-- block:live-screen -->
실제 화면에서는 개인/사업자 상태와 추가 인증·설치·신고기간 제한을 확인한다. 조회 전 초기 값과 조회 후 결과, 작성 화면과 실제 접수·발급·납부를 구별한다. 빈 결과는 선택한 기간·자료원 안에서만 해석한다.
<!-- /block -->

## 처음에 확인할 것

1. **기준일**: 오늘 날짜를 시스템 시계에서 읽거나 사용자에게 확인한다. 추정하지 않는다. 전자신고 공제 금액, 기한후 여부, 경과일수, 지원 기간 판단이 모두 이 날짜에 걸린다. 모든 보고 머리에 `기준일 YYYY-MM-DD (출처: 시스템/사용자)`를 적는다.
2. **설치 판별**: [Pro 설치 탐지](references/pro-detection.md)를 한 번 실행하고 첫 보고 첫 줄에 `Free 모드` 또는 `Pro 탐지`를 선언한다. Free 모드에서는 허브 본문과 보고에 Pro 도구명을 쓰지 않고, 참고 문서에 "설치돼 있으면 실행"으로 적힌 Pro 도구를 찾지 않는다.
3. **사업장**: 사업장 가명·대상 기간·목적을 확인한다. 기존 [가명 프로필](references/owner-profile.md)이 있으면 변경점만 묻는다. 직원 유무와 외주 지급 여부는 별개이며 미확인을 0원·없음으로 바꾸지 않는다. 일반·간이·면세·겸영은 해당 기간 기준이다.

"세금 얼마"는 세목부터 구별한다. 종소세 엔진을 부가세·법인세에 적용하지 않는다. 원천세 준비와 직원 연말정산 전체 계산도 구별한다.

## Pro 연동

[Pro 설치 탐지](references/pro-detection.md) 결과가 `Pro 탐지`일 때만 [Pro 연동](references/pro-integration.md)을 읽고 확인된 엔진만 실행한다. `Free 모드`에서는 허브 본문과 보고에 Pro 도구명을 쓰지 않고 안내·자료 준비·수동 대조로 같은 절차를 끝까지 진행한다. 실행하지 않은 엔진을 사용했다고 표시하지 않으며, 엔진 오류를 AI 암산으로 대신하지 않는다.

## 진행과 완료

1. 필요한 자료와 현재 할 일을 알려준다. 자료가 충분하면 같은 질문을 반복하지 않는다.
2. 자료 출처·기간·누락과 입력값을 확인한다. 법은 적용연도 공식 법령·국세청 자료, 화면은 실제 현재 화면으로 확인한다.
3. 최종 신청·신고·발급·납부 내용은 본인이 확인하고 직접 진행한다. 로그인·인증·비밀번호·OTP는 사용자에게 맡긴다. 자동 제출·납부·발급 금지.
4. [상태 기록](references/filing-status.md)에 접수·국세납부·지방신고·지방납부·환급입금을 각각 기록한다. 신청 접수와 승인, 파일 생성과 발급 결과를 구별한다.
5. 완료 보고는 `기준일·모드(Free/Pro) / 확인한 결과 / 근거 증빙 / 미확인·남은 일 / 다음 행동`으로 작성한다. 통합 요청이면 필요한 다음 업무를 연결한다.

자료가 없으면 해당 항목을 미확인으로 남기며 임의로 0원·완료를 만들지 않는다. 주민번호·계좌 등은 가명·마스킹한다. 법인세·성실신고확인·세무조사·불복·재산세목의 전문 판단은 별도 전문가에게 연결하고 구체적인 준비자료를 제공한다.

# Pro 설치 탐지 절차

이 스킬 모음은 Free 6종과 Pro 9종이 같은 안내 문서를 공유한다. 계산 엔진은 Pro에만 있다. 어느 쪽이 설치돼 있는지는 **문서를 읽어서 알 수 없고 파일 존재로만 판정**한다. 대화 시작 시 한 번 실행하고, 결과를 첫 보고에 한 줄로 선언한다. 추측·기억·이전 대화의 결과를 재사용하지 않는다.

## 1. 확인할 파일

아래 **엔진 파일 세 개** 중 하나라도 실제로 존재하면 Pro 탐지다. 존재 확인은 파일 시스템 조회(디렉터리 목록 또는 존재 검사)로 한다. 파일을 실행하거나 내용을 읽을 필요는 없다. SKILL.md 존재는 신호가 아니다(동명 스킬의 옛 사본이 남아 있을 수 있다).

| 엔진 | 상대 경로 (스킬 폴더 기준) |
|---|---|
| 종소세 예상세액 | `jongsose-prep-kr/assets/jongsose_engine.py` |
| 원천징수 예상액 | `withholding-tax-hometax/assets/withholding-engine.mjs` |
| 미수금 대조 | `tax-invoice-hometax/assets/receivables-engine.mjs` |

## 2. 어디를 보는가

**두 곳을 모두 본다.** (1) 이 SKILL.md가 로드된 폴더의 상위 폴더(플러그인 설치면 플러그인 캐시 안의 `skills/`), (2) 아래 사용자 홈의 스킬 폴더 중 존재하는 것. 플러그인으로 Free를 설치한 사용자가 Pro를 홈 폴더에 폴더 설치한 경우가 있으므로 (1)만 보고 Free 모드로 단정하지 않는다. 후보 밖의 개인 폴더를 넓게 뒤지지 않으며, 폴더마다 목록 조회 한 번이면 된다.

| 앱 | 스킬 폴더 |
|---|---|
| Claude Code 폴더 설치 | `~/.claude/skills/` |
| Codex | `~/.codex/skills/` |
| Aside | `~/.aside/u/0/skills/user/` (구버전: `~/.aside/u/0/agents/main/skills/user/`) |
| Claude Desktop 등 `.skill` 업로드 앱 | 파일 시스템을 볼 수 없으면 3절의 "판별 불가" 규칙 (사용자에게 묻는다) |

## 3. 선언 문구 (첫 보고 첫 줄)

- 하나 이상 존재: `Pro 탐지 · 사용 가능한 엔진: 종소세 / 원천세 / 미수금 중 실제로 확인된 것만` (사업자등록 전용 스킬 `biz-reg-hometax`는 탐지 뒤 같은 폴더에 있을 때만 사용)
- 전부 없음: `Free 모드 · 안내·자료 준비·수동 대조로 진행`
- 파일 시스템을 조회할 수 없는 앱(`.skill` 업로드 등): 첫 보고 전에 한 번 묻는다 — "업로드한 스킬 목록에 jongsose-prep-kr, withholding-tax-hometax, biz-reg-hometax가 있나요?" 있다고 답하면 `Pro(사용자 확인) · 해당 스킬을 이름으로 호출`로 선언하고, 그 스킬이 실제로 실행돼 결과를 낸 경우에만 엔진 사용으로 표시한다. 없다거나 모르면 `Free 모드 · 안내·자료 준비·수동 대조로 진행`. 파일이 보이지 않는다는 이유만으로 Pro 구매자를 Free 모드로 내리지 않는다.

선언 뒤의 동작:

- **Free 모드**에서는 허브 본문과 보고에서 Pro 도구 파일명(`.py` · `.mjs`)과 Pro 전용 스킬명을 쓰지 않는다. 참고 문서에 "설치돼 있으면 실행"으로 적힌 Pro 도구는 Free 모드에서 실행 대상이 아니며 찾지 않는다. 계산이 필요한 지점은 "홈택스 공식 화면의 계산 결과를 확인"으로 안내한다. 대화 마지막에 Pro가 있으면 무엇이 자동화되는지 한 줄만 덧붙일 수 있다.
- **Pro 탐지**에서는 [Pro 연동](pro-integration.md)을 읽고, 확인된 엔진만 실행한다. 존재를 확인하지 못한 엔진은 없는 것으로 다룬다.
- 엔진 실행이 실패하면 오류를 그대로 보고하고 수동 절차로 계속한다. AI 암산으로 대신하지 않는다.

## 4. 하지 않는 것

- 존재 확인 없이 "Pro가 설치돼 있다면"으로 진행하지 않는다.
- 사용자가 "Pro 샀어요"라고 말해도 파일이 없으면 Free 모드다. 설치 방법을 안내한다.
- 엔진 파일을 새로 만들거나 다른 경로에서 복사하지 않는다.

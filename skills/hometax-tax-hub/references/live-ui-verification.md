## 실제 계산 대조 사례

2025년 미등록 주택 1개, 연간 임대수입 12,000,000원, 임대 외 소득 0원인 가상 사례를 주택임대 종합·분리과세 모의계산에 입력했다. 종합과세 비교용 장부 필요경비는 6,000,000원, 감면은 적용하지 않았다. 아래 비교는 **분리과세 열**에 한정한다.

| 항목 | 홈택스 화면 | Pro 엔진 |
|---|---:|---:|
| 수입금액 | 12,000,000 | 12,000,000 |
| 필요경비 | 6,000,000 | 6,000,000 |
| 공제금액 | 2,000,000 | 2,000,000 |
| 과세표준 | 4,000,000 | 4,000,000 |
| 감면 전 산출국세 | 560,000 | 560,000 |

결과는 `matched_selected_fields`다. 홈택스는 이 가상 사례에서 종합과세 결정세액 200,000원도 표시했지만, Pro의 `residential_separate`는 종합과세 비교·유리한 신고 선택·지방세·건강보험료를 계산하지 않는다. 모의계산의 일치는 실제 신고서 입력이나 신고 완료의 증거가 아니다. 홈택스 자체 안내도 모의계산 결과를 신고·불복자료로 사용할 수 없다고 명시한다.

H12의 업종코드 조회는 2025년 701102 한 건의 결과를 확인했다. 화면에는 2026년 귀속 경비율은 2027년 4월 이후 조회 가능하다는 안내가 있다. 경비율과 주택임대 분리과세의 법정 필요경비율을 혼용하지 않는다.

## 로그인 후 검증을 이어가는 방법

1. 사용자가 직접 본인 인증을 완료하고 검사할 사업장·기간·권한을 확인한다. 비밀번호·OTP·인증서 비밀값을 대화나 파일에 받지 않는다.
2. 위 표의 업무를 선택하고 현재 화면의 명칭·연도·사업자 유형을 다시 확인한다. 공개 경로와 로그인 후 메뉴가 같다고 가정하지 않는다.
3. 조회 화면부터 확인하고 필요한 합계·행 참조만 가명으로 기록한다. 신고서에 가상 수치를 넣거나 임의로 임시저장하지 않는다.
4. 실제 입력·검증을 요청받은 경우 확인된 자료만 사용하고 입력 화면·오류 검증·제출 직전 요약을 따로 기록한다. 불일치와 1원 차이도 확인 없이 승인하지 않는다.
5. 제출·발급·납부·신청 취소 등 최종 행위는 사용자가 직접 수행한다. 접수번호·정상 처리·납부 결과는 별도 증거로 확인하며, 불명확한 제출을 반복하지 않는다.

## 기록 해석

각 기록에는 실제 이동 URL·확인 시각·대표 메뉴명·부분 검증 단계·증거 파일 SHA-256이 있다. 원본 캡처와 DOM은 별도 검증 산출물의 `qa/browser/`에 보관하며 스킬 패키지에 원본 이미지나 개인자료를 넣지 않는다. 화면은 바뀔 수 있으므로 URL만으로 결과를 재사용하지 않는다. Aside 앱 실행 오류 후 Playwright 브라우저로 실제 사이트를 확인했다. 로그인 및 외부 의존성이 있는 기능의 성공을 로컬 단위 테스트로 대신하지 않는다.

# 로그인 전에 세금이 얼마인지 보는 법

확인일: 2026-09-20. 아래 경로는 [실제 홈택스 검증 기록](live-ui-verification.md)에서 **공개 화면으로 확인된 것**만 적는다. 공개 여부는 홈택스 개편으로 바뀔 수 있으므로 화면에서 다시 확인한다.

## 이 문서가 답하는 요청

"신고 전에 대충 얼마 나오는지 미리 보고 싶다", "로그인 안 하고 계산해 볼 수 있나", "세금 얼마 나올지 궁금하다" 같은 요청이다.

**국세청이 만든 모의계산기를 쓰게 안내한다.** 이 도구가 대신 세액을 계산하거나 암산하지 않는다 — 추정이라도 LLM이 계산한 숫자를 세금으로 제시하지 않는다.

## 로그인 없이 되는 것 (검증 기록 기준)

| 하고 싶은 것 | 홈택스 경로 | 검증 상태 |
|---|---|---|
| **급여생활자 세금 미리보기** | 장려금·연말정산·기부금 → 편리한 연말정산 → **(모의계산) 연말정산 자동계산** → 귀속연도 선택 | H16 공개 입력 화면 확인 |
| **내 업종의 단순경비율·기준경비율 확인** | 세금신고 → **기준·단순경비율(업종코드) 조회** | H12 공개 조회 결과 확인 |
| **주택임대 종합과세 vs 분리과세 비교** | 주택임대 모의계산 | S01에서 가상 사례로 입력·대조 |

## 로그인이 필요한 것

| | 홈택스 경로 | 검증 상태 |
|---|---|---|
| 부가세 세액비교 | 세금신고 → (모의계산)부가가치세 세액비교 | H10 **로그인 요구 확인** |

부가세를 미리 보고 싶다는 요청에는 로그인이 필요하다고 먼저 알린다. 로그인 없이 대신 계산해 주지 않는다.

## 안내할 때 지킬 것

1. **대신 계산하지 않는다.** 경로를 안내하고, 어떤 칸에 무엇을 넣는지 준비를 돕는다. 화면의 결과를 읽고 해석하는 것까지가 이 도구의 몫이다.
2. **모의계산 결과는 신고 금액이 아니다.** 국세청 화면에도 그렇게 적혀 있다. 실제 신고는 자료가 반영된 뒤 달라진다.
3. **공개 여부를 단정하지 않는다.** 위 표는 확인일 기준이다. 화면이 로그인을 요구하면 그대로 알리고 로그인 후 경로로 넘어간다.
4. 금액이 크거나 애매하거나 범위 밖이면 세무사 상담을 권한다.

## 연말정산 자동계산에 넣기 전에 모을 것

급여생활자 미리보기는 이 정도만 있으면 대강 나온다. 정확한 값은 회사 원천징수영수증과 연말정산 간소화 자료로 확인한다.

- 연간 총급여(비과세 제외)
- 부양가족 수와 각자의 나이·소득 요건 충족 여부
- 국민연금·건강보험·고용보험 납부액
- 연금저축·IRP 납입액, 주택청약, 신용카드 사용액
- 의료비·교육비·기부금·월세

## Pro 가 설치돼 있으면

`jongsose-prep-kr` 의 `references/estimate.md`(로그인 전 추정)로 이 도구 안에서 바로 추정할 수 있다(사업자 종소세·급여생활자 종소세·부가세). 그 산출물도 전부 추정이며 신고 금액이 아니다. 미설치면 위 홈택스 경로를 계속 쓴다.

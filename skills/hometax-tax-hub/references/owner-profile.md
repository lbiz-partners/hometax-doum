# 1인 개인사업자 공통 프로필

목적은 같은 사업·기간의 자료를 연결하고 반복 질문을 줄이는 것이다. 프로필은 세무 판정서나 홈택스 계정이 아니다. 법인 프로필을 개인 종소세 엔진으로 보내지 않는다.

## 재사용과 갱신

1. 사용자가 지정한 로컬 JSON만 읽는다. 다른 사업장·개인 폴더를 넓게 탐색하지 않는다. 저장을 원하지 않으면 현재 대화의 확인된 값으로 진행한다.
2. 사업 가명·개인사업 여부·과세유형·기준일·작업 기간을 보여 준다. 마지막 확인일이 없거나 다른 과세기간의 값이면 재확인이 필요하다. 최근 파일이어도 과세유형·업종·판매채널·직원·외주 지급 변경을 확인한다.
3. 확인한 정보는 인계하고 변경점만 묻는다. 사용자 응답 없이 기준일을 오늘로 바꾸거나 confirmed를 true로 설정하지 않는다. 사업 사실의 확인일과 파일 수정일은 다르다.
4. 저장 시 변경 전·후 차이를 제시하고 사용자가 선택한 경로에 기록한다. 원본과 종전 프로필을 임의 삭제하지 않는다. Pro 엔진 출력은 새 파일만 사용한다.

최소 내용은 사업 가명, 개인사업 여부, 과세유형, 생활어 업종, 실제 판매채널, 직원 여부, 외주 지급 여부, 확인일이다. **직원 없음과 외주·강사료·일용 지급 없음은 별개**다. 금액·건수 0 또는 false는 실제 없음을 확인한 값이며 미수집은 null/unknown으로 남긴다. 과세유형은 해당 기간·변경 효력일을 확인한다.

[프로필 템플릿](owner-profile-template.json)을 사용자가 선택한 세무 폴더에 복사해 채운다. business_key는 shop-a 같은 토큰이며 실명·상호·사업자번호를 쓰지 않는다. 주민번호, 전체 계좌·카드번호, 연락처, 비밀번호·인증서·OTP, 거래 원본은 넣지 않는다. 가명화는 완전한 익명화를 보장하지 않으므로 외부 공유를 기본 동작으로 삼지 않는다.

무료에서는 같은 JSON을 수동 관리한다. Pro jongsose-prep-kr가 설치되어 있으면 그 스킬의 references/owner-workspace.md와 scripts/owner_workspace.py --help에 따라 검증한다. 해당 엔진이 없거나 검증에 실패하면 자료 준비와 화면 안내는 계속하되 자동 검증 완료라고 하지 않는다. 단독 스킬 설치에서도 최소 항목을 직접 확인하면 진행할 수 있다.

인계 요약: 프로필 경로(선택) / 사업 가명 / 과세유형·기간 / 확인일 / 이번 변경점 / 미확인 항목.

# 신고 후 상태와 증빙

서로 다른 사실을 하나의 완료로 합치지 않는다. 사용자 말만 있으면 사용자 진술, 화면·파일을 열어 대조했으면 증빙 확인으로 표시한다. 로컬 상태 기록은 신고나 납부를 실행하지 않는다.

| 사실 | 필요한 증거 | 이것만으로 알 수 없는 것 |
| --- | --- | --- |
| 제출 직전 준비 | 기간·유형·차이표·최종 세액 검토 | 실제 접수 |
| 국세 신고 접수 | 해당 세목·귀속·유형의 접수증·접수번호·시간 | 국세 납부·지방 접수 |
| 국세 납부 | 해당 납부번호의 납부결과·금액·일자 | 분납 잔액·지방 납부 |
| 지방소득세 신고 | 위택스 등의 접수 결과 또는 적법한 신고 간주 사실 | 지방 납부 |
| 지방소득세 납부 | 지방 납부결과·납부번호·금액·일자 | 국세 납부 |
| 환급 예정 | 신고서 예상액·처리상태 | 환급 결정·지급·입금 |
| 환급 지급·입금 | 공식 지급 내역과 마스킹된 입금내역을 각각 확인 | 다른 세목·지방세 환급 |

각 사실을 미확인/준비중/접수확인/납부확인/환급처리중/입금확인/해당없음 등으로 기록한다. 해당없음에는 무납부·환급신고·법정 신고 간주 등 확인한 사유가 필요하다. 조회 결과 없음은 곧 미신고·미납·0원이 아니다. 조회기간·세목·명의·반영 시점을 확인한다.

최소 기록: 사업 가명, 세목, 귀속·기간, 정기/기한후/수정 구분, 확인일, 상태별 근거 파일 경로, 금액 출처, 남은 일. 접수번호·계좌 등은 보고용 사본에서 마스킹한다. 원본은 사용자가 선택한 폴더에 보관한다. 수정신고가 있으면 최신 접수증과 종전 이력을 연결한다.

[국세청 신고·납부방법](https://g.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=238910&mi=40296)은 종소세 후 지방소득세와 국세 납부를 별도 절차로 안내한다(확인일 2026-09-12). 모두채움 지방세 신고 간주 등 예외는 해당 연도 공식 안내와 실제 이행증빙으로 확인한다. 자동 제출·납부 금지와 사용자 인증 원칙을 유지한다.

보고 예: 국세 접수증 확인 / 국세 납부 미확인 / 지방 신고 미확인 / 지방 납부 미확인 / 환급 해당없음(납부신고 확인). 예상세액·준비금 계산 결과로 이 상태를 바꾸지 않는다.

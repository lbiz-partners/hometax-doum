# 단순 부가세 신고의 짧은 경로와 후속 확인

## 짧은 경로 선택

사용자 요청이 단순 신고이고 과세유형·과세기간·유형 전환·매출/매입 자료 범위가 확인된 경우에 쓴다. 자료가 적다는 이유만으로 무실적 또는 0원으로 채우지 않는다. 여러 사업장·겸영·영세율·재고/고정자산·폐업·조기환급·복잡한 수정 등이 있으면 일반 점검 흐름과 해당 서식으로 확장한다.

1. 현재 신고 안내와 과세유형 확인. 간이의 세금계산서 발급·7월 유형 전환 여부를 확인하고 면세 전용은 사업장현황 준비로 연결한다.
2. 미리채움에서 판매채널 원장·세금계산서·카드·현금영수증의 매출과 매입을 비교한다. 누락·이중계상·취소/환불·자료 제공기간을 확인한다.
3. 사업용카드 공제/불공제와 해당 공제 명세를 확인한다. 기존 SKILL.md의 전자신고·전자세금계산서 발급공제 요건과 최종 반영 QA를 생략하지 않는다.
4. 미해결 차이가 없으면 사용자에게 최종 금액·기한·검토 내용을 제시한다. 제출·납부·인증은 사용자가 한다.

간이의 납부면제와 신고의무를 구별한다. [국세청 VAT 신고납부기한](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7694&mi=2273)(2026-09-12 확인)은 유형별 기본기간과 전환·상반기 발급 간이의 예외를 안내한다. 정확한 실제 마감일은 해당 연도 공지·휴일·개별 연장을 다시 확인한다.

## 사용자가 신고를 마쳤다고 하면

- 신고 접수증의 사업장·기간·유형·접수번호·일시를 대조한다. 접수만 확인했으면 신고접수 확인으로 보고한다.
- 국세 납부결과·세액·기한·분납 잔액 또는 환급신고 상태를 별도로 확인한다. 납부서를 출력한 것과 납부 완료는 다르다.
- 환급은 신고서 예상액, 공식 처리상태, 실제 입금을 따로 남긴다. 환급계좌는 사용자가 공식 화면에서 직접 확인한다.
- VAT에는 종소세의 지방소득세 연계 단계를 기계적으로 붙이지 않는다. 국세 납부/환급 후속만 해당 사실에 따라 기록한다.
- 신고서·접수증·납부/환급 증거를 사용자가 선택한 폴더에 보관하고 확인되지 않은 사실은 미확인으로 둔다.

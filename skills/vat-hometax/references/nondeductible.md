# 매입세액 공제·불공제 1차 체크

신고 시점 홈택스 분류를 출발점으로 삼되 증빙·거래일·공급자 자격과 법령으로 대조한다. 홈택스 공제 표시도 확정 판정이 아니다.

## 공제 후보 요건 (동시)
1. 사업 관련
2. 과세사업 사용(예정)
3. 적격증빙 (세금계산서 / 카드매출전표 / 지출증빙 현금영수증, 부가세 구분)
4. 공제 가능 공급자
5. 수령명세서·보관 요건 (해당 시)

## 대표 불공제 후보
- 기업업무추진비(접대)
- 비영업용 소형승용 구입·유지·임차
- 사업무관·가사
- 면세·토지 관련
- 세금계산서 미수취·부실
- 사업자등록 전 매입 (예외 검토)
- 면세 공급 또는 세금계산서를 발급할 수 없는 간이과세자와의 거래 등 (아래 공급자 구분 참조)
- 해외 사용
- 여객운임 등 (예외 확인)
- 인건비(매입세액 아님)

## 사업용카드 홈택스 분류
- 공제 / 선택불공제 / 당연불공제
- 선택불공제→공제 전환은 사용자 확인 후에만
- 당연불공제는 공제 전환하지 않음

## 간이과세 공급자 구분

| 공급자·증빙 | 1차 판정 |
| --- | --- |
| 세금계산서 발급사업자인 간이과세자 + 유효한 세금계산서/세액 구분 카드·현금영수증 | 다른 요건을 충족하면 공제후보. 간이라는 이유만으로 제외 금지 |
| 영수증 발급대상 간이과세자 또는 면세 공급자 | 해당 거래의 부가세 매입세액은 불공제후보/해당없음. 종소세 필요경비는 별도 판단 |
| 거래 당시 공급자 자격·실제 판매자·증빙이 불명확 | 확인필요. 현재 조회한 과세유형을 과거 거래에 그대로 대입하지 않음 |

카드 결제와 세금계산서가 같은 거래이면 한 번만 공제한다. 플랫폼 상호만 있으면 실제 판매자와 원증빙을 확인한다. 신고자 본인이 간이과세자이면 일반과세자의 매입세액 전액 공제 방식을 적용하지 않는다.

근거(2026-09-12 확인): [손택스 사업용신용카드 공제 안내](https://mob.tbcr.hometax.go.kr/jsonAction.do?actionId=UTBCRCB023F001), 부가가치세법 §38·§39·§46③ 및 시행령 §88⑤. 공제 안내에서 일반과세자와 세금계산서 발급 간이과세자를 별도로 확인할 수 있다.

## 겸영 안분
과세+면세 동시 → 공통매입 안분 여부 질문. 전액 공제 추정 금지.

# 매입세액 공제·불공제 1차 체크

신고 시점 홈택스 분류·안내 우선.

## 공제 후보 요건 (동시)
1. 사업 관련
2. 과세사업 사용(예정)
3. 적격증빙 (세금계산서 / 카드매출전표 / 지출증빙 현금영수증, 부가세 구분)
4. 공제 가능 공급자
5. 수령명세서·보관 요건 (해당 시)

## 대표 불공제 후보
- 기업업무추진비(접대)
- 비영업용 소형승용 구입·유지·임차
- 사업무관·가사
- 면세·토지 관련
- 세금계산서 미수취·부실
- 사업자등록 전 매입 (예외 검토)
- 간이·면세 거래 등 당연불공제
- 해외 사용
- 여객운임 등 (예외 확인)
- 인건비(매입세액 아님)

## 사업용카드 홈택스 분류
- 공제 / 선택불공제 / 당연불공제
- 선택불공제→공제 전환은 사용자 확인 후에만
- 당연불공제는 공제 전환하지 않음

## 겸영 안분
과세+면세 동시 → 공통매입 안분 여부 질문. 전액 공제 추정 금지.

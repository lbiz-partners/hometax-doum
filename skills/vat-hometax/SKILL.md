# 부가세 홈택스 신고 (vat-hometax)

홈택스에서 **부가가치세 신고를 제출 직전까지** 준비·점검하는 범용 스킬.  
특정 회사 전용이 아니다. 동료·일반 개인사업자 기준으로 동작한다.

연관 스킬:
- 준비: `tax-prep-kr`
- 분류: `receipt-classify-kr`
- 종소세: `income-tax-hometax`
- 허브: `hometax-tax-hub`

상세:
- `references/nondeductible.md`
- `references/excel-control.md`
- `references/tax-policy.md` — 과세유형·공제 적용요건과 공식 근거 (2026-09-12 확인)

## 절대 규칙

1. **자동 제출·납부 금지.** 확인 문구: `이 내용으로 부가세 신고/납부 진행해도 될까요?`
2. 비밀번호·인증서 비밀번호·OTP·간편인증 **직접 입력 금지**
3. 홈택스에 없는 숫자 창작 금지
4. 공제/불공제 단정 금지 → 후보 + 확인
5. 해당 과세기간·신고일 법령과 홈택스 화면을 함께 대조. 모순은 확인필요로 남기고 제출 준비 완료로 표시하지 않는다.
6. **주민번호·계좌·사업자번호 등 식별정보는 마스킹**하고 파일/폴더로 관리, 채팅 입력 최소화.
7. 보고 말미 표준 면책(아래 「보고 포맷」 하단 문구)

## 복잡한 신고와 정정

영세율·겸영·조기환급·의제매입·자산·임대는 `tax-prep-kr`의 `references/advanced-and-linked.md` H10에서 준비자료·검토 범위를 확인한다. 기한후·수정·경정청구는 `references/corrections-and-relief.md` H20과 현재 세목별 화면을 연결한다. Pro 신고값 대조는 `jongsose-prep-kr`의 `references/business-desk.md`를 따른다. 세법상 공제 가능성이나 세율을 합계 일치만으로 확정하지 않는다.

## 시작 인터뷰

```text
- 기준일(오늘 날짜): 시스템 시계에서 읽거나 사용자에게 확인. 추정 금지. 신고일·기한·경과일수 판단의 기준
- 과세기간 (예: 2026년 1기 확정)
- 신고구분·예정 신고일 (정기 / 기한후 / 수정 / 경정청구)
- 과세유형: 일반 / 간이 / 모름
- 간이면 세금계산서 발급사업자인지, 기간 중 과세유형이 바뀌었는지
- 자료: 홈택스만 / 분류 엑셀 있음
- 목표: 조회만 / 제출 직전까지
```

자료가 거의 없으면 `tax-prep-kr` 먼저 권고.  
미분류 카드·영수증이 많으면 `receipt-classify-kr` 먼저 권고.

## 단순 신고와 신고 후 확인

[짧은 경로·신고 후 확인](references/simple-route-and-aftercare.md)을 따른다. 과세유형·전체 기간·자료원 누락이 없고 예외가 없는 단순 건은 미리채움 → 매출/매입 대조 → 공제 점검 → 제출 직전 QA로 진행한다. 단순이라는 이유로 유형 전환·환불·이중계상 검토를 생략하지 않는다. 면세 전용이면 tax-prep-kr의 사업장현황신고 준비로 연결한다.

## 홈택스 절차

1. 로그인 세션 확인 (없으면 사용자 로그인)
2. **세금신고 → 부가가치세 신고**
3. 일반과세: **정기신고(미리채움)** 우선 / 간이: 해당 메뉴
4. 과세기간·사업장 확인
5. 미리채움 적용 후 항목별 확인
6. snapshot으로 숫자 기록

### 매출 확인
- 매출처별 세금계산서 합계표
- 신용카드 매출전표 등 발행금액 (해당 시)
- 현금영수증 매출 (해당 시)
- 수기·누락 매출 여부
- 카드매출과 세금계산서 **이중계상** 여부

### 매입 확인
- 매입처별 세금계산서 합계표
- 사업용신용카드 공제 확인/변경
- 현금영수증 매입
- 공제/선택불공제/당연불공제 구분

### 기타
- 공제·감면·가산세 → **경감·공제세액 2종**(전자신고 세액공제 + 전자세금계산서 발급세액 공제)은 아래 「경감·공제세액」 섹션에서 필수 점검
- 기납부(예정고지 등)
- 업종별 추가 서식

## 간이과세자 흐름 (과세유형이 간이일 때 — 다른 점만)

나머지는 일반과세 절차와 동일. 아래만 다르게 본다.

- **판정 기준연도 (오인 주의)**: 기존 사업자의 간이과세 여부는 **직전연도 공급대가**와 업종·지역 등 배제요건을 함께 본다(부가가치세법 §61). 현행 일반 기준은 **1억400만원 미만**(시행령 §109①). 부동산임대업·과세유흥장소의 별도 기준, 복수 사업장 합산, 신규·휴업자의 12개월 환산을 확인한다. 현재 매출만으로 사업자등록상의 과세유형을 바꾸지 않는다. **납부면제는 해당 과세기간 공급대가 4,800만원 미만**(§69)으로 기준연도가 다르며, 신규·폐업 등 1년 미만 기간의 환산도 확인한다.
- **신고 횟수**: 원칙 연 1회 — 과세기간 1~12월 → **다음 해 1월** 신고. (7월 예정부과 고지·세금계산서 발급 간이과세자의 7월 신고 여부는 홈택스 안내 확인)
- **세액 구조**: 공급대가(부가세 **포함** 매출) × 업종별 부가가치율 × 10% − 세금계산서 등 수취분 공제(현행 공급대가×0.5%). 계산은 홈택스가 한다 — 여기서는 **매출 누락·업종 부가가치율이 내 업종인지** 위주로 점검.
- **납부면제**: **해당 과세기간(당해연도) 공급대가 합계액이 4,800만원 미만**이면 납부의무 면제(신고 자체는 필요 — 부가가치세법 §69). 위 간이과세자 판정(직전연도 기준)과 달리 **당해연도** 기준이다. 기준금액은 해당 연도 홈택스/국세청 안내로 재확인.
- **매입초과 환급 없음**: 간이과세는 매입세액이 매출 관련 세액보다 크다는 이유만으로 일반과세처럼 환급하지 않는다. 과오납·기납부 정산까지 모든 환급이 불가능하다고 단정하지 않는다. 설비 투자 등 매입이 큰 경우 과세유형 전환 요건·적용시점을 별도로 비교한다.
- 점검 3가지: ① 매출을 공급대가(부가세 포함) 기준으로 봤는지 ② 세금계산서 수취분 입력 누락 없는지 ③ 겸영(과세+면세) 여부.

## 엑셀 대조

`references/excel-control.md` 기준.  
기본 전략: **미리채움 + 엑셀 합계 대조 + 차이만 수정**  
엑셀 전체 업로드로 끝난다고 가정하지 않음.

사용자가 별도 장부 프로그램의 기간 집계나 Pro 월마감 대조 결과(탐지 시)를 제공하면 **[홈택스 미리채움 ↔ 엑셀 ↔ 집계값] 3자 대조**로 확장한다. 집계의 과세방식(일반/간이/면세)을 먼저 확인한다 — 과세유형별 집계 방식이 다르다. 집계 파일의 존재를 가정하거나 찾아 헤매지 않는다. 차이가 있으면 원인 확인 전 제출 권유 금지.

| 차이 | 조치 |
| --- | --- |
| 일치 | pass |
| 홈택스 > 엑셀 | 엑셀 누락 가능 |
| 엑셀 > 홈택스 | 미전송·미등록·기간오류 가능 |
| 분류만 다름 | 공제여부 확인 질문 |

## 경감·공제세액 — 놓치기 쉬운 2종 (개인사업자 필수 점검)

③ 공제·감면·가산세액 > **경감·공제세액**은 미리채움에 자동 반영이 안 될 수 있다. **금액에 직접 영향**을 주므로 제출 전 반드시 두 명세를 직접 연다.

| 공제 | 요건 | 금액 | 입력 위치 |
| --- | --- | --- | --- |
| **전자신고 세액공제** | 법정 대상인 확정신고를 납세자가 직접 전자신고. 무실적 일반과세자 제외, 간이과세자는 납부세액 한도 확인 | **2026-02-27 이후 전자신고분 5,000원**, 이전 신고분 10,000원. 과세기간 대신 신고일로 구분 | ③ > `그 밖의 경감·공제세액` 명세 |
| **전자세금계산서 발급세액 공제** | 직전연도 사업장별 공급가액(면세 포함) 합계 **3억원 미만 개인사업자**(또는 당해연도 신규 개시). 발급 후 **다음날까지 전송**분 | **건당 200원**, 연 100만원 한도 | ③ > `전자세금계산서 발급세액 공제` 명세 |

- **전자세금계산서 발급공제 절차**: 명세 팝업 → 자격 `여` 확인 → `전자세금계산서 발급건수 및 공제금액 조회`로 국세청 집계 건수 확인 → **① 발급건수**에 그 건수 입력 → ③ 공제가능세액 자동계산(건수×200원, 한도 100만원) → **입력완료**를 눌러야 신고서 ③에 반영된다.
- 홈택스가 상단에 **"전자세금계산서발급정상입력여부" 안내(경고)**를 띄우면 = 이 공제를 확인하라는 신호. 반드시 검토.
- **전자세금계산서 발급공제의 간이과세자 예외**: 세금계산서 발급사업자인 간이과세자는 부가가치세법 §63④에 따라 대상이 될 수 있다. §36①2의 영수증 발급대상 간이과세자(신규·직전연도 공급대가 4,800만원 미만 등)는 구분한다. **간이과세자를 일괄 제외하지 않는다.**
- **전자세금계산서 발급공제 제외·한도**: 법인사업자, 직전연도 사업장별 공급가액(면세 포함) 3억원 이상인 기존 개인사업자 등은 제외. 현행 발급기한은 **2027-12-31**이며 연간 한도와 해당 납부세액 한도를 확인한다. 공제 때문에 언제나 환급이 늘어난다고 가정하지 않는다.
- 두 공제는 **매번 적용요건을 점검**하되, 무실적·간이 납부면제·기한후/수정/경정청구·이미 공제한 건에 자동으로 다시 가산하지 않는다. 기한후 등 공제 적용 근거를 확인하지 못하면 `확인필요`로 남긴다. 상세 근거는 `references/tax-policy.md`.

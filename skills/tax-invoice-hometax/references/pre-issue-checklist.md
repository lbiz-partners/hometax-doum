# 전자세금계산서 발급 직전 체크리스트

본문·미리보기 발급 버튼 전에 모두 확인. fail 또는 확인필요면 발급 권유 금지. 미리보기 열림만으로 pass 처리하지 않는다. 해당하지 않는 수정발급 항목은 사유를 적고 해당없음으로 표시한다.

| # | 항목 | pass / fail / 확인필요 | 메모 |
| --- | --- | --- | --- |
| 1 | 로그인 사업·공급자 사업장 일치 |  |  |
| 2 | 공급받는자 사업자번호 정확 |  |  |
| 3 | 실제 반영된 상호·성명·주소 및 화면 필수 항목 충족 = 사용자 의도 거래처 |  |  |
| 4 | 작성일자 확인 |  |  |
| 5 | 공급일자 확인 |  |  |
| 6 | 품목(재화·용역) 명확 |  |  |
| 7 | 공급가액/부가세 포함 합계 기준 확인, 사용자 금액과 입력값 자릿수 대조 |  |  |
| 8 | 세액 검산 (과세 시 약 10%) |  |  |
| 9 | 합계금액 = 공급가액 + 세액 |  |  |
| 10 | 과세 / 영세율 / 해당 구분 맞음 |  |  |
| 11 | 동일 거래 중복 발급 아님 (조회) |  |  |
| 12 | 수정발급이면 원본·수정사유 일치 |  |  |
| 13 | 이메일/전송 옵션 필요 시 설정 |  |  |
| 14 | 사용자 확인 문구 준비 |  |  |
| 15 | 휴·폐업 여부 확인 (번호 유효성 알림과 별도 확인, 폐업이면 중단) |  |  |
| 16 | 영수/청구 실제 선택 = 대금 수령 여부 (사용자 본인 선택) |  |  |
| 17 | 조회 실행·사업장·기간·문서 종류 등 조건 확인, 처리 중인 동일 거래 없음 |  |  |

확인 문구:

```text
이 내용으로 세금계산서 발급 진행해도 될까요?
- 공급자: {사업장} / 문서 종류: {종류·과세구분}
- 공급받는자: {상호} ({사업자번호})
- 받은 금액의 기준: {공급가액 / 부가세 포함 합계}
- 공급가액: {n}원 / 세액: {n}원 / 합계: {n}원
- 작성일: {yyyy-mm-dd} / 공급일: {yyyy-mm-dd}
- 품목: {내용}
- 대금 수령 여부: {받음 / 미수령} / 실제 선택: {영수 / 청구}
확인 후 발급하기와 인증은 직접 진행해주세요.
```

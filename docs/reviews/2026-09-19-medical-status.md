## 13차가 잡은 것 (마지막 델타의 첫 독립 검증)

12차 지적을 반영한 델타는 13차가 처음 검증했고, 여기서 **두 건이 실제로 뚫렸다.**

- **주석 은닉 차단이 래퍼 한 겹에 되살아났다.** `<!--` 안에 코드펜스를 두르면 펜스 판정이 주석 판정보다 먼저 와서 숨긴 문구가 그대로 남았다(실측). → 주석 안에서는 펜스를 토글하지 않도록 순서를 바꿨다. 같은 수정으로 "주석 안 홀수 펜스가 문서 나머지를 삼켜 정상 문서를 FAIL 시키는" 오탐도 함께 닫혔다.
- **안전규칙 한 건이 절 범위 밖에 남아 있었다.** `pro-detection-file-based` 가 `under_heading` 없이 파일 전체를 보고 있어 문구 부록 이동으로 뚫렸다(실측). → 앵커를 절별로 4개 규칙으로 분리했다. 이제 `under_heading` 이 없는 규칙은 JSON 파일 대상 1건뿐이며, 그 건은 `check.mjs` 의 JSON 구조 검사가 받는다.
- **버전 가드가 표기 한 글자에 꺼졌다.** VERSION 끝의 공백 하나, CRLF, `-rc1` 이면 비교가 "생략"돼 역행이 통과했다(실측). → 공백·CR 을 떼고 `X.Y.Z` 엄격 일치를 강제하며, 어긋나면 생략이 아니라 **거부**한다. 경계 11종 재확인.
- **절대 URL 전환이 오타를 검사 밖으로 옮겼다.** → 링크 검사가 GitHub 절대 URL도 리포 경로 실재 여부로 확인한다. 다만 **머지 전에는 그 URL 이 404 이므로, 출고 ZIP 배포는 머지 완료 후에 한다.**
- README 의 "배포 차단 지적을 모두 해소" 표현을 "13회의 지적을 반영"으로 낮췄다.

## 남은 것

- 홈택스 로그인 후 실제 화면에서 치과의원에 어떤 검토표가 뜨는지, 검토표 비보험란에 과세(미용) 비급여가 포함되는지, 「해당 과세기간 진료분 미수령액」 칸의 본인부담금 중복 여부 — 문서가 모두 "확인 필요"로 표시.
- ~~수의업(동물병원)·약국 전용 안내 부재~~ → 이번 버전에서 추가했다. 다만 약국의 면세 경계(처방조제 약제비의 범위, 재화 판매의 취급)는 조문으로 확정되지 않아 안내에서 확인 항목으로 남겼다.
- **`repo-sync` 데몬**: 이 기계에서 상시 실행되며 이 리포가 등록돼 있다. main 만 동기화하고 60초 무편집이면 push 하므로 **승인 전 main 체크아웃 금지**를 CLAUDE.md에 차단 조건으로 적었다. 데몬 제외(`repo-sync remove`) 여부는 사용자 결정.
- 데몬의 실제 push 가 `--no-verify` 로 pre-push 를 우회하는지는 확인하지 못했다. CI 측 버전 가드를 세워 클라이언트 훅 단독 의존은 줄였다.
- 새 브랜치 push(`remote_sha` = zero)는 pre-push 버전 비교를 건너뛴다. main 삭제 후 재생성 시나리오는 CI 가 받는다.

# 사업자등록·사업용계좌·사업용카드·현금영수증·통신판매업 근거 대조표 (2026-09-30)

범위: 홈택스 도움 스킬 문서 갱신에 쓰기 위해, 2026-09-30 현재 시행 기준으로 조문 원문(법제처, korean-law MCP)과 국세청 안내 페이지(WebFetch)를 직접 읽고 확인한 내용만 적었다. "원문 확인"은 이번 작업에서 해당 원문을 실제로 읽은 항목이다. 읽지 못했거나 원문에 없는 항목은 "미확인"으로 두었고 숫자를 채우지 않았다. 조회일은 전부 2026-09-30이다. MST는 search_law가 [현행]으로 돌려준 법령일련번호이고, "조문 시행일"은 get_law_text가 해당 조문 본문에 표시한 시행일이다.

## 미확인·주의

1. **사업용 신용카드 등록 제도의 법령 근거**: 국세청 페이지에 근거 조문 표기가 없고, 부가세법 시행령 §74·§88에도 등록 규정이 없었다. 근거 조문을 적지 말고 "국세청 안내" 출처로만 쓸 것.
2. **현금영수증 취소 방법·메뉴**: nttSn=1351766 게시물에 취소 절차가 없다. 취소 메뉴명은 미확인이다.
3. **현금영수증 가맹점 가입의 홈택스 세부 메뉴명**: 7795 페이지에 없다. 미확인.
4. **사업용계좌 신고의 홈택스 메뉴명**: 이번 작업에서 조회하지 않았다. 미확인.
5. **사업자등록 홈택스 메뉴**: 국세청 페이지 문구("신청/제출 → 사업자등록신청/정정 등")는 확인했지만, 개편된 현재 홈택스 화면의 실제 메뉴명과 같은지는 확인하지 않았다.
6. **국세청 지정코드 번호**: 7796 페이지에 지정코드로 발급하라는 안내는 있다. 로컬 데이터 보호 훅이 전화번호 형식을 막아서 번호 문자열 자체는 이번 조회에서 옮겨 적지 않았다. 스킬 문서에 번호를 적을 때는 페이지에서 다시 확인할 것.
7. **현금영수증 미가입 가산세는 정액 1%가 아니다**: 수입금액 × 미가입일수/365 × 1%로 일할 계산한다. "미가입 1%"로 줄여 쓰면 과대 표기가 된다.
8. **발급거부 5%의 조건**: 건당 5천원 이상 거래이고 세무서장 통보를 받은 경우에만 적용된다. 건별 최소 5천원이다.
9. **의무발행 미발급 20%의 감경**: 10일 이내 자진신고·자진발급하면 10%로 줄어든다. 국민건강보험 급여 대상 등은 제외된다.
10. 조문 버전 표시: 소득세법 조문 본문의 시행일은 2026-01-01로, 법령 전체 시행일(2026-07-01)과 다르게 표시되었다. 부가세법 시행령 조문 본문의 시행일도 2026-02-27로, 법령 전체 시행일(2026-04-01)과 다르다. 둘 다 [현행] MST로 조회한 결과이므로 2026-09-30 현재 적용되는 본문이다.

# 업종별 준비·계산의 공식 근거와 적용 범위

제품 4.1.2 · 공식 근거 확인일 **2026-09-17**. 이 문서는 무료와 Pro가 함께 사용하는 정책 출처 안내다. 법령의 시행일·특례 종료일·도구의 지원 기간은 서로 구별한다. 법령에 계산식이 있다는 사실만으로 해당 사업자의 자격·거래 귀속·증빙 적격성이 확인되는 것은 아니다.

## 무료와 Pro의 제공 범위

[업종별 준비·검토목록](../skills/tax-prep-kr/references/industry-guide.md)은 온라인판매·소매, 음식점, 제조, 프리랜서·인적용역, 학원·면세 서비스, 상가임대, 주택임대, 수출·과세면세 겸영의 8개 업종·상황을 다룬다. 무료판은 자료 준비·질문·수동 확인·공식 경로와 이 근거 문서를 제공하며 계산 실행 코드는 포함하지 않는다.

Pro는 아래 8개 모드를 제공한다. 이는 업종마다 모든 세목을 계산한다는 뜻이 아니다. 한 업종에 여러 모드가 쓰일 수 있고, 같은 모드도 확인된 사실에 따라 사용 여부가 달라진다. 업종명만으로 일반·간이·면세 또는 공제 자격을 확정하지 않는다.

| Pro 계산 모드 | 계산하는 좁은 범위 | 현재 지원 기간과 주요 제외 조건 |
|---|---|---|
| 일반과세 기초 차액 | 통상 10% 과세 공급가액·확인된 영세율 공급가액과 직접 귀속 매입세액 | 종료한 2025·2026년 단일 연도 내 작성표. 특별 공제·기납부·예정고지·가산세·공통매입 안분 등이 있으면 제외 |
| 음식점 의제매입 | 개인 일반 음식점의 적격 국내 면세 원재료 매입에 대한 공제율·매입 한도 | 종료한 2025·2026년 정규 반기. 간이·법인·유흥·제조·다른 업종 겸영·수입 원재료·단축 기간 제외 |
| 간이과세 | 확인된 과세 업종별 부가가치율, 매입 공제 상한, 납부면제, 확인 기납부 차액 | 완전한 1년. 확인일 현재는 2025년 연간 자료가 대상이며 2026년 연간은 미완료. 영세율·면세 겸영·개폐업·유형 전환·재고납부 등 별도 조정 제외 |
| 공통매입 안분 | 일반과세자의 하나의 공통매입 범위와 관련 과세·면세 공급가액 비율 | 종료한 2025·2026년 정규 반기. 과세·면세 공급가액이 모두 양수인 경우. 대체 안분기준·보조금·자산 정산·예정 정산·간이 겸영 제외 |
| 상가 보증금 | 단일 상가 직접임대의 일별 보증금 간주임대료 공급가액과 그 매출세액 기여분 | 2025년 정규 분기·반기 및 2026년 1·2분기·상반기. 공동소유·전대·혼합용도·특수관계·특수기간 제외. 월세·매입세액을 포함한 최종 납부세액 아님 |
| 주택임대 분리과세 | 확인된 등록·미등록 수입의 필요경비·가중공제와 감면 전 산출국세 | 2025년 전체 연도, 총수입 2천만원 이하, 연중 등록상태 유지. 과세대상·주택 보증금 간주임대료·감면·추징·지방세·종합과세 비교 제외 |
| 재고원가 | 상품 원가 또는 원재료→재공품→완제품의 원가 연결과 장부상 이익·손실 | 종료한 2025·2026년 단일 연도 내 작성표. 실사·평가·귀속 확인 필요. 타계정 대체·자가소비·평가손실·감가상각 계산·세무조정 제외 |
| 서비스 수입 연결 | 환불·미수·선수, 별도 실지급액과 확인 원천징수액, 실제 경비의 연결 | 종료한 2025·2026년 단일 연도 내 작성표. 법정 귀속이 연결식과 맞는 경우만. 현금수령 특례·다른 귀속 조정·추정 경비율 제외 |

미완료 기간·미래 확인일·지원표 밖 조건은 과거 예제나 샘플 값으로 채우지 않는다. 기간의 법정 적격성과 실제 자료의 완전성은 별도로 확인한다. 2027년 이후 계산을 이번 근거 확인만으로 지원한다고 표시하지 않는다.

서비스 원천징수 수입은 실제 지급액에 증명된 원천징수액을 더한다. 해당 거래는 일반 수령액에서 제외하여 두 번 합산하지 않는다. 3.3%나 업종별 경비율을 임의로 가정하지 않으며 원천징수액을 필요경비로 다시 차감하지 않는다.

## 끝수·표시 금액의 한계

[국고금 관리법 제47조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1031067671)는 국세 과세표준의 1원 미만과 최종 국고 수입·지출의 10원 미만 처리를 구분한다. 계산 모드의 원 단위 미리보기·중간 분수 유지·표시용 절사 정책은 각 결과의 계산식과 제한사항에 따른다. 모든 홈택스 입력칸의 중간 단수 처리와 동일하다는 뜻이 아니며, 1원 차이도 자동 승인하지 않는다.

일반과세의 환급 방향 차액, 간이의 확인 기납부 차감 후 음수, 장부 손실은 의미가 다르다. 숫자가 음수라는 이유로 모두 0으로 올리거나 확정 환급으로 바꾸지 않는다.

## 공식 근거·계산·실제 UI·최종 제출의 구분

공식 법령과 안내의 열람은 계산 정책의 근거다. 가상자료의 계산 검증은 해당 입력과 지원 조건의 산술 검증이다. 두 결과 모두 로그인한 홈택스 화면의 현재 입력칸·자동계산·오류 표시를 확인한 증거를 대신하지 않는다.

실제 UI는 접근한 메뉴, 사업장·기간 선택, 입력·자동계산·검토 단계, 확인일과 해당 증거를 단계별로 따로 기록한다. 계산 참고값과 화면의 일부 항목이 같아도 나머지 신고 항목이나 공제 적격성이 검증된 것은 아니다. **이 문서는 실제 UI 검증의 결과·건수·완료 여부를 선언하지 않는다.**

최종 제출·접수증, 국세·지방세 납부, 환급 결정·입금도 각각 별도 확인이다. 로그인·인증과 마지막 제출·발급·납부는 이용자가 내용을 확인한 뒤 진행한다. 이 도구는 세무사법 제2조의 세무대리를 수행하지 않으며 실제 신고·납부 판단은 세무 전문가 검토가 필요하다.
